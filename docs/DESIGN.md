# FOMO Club — DESIGN.md

> 디자인 시스템 **단일 출처**. Claude Code(디자인·UX)와 Codex(데이터 렌더 시)가 모두 이 문서를 참조한다.
> **기반 토큰(색·타이포·간격·형태·터치·금지 목록)의 정본은 `docs/design/DS-00_TOKENS.md`(DS-00, v2)다.** 이 문서 §2~§6은 DS-00의 미러이며, 값이 어긋나면 **DS-00이 이긴다.** 모션·모티프·컴포넌트·보이스는 화면별 스펙(DS-01~06)이 도착할 때까지 이 문서가 담당한다.
> 컨셉 한 줄: **살아있는 터미널 × 클린 시트** — 수치는 모노(터미널), 문장은 Pretendard(클린 시트). 폰트로 둘을 분리한다.
> 테마: **다크 전용.** 라이트 모드는 만들지 않는다.

---

## 0. 두 가지 원칙 (DS-00 §1)

```
메인 카드 = 후킹      한 장면에 놀라움 하나. 텍스트를 최대한 없앤다.
상세 페이지 = 설득    근거를 쌓되 스캔 가능하게. 순서가 곧 논증이다.
```

원칙에 안 맞는 요소는 **크기를 줄이는 게 아니라 다른 화면으로 옮기거나 삭제**한다.
**현재 데이터로 채울 수 없는 것은 자리도 만들지 않는다** — 있음/없음 목록은 DS-00 §1-1.
결손·빈 상태·오류·로딩의 전 화면 공통 규칙은 **`docs/design/DS-05_MISSING.md`** 가 정본이다.
특히 **신뢰할 수 없는 섹터는 표시하지 않는다**(§4) — 틀린 섹터가 없는 섹터보다 나쁘다.

## 1. Identity & Principles

- **이중 모드:** 발견 모드(홈·스와이프·카드 앞면) = 후킹. 근거 모드(상세·출처·재무) = 설득. "겉은 가볍게, 속은 단단하게". 두 모드는 **색이 아니라 정보 밀도와 순서로** 구분한다.
- **브랜드 대비:** 머니터링 = 라이트·블루·빽빽한 점수·은행 도구. 우리 = 순수 검정·무채색·모노 수치. 의도적으로 다른 종(種).
- **제품 원칙이 시각을 구속한다(절대):**
  - 색이 매수/매도를 인코딩하지 않는다. **등락에 색을 쓰지 않는다**(상승=흰색, 하락=`down` 회색).
  - accent는 **화면당 한 곳**, 우리 성적 자리에만.
  - 무판정·차분: 근거 모드를 화려하게 만들지 않는다.
  - 상태는 색만으로 전달 금지 — 항상 텍스트 라벨 동반.

## 2. Color — DS-00 §2 미러

다크 전용. 표면 구분은 **배경 밝기 차이로만** 만든다(그림자·그라데이션·글로우 전면 금지).

| token | hex | 용도 |
|---|---|---|
| `bg` | `#000000` | 화면 배경 |
| `surface-1` | `#101010` | 카드 |
| `surface-2` | `#181818` | 카드 안 블록 |
| `border` | `#242422` | 구분선 (0.5px) |
| `text-1` | `#FFFFFF` | 본문·제목 |
| `text-2` | `#9A9A96` | 보조 |
| `text-3` | `#5A5A57` | 캡션·비활성 |
| `accent` | `#D4FF3F` | **화면당 1회만** |
| `accent-ink` | `#1A1A00` | accent 배경 위 텍스트 |
| `down` | `#7A7A76` | 하락 (빨강 쓰지 않음) |

**accent 규칙(가장 중요 — 2026-08-20 개정, 기획자 모킹 기준):** accent 는 **결론 · 우리 성적 · CTA** 세 자리다.
메인 카드 = 결론(`display`) + 우리 성적 + CTA(배경 accent, 글씨 `accent-ink`) / 상세 = 우리 기록의 수익률(상세엔 CTA 없음) / 성적표 = 대표 지표 하나 / 헤더·덱 타이틀·지켜보는 중·하단 탭 = 없음.
스파크라인·차트·등락·근거 박스·섹션 제목에는 여전히 쓰지 않는다. 성적이 없는 카드는 **성적 accent가 없는 것이 정상**이다.

**폐기된 v1 색축:** 오렌지(열기)·네온(발견) 2축, 봉인색 `up/down`(빨강·파랑), 감정색 5종, 그린/레드플래그 색. 판정 근거는 DS-00 §9.
감정색(`@fomo/core` `EMOTION_COLORS`)은 **데이터 계약으로만** 남는다 — UI에서 쓰지 않는다.

## 3. Typography — DS-00 §3 미러

| family | 폰트 | 용도 | 금지 |
|---|---|---|---|
| mono | **Departure Mono** (SIL OFL) | 티커, 종목코드, 수치, 라벨, 날짜 | 한글 금지 |
| sans | **Pretendard** (SIL OFL) | 문장 전부 | — |

수치와 문장을 폰트로 분리한다. 이것이 "Living Terminal × Clean Sheet"의 실행 방식이다.
*(2026-08-21 — 폰트를 `public/fonts` 에 번들했다. mono 1순위가 Departure Mono 이고 CDN 로딩은 없다. DS-06 §6-2.)*

**Scale:** `display` 24/500/1.32/-0.02em (결론 문장, 카드당 1회) · `title` 17/500/1.4/-0.01em · `body` 14/400/1.65 · `data` 14/400/1.4 (mono) · `label` 12/400/1.4/0.04em (mono) · `caption` 11/400/1.5/0.02em.
**11px 미만 금지. weight는 400·500 두 개만.**

**문장 규칙:** 해요체 통일(`~하였음`·`~합니다` 금지) · 한 문장 최대 2줄 · 마침표는 본문에만(라벨·제목·버튼엔 안 찍는다).
**OFL 의무 3:** ①폰트 단독 판매 금지(앱 번들 OK) ②배포 시 라이선스 텍스트 동봉 ③예약명으로 수정본 배포 금지.

## 4. Spacing & Layout — DS-00 §4 미러

4의 배수만: `s1` 4 · `s2` 8 · `s3` 12 · `s4` 16 · `s5` 24 · `s6` 32.
카드 패딩 `s4` · 화면 좌우 여백 20 · 섹션 사이 `s5` + 0.5px 구분선.
모바일 퍼스트(앱 출시 전제), 웹은 동일 스펙을 중앙 정렬. 세이프에어리어 준수. 스와이프 덱은 풀블리드.

## 5. Shape & Border — DS-00 §5 미러

카드 radius 16 / `surface-1` / 테두리 없음 · 카드 내부 블록 radius 10 / `surface-2` · 주요 버튼 pill h48 · 보조 버튼 pill h44 + 0.5px `border` · 칩 pill h26 padding 0 10 · 구분선 0.5px `border`.
**그림자·그라데이션·글로우 전면 금지.**

## 6. 터치 타겟 — DS-00 §6 미러

최소 44×44pt · 인접 타겟 간 최소 8px · **카드 전체가 탭 영역**(별도 버튼 없이 상세 진입).

## 7. Motion

- **제스처:** 덱의 스와이프는 **탐색**이다 — 좌=다음 / 우=이전 / 탭=상세(정본: DS-02 §4-1). 관심은 카드의 ★ 버튼만 담당한다. (종전 "우=관심 / 상=슈퍼관심" 은 폐기 — 슈퍼관심은 구현된 적이 없다.)
- **피드백:** 카드 이동 → transform 300ms(관성 없음: 한 번 스와이프 = 한 장) · 관심(★) → 아이콘 밝기 전환 + 햅틱. **글로우 금지**(DS-00 §5) — 밝기·투명도·형태로만 표현한다.
- **모드 전환:** 상세 진입 → 카드 전체 탭 또는 CTA(DS-02 §4-1).
- **로딩:** 스켈레톤(opacity 0.4↔0.7, 1.4s). **스피너 금지**(DS-02 §9).
- **Duration/Easing:** micro 120 / standard 200 / expressive 320. ease `cubic-bezier(.2,0,0,1)`. 디졸브·미터는 `steps()`.
- **60fps 필수**, 스와이프 잰크 금지. `prefers-reduced-motion` 존중(디졸브→페이드, 버스트 off).

## 8. Motifs — 데이터 비주얼 프리미티브

- **픽셀 스파크라인:** 매끈 선 아님 — 이산 픽셀 컬럼. **`text-2` 회색 단색**(가격 *형태*, 판정 아님). accent 금지. 무효선 동반.
- **강도 미터:** 도트 세그먼트, 채운 부분 `text-1`, 나머지 `text-3`. 옆에 mono 숫자. accent 금지.
- **로딩 시머:** 픽셀 블록 사이클(로딩 진행 작업과 연결).
- 도트-그리드 히트맵은 데이터 확보 후. **지금 채울 수 없는 프리미티브의 자리를 만들지 않는다**(DS-00 §1-1).

## 9. Components

**Stock Card (후킹)** — **정본은 `docs/design/DS-01_MAIN_CARD.md`.** 요약: `surface-1` · radius 16 · 패딩 `s4` · 고정 높이 없음 · 카드 전체 탭.
블록은 ① 종목명+티커 / 섹터·거래 → ② 가격(통화 기호 필수) → ③ 결론(`display`, **accent**, 명사형, 카드당 1회) → ④ `주가는 N일간 X%` → ⑤ 근거 박스(`surface-2`, 라벨-값 3행) → ⑥ 스파크라인 → ⑦ 우리 성적(accent) → ⑧ CTA(accent).
칩·로고·국기·무효선·매출 막대·회사 설명은 카드에 없다(상세로 옮겼다). 값·조건·삭제 목록은 DS-01 을 본다 — 여기서 중복 정의하지 않는다.

**Buttons:** 카드의 주요 CTA = pill h48, **배경 `accent` + 글씨 `accent-ink`**(화면에서 유일하게 채워진 버튼) · 보조 = pill h44 + 0.5px `border` + 글씨 `text-1`/`text-2`. 한 화면에 CTA 3개 이상 금지. 탭 타깃 ≥44×44.

**상세 (설득)** — **정본은 `docs/design/DS-03_DETAIL.md`.** 6섹션 고정: ① 결론(카드와 같은 문장, 화면에서 1회) → ② 근거(라벨-값 + 88px 스파크라인) → ③ 무슨 회사 → ④ 값(지표 3개 이상일 때만) → ⑤ 틀리는 경우 → ⑥ 우리 기록.
박스와 accent는 각각 ⑥ 하나뿐. 하단 CTA 없음(관심은 헤더 우측 별). 확보 안 된 섹션은 헤더까지 사라진다.

## 10. Voice & Tone (UI 카피) & Icon

- 해요체. 무판정(매수·매도·목표가·상승확률 금지). 시점·출처 항상. "추천" 대신 "판단 재료".
- **이모지 금지**(DS-00 §7). 아이콘은 라인 세트(Tabler outline 류) 일관 스트로크.
- **은어 금지**: 와이코프·클러스터 등. 대상은 왕초보다.

## 11. Do / Don't

**Do:** accent 한 곳 · 상태는 색+텍스트 · 등락은 무채색 · 근거 모드 차분 · 60fps · WCAG 대비 확인 · 높이는 내용에 따라 변한다.
**Don't:** accent 2곳 이상 · 같은 숫자 2회 이상 반복 · 빈 헤더 · 고정 높이로 생긴 공백 · CTA 3개 이상 · 이모지 · 빨강/초록 등락색 · 한글 mono 폰트 · 그림자/그라데이션/글로우 · 라이트 모드 · 없는 기능의 UI.

## 12. Governance

- 계층: **DS-00(기반 토큰) → DS-01~06(화면별 스펙, 도착 예정) → 이 문서(그 외 서술) → 화면별 핸드오프.** 상위가 이긴다.
- 오너: 디자인 시스템 = Claude Code / 데이터 렌더 준수 = Codex / 의사결정 = 광혁.
- 변경 절차: 토큰 변경은 **DS-00 문서부터** → `design/tokens.json` `ds` 블록 → 코드 → 이 문서 미러 갱신. 드리프트 테스트(`packages/fomo-core/__tests__/ds-tokens-drift.test.ts`)가 어긋남을 막는다.
