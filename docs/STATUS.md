## 7. WO-RENDER-01 — PART C 범위 정정 (중요)

직전 판 §11 은 *"세 번 반복된 사고의 틈이 닫혔다"* 라고 적었다. **그 판정은 과했다.**

**실측:**

1. `rebake-payload` 잡은 `.github/workflows/vercel-production-deploy.yml` 안에만 있다.
2. 그 워크플로의 트리거는 **`on: workflow_dispatch:` 하나뿐이다.** 자동 트리거가 없다.
3. 그런데 **Vercel Git 연동 자동배포가 살아 있다** — 배포 메타의 `source: "git"`,
   `gitRootDirectory: apps/web` / `apps/fomo-web` 가 그 증거다. `main` push 마다 자동 배포된다.

**→ 결론: 재생성은 사람이 워크플로를 수동 실행한 배포에만 붙는다.
`main` 에 머지해서 자동 배포되는 평상시 경로에는 붙지 않는다.**

그리고 그 상태가 **지금 프로덕션에 실제로 나타나 있다** — `asOf`(15:07) < 배포 시각(15:25), §4.

| PART | 내용 | 상태 |
|---|---|---|
| C | 배포 → 페이로드 재생성 | **부분**. 수동 dispatch 경로만. **자동배포 경로 미해결** |
| D | 수동 재생성 실측 | ✅ F-1 0건 · F-2 10/10 |
| E-1 | 앞면 매출 막대 제거 | ✅ 배선·높이 계약·E2E |
| E-2 | 거래 경고 → 헤더 중립 정보 | ✅ 배선. **화면 확인은 조건 미발생**(`liquidityNote` 보유 0/10) |
| **A** | 경고문 `with_band`/`without_band` 2종 분리 | **미착수** |
| **B** | `scripts/verify-production.ts` | **미착수 — 파일이 존재하지 않는다**(실측) |
| E-3 | 회사 설명 첫 문장 = 주력 사업 | 미착수 |
| E-4 | 디테일 순서·훅 1회 | 미착수 |

> ⚠️ **PART B 는 단순 미착수가 아니라 활성 결함이다.**
> `AGENTS.md:40` 의 세션 시작 체크리스트 2번이 *"verify-production.ts 로 정규 도메인 상태를 확인한다"* 인데
> **그 파일이 없다.** 모든 세션이 절차 2단계에서 막히고, 대개 그냥 건너뛴다.
> 지시와 코드가 어긋난 이 상태 자체가 WO-SYNC 가 잡으려던 드리프트다.

### 다음 착수 순서 (권고)

1. **PART C 잔여** — 자동배포 경로에 재생성 부착. `push: branches: [main]` 트리거 추가가 가장 짧다.
2. **PART B** — `verify-production.ts`. 핵심 조건 *페이로드 `asOf` < 마지막 배포 시각 → exit 1*.
   **CDN 캐시 우회 필수**(`Cache-Control: no-cache` + 캐시버스터).
3. **프론트 별칭 확인** — `fomo-web-liart.vercel.app` 이 최신 배포를 가리키는지(§4).
4. **PART A** → **PART E-3·E-4**.

## 10. 에이전트 메모리 검증 (E-1)

이 프로젝트의 에이전트 영구 메모리 디렉터리는 **비어 있다.**
따라서 **"00~08 머지" 오류는 영구 메모리에서 온 것이 아니다** — 세션 요약·인수인계 경로에서 발생했다.

**이번 세션이 그 진단을 다시 확인했다.** 인계된 전제 두 가지가 실측과 어긋났다:

| 인계된 전제 | 실측 |
|---|---|
| "열린 PR 2건(#578·#576, 6월 20일자)" | **둘 다 2026-06-21 머지.** 열린 PR 은 0건 |
| "README 가 피봇 이전(해자는 취향 매칭 × 쉬운 번역)" | README 헤드라인은 **이미 판단 원장으로 수정됨.** 그 문구는 **GitHub 레포 description** 에 남아 있다 |

→ 대응은 메모리 정정이 아니라 **`STATUS.md` 를 참조하게 만드는 것**이다.
그리고 **이 파일 자신도 틀릴 수 있다** — 직전 판의 §2 가 머지된 PR 4건을 "열림" 으로 이틀간 방치했다.
**읽는 쪽이 실측으로 재확인하라.**
