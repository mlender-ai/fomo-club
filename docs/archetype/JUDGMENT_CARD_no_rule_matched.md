작성 2026-08-06 · 대상 `archetype-v1.1.0` · 입력: A-0 실측(`docs/audit/A0_unclassified_reasons.md`, run 31019246701)

> 64/82가 한 축에 몰렸다는 건 카테고리가 없어서가 아니라 규칙에 구멍이 있다는 뜻이야. (…)

## 1. 판정 ① — 임계값 문제가 **아니다**

### 근거 A. 분포가 임계값 근처에 없다

θ_growth=15 에 근접한(12.5~15) 종목은 **32건 중 4건**뿐이다. 질량은 5~11 구간에 있다
(19건이 CAGR 10% 미만). 임계값을 조금 내려서 풀리는 모양이 아니라 **구간 전체가 비어 있다.**

### 근거 B. θ_growth 를 내리면 자를 틀리게 댄다

`QUALITY_COMPOUNDER` 의 경고문은 독트린에 이렇게 박혀 있다.

> 이 유형은 성장률과 값의 배수가 함께 움직입니다. 과거 성장이 둔화한 구간에서 배수도 함께 내려왔는지 확인해 보세요.

CAGR 중위 9.8%(19건은 10% 미만)에 이 프레임을 씌우면 **틀린 안내**다. 커버리지 숫자는
오르지만 이 배치가 없애려던 것이 정확히 그것이다.

방증: 중성장 32건의 PBR 이 넓게 퍼져 있다(<1: 7 · 1~3: 12 · ≥3: 12).
성장률로 배수를 설명할 수 없다는 뜻이다 — QC 프레임의 전제가 성립하지 않는다.

### 근거 C. 배당 θ 를 내리는 경로는 커버리지도 못 올린다

정체 32건의 배당수익률은 **전원 3% 이하**다(3% 초과 0건). "배당 조건을 살짝 못 넘긴 집단" 이
아니라 배당이 관측 지점이 아닌 집단이다. θ 를 3→2 로 내리면 6건(배당 2~3%)이
`MATURE_INCOME` 으로 간다. 그런데

> `MATURE_INCOME` 의 막대축은 주당배당금이고 **소스에 그 계정 매핑이 없다.**
> A-0 실측에서 유니버스 `MATURE_INCOME` 10장의 슬롯③ 성공은 **0/10** 이다.

즉 임계값을 느슨하게 해서 밀어 넣어도 **차트는 안 나오고 프레임만 틀린다.**
임계값 완화의 두 경로가 모두 실패한다.

**판정: 임계값 재도출로 풀 문제가 아니다. θ_growth·θ_dividend 를 건드리지 않는다.**

## 2. 판정 ② — 유형 부재다. 후보 두 개

### 후보 A — 안정 성장·흑자 (중성장 32건)

| 항목 | 내용 |
|---|---|
| 경계(안) | TTM 순이익 흑자 · CAGR3Y 5~15% |
| 표시 지표 | 매출 성장률 · PER 밴드 위치 · 영업이익률 추이 — QC 와 겹친다 |
| **해석 방법** | **다르다.** QC 는 "성장이 배수를 정당화한다" 가 프레임이다. 이 집단은 성장이 배수를 **부분적으로만** 설명한다(PBR 분산이 근거). 관측 지점이 "성장 지속성" 이 아니라 **"성장 대비 배수 위치"** 다 |
| 차트 축 | 매출 막대 + PER 밴드 — **이미 확보된 축**(`annual_revenue`) |
| 덱 해당 | 우진 · 일진파워 |

### 후보 B — 정체·저배당 흑자 (정체 32건)

| 항목 | 내용 |
|---|---|
| 경계(안) | TTM 순이익 흑자 · CAGR3Y <5% · 배당수익률 ≤3% |
| **해석 방법** | 성장도 배당도 관측 지점이 아니다. 12건이 마이너스 성장(중위 2.28%). 관측 지점은 **이익이 유지되는지 + 밴드 위치** 다 |
| `MATURE_INCOME` 과 경계 | 배당이 없거나 낮다(무배당 10 · 0~2% 16) → 배당 지속성 프레임이 성립하지 않는다 |
| `ASSET_DEEP_VALUE` 와 경계 | PBR ≥1 이 24/32 → 자산 재평가 프레임도 아니다 |
| 차트 축 | 매출 막대 + PER 밴드 — **이미 확보된 축** |
| 덱 해당 | Albertsons · Orion Group · V F Corp · 빅텍 · 풍산 |

### 하나로 합칠 수 있는가

경고문이 갈린다 — "성장이 배수를 부분적으로 설명한다" vs "성장이 배수를 설명하지 않는다".
독트린은 유형 : 경고문을 1:1 로 두므로, 하나로 합치면 그 분기가 **유형 안에 숨는다.**
§B 기준(해석 방법이 달라지는가)에 따라 **두 유형을 권한다.** 다만 최종 결정은 사람이다.

### 이 판정이 B3(임계값 재도출)에 갖는 함의

두 후보의 경계는 **기존 θ(5·15·3)를 그대로 쓴다.** 5~15 구간을 채우고 배당 조건을 반대로
읽는 것이므로 **새 임계값을 도출할 필요가 없다.** 즉 유형 추가만으로 64건이 분류된다.

단 새 유형의 오분류율은 **그 규칙에 실제로 도달하는 모집단에서** 재야 한다(θ_cyclical 교훈 —
전체를 분모로 잡으면 FP 가 작게 나온다).

## 3. 커버리지 효과 (추정 — 실측 아님)

두 유형 모두 막대축이 `annual_revenue` 이고 밴드가 PER 이다. **둘 다 이미 확보된 축**이라
분류가 되는 즉시 슬롯③ 이 그려질 가능성이 높다.

| 대상 | 현재 | 두 유형 추가 시(추정) |
|---|---|---|
| 오늘 덱 ③ | 1/10 | 최대 8/10 (미분류 7 중 7 + 기존 1) |
| 유니버스 ③ | 225/362 (62.2%) | 최대 289/362 (79.8%) |

**추정이다. A-3 과 같은 규칙으로 배포 후 `card-slot-coverage` 로 실측한다.**
매출 시계열이 없는 종목은 `no_bar_data` 로 떨어지므로 상한보다 낮게 나온다.
