# AUDIT — 공유·검색 메타 문구가 폐기된 포지셔닝을 광고한다

| 항목 | 값 |
|---|---|
| 접수 | 2026-08-15 · 배포 HTML 실측(병행 세션) |
| 범위 | `apps/fomo-web/app/layout.tsx`, `apps/fomo-web/app/manifest.ts` |
| 판정 | **부분 확인** — 접수 시 지목한 두 표현 중 **하나만 실제 결함** |
| 영향 | 링크 공유 카드·검색 스니펫·PWA 설치 화면 |

---

## 1. 무엇이 배포돼 있었나

```
description      : 스와이프로 투자 취향을 학습해 오늘의 테마와 종목을 쉽게 매칭하는 피드.
og:description   : 오늘 볼 만한 시장 테마와 종목을 넘겨 보고, 내 취향에 맞는 투자 정보를 쉽게 발견하세요.
og:title         : FOMO Club — 내 취향 투자 피드
manifest.name    : FOMO Club — 취향투자 발견
manifest.desc    : 스와이프로 투자 취향을 학습해 오늘의 테마와 종목을 쉽게 발견하는 피드.
```

접수 시 지목은 **"취향 학습"·"테마 매칭" 둘 다 v5 이전 포지셔닝**이었다.
`docs/PRODUCT_VISION.md` 를 읽어 대조한 결과 **그 판정의 절반은 틀렸다.**

## 2. 정본 대조 — 무엇이 폐기됐고 무엇이 아닌가

### ❌ "테마" — 진짜 결함이다

PRODUCT_VISION §3.2 가 명시적으로 폐기했다:

> ⚠️ **폐기**: v4의 "7종 카드(종목·테마·매크로·이벤트·내러티브·인물·…)를 한 피드에 비율로
> 섞는다"는 더 이상 정본이 아니다. **발견 표면은 종목 카드만.**

메타 문구는 **폐기된 v4 피드 구성을 그대로 광고하고 있었다.** 링크를 받은 사람은
"테마와 종목을 섞어 보여주는 앱" 으로 이해하는데, 발견 표면에 테마 카드는 없다.

### ✅ "취향" — 폐기된 적 없다. 건드리면 안 된다

| 근거 | 내용 |
|---|---|
| §1 한 줄 정의 | "종목을 스와이프하며 **'내 취향의 종목'**을 발견하고" |
| §2.2 핵심 철학 | 제목 자체가 **"취향은 자각하게 만드는 것"** |
| §7 | "매칭 — **취향** 유사도 사실까지만" |

**"취향" 은 v5 핵심 철학이다.** 이걸 빼면 정본에서 오히려 멀어진다.

### ⚠️ "조용한 돈" 으로 바꾸자는 제안은 채택하지 않았다

접수 시 "지금 제품은 '조용한 돈'" 이라고 했으나, **그 문구는 PRODUCT_VISION 에 없다.**
`조용한 돈` 은 quiet-pick 엔진이 만드는 **한 기능·표면의 이름**이지 제품 포지셔닝이 아니다.
제품 정의는 §1 **"주식시장의 틴더 — 캐주얼 투자 발견 앱"** 이다.
메타 문구를 "조용한 돈" 으로 바꿨다면 **다른 방향으로 정본을 이탈했을 것이다.**

### 누락 — 💎 조기 발견이 한 글자도 없었다

§1·§2.4 가 "뜨기 전의 신호(💎)를 남보다 먼저" 를 제품 가치의 축으로 놓는데
메타 문구에는 그 축이 **아예 빠져 있었다.** 지운 것보다 이게 더 큰 손실이다.

## 3. 고친 문구

```
description      : 종목을 스와이프하며 내 취향의 종목을 발견하고,
                   수급이 먼저 들어오는 순간을 사실로 확인하는 종목 카드 피드.
og/twitter:title : FOMO Club — 주식시장의 틴더
og/twitter:desc  : 종목을 넘겨 보며 내 취향의 종목을 발견하고,
                   수급이 먼저 들어오는 순간을 사실로 확인하세요.
manifest.name    : FOMO Club — 캐주얼 투자 발견
manifest.desc    : (description 과 동일)
```

근거: §1(한 줄 정의·틴더 비유) · §2.2(취향 유지) · §2.4(💎 복원) · §3.2(테마 제거).

**§5.1 예측 금지선을 메타 문구에도 적용했다.** "수급이 먼저 들어오는 순간을 **사실로 확인**"
까지만 쓰고 "곧 오른다 / 지금 안 사면 늦는다 / 급등 임박" 류는 쓰지 않는다. 공유 카드와
검색 스니펫은 **제품 밖에서 읽히는 문구라 금지선이 더 세게 걸린다** — 맥락 없이 단독으로 뜬다.

## 4. 바꾸지 않은 것

`apps/fomo-web/app/privacy/page.tsx` 에도 "취향" 이 여러 번 나오지만 **그대로 뒀다.**
그 문서는 포지셔닝이 아니라 **실제 수집 항목을 고지하는 법적 문서**다.
온보딩이 취향 선택을 실제로 수집하는 한, 문구를 손대면 **고지가 사실과 어긋난다.**

## 5. 남은 일

- **완료 판정은 정규 도메인 배포 후 공유 카드 실측이다.** 머지는 완료가 아니다.
  OG 캐시(카카오톡·슬랙·X)는 별도로 오래 남으므로 각 플랫폼 디버거로 강제 갱신이 필요할 수 있다.
- 이 감사는 **메타데이터만** 봤다. 온보딩·설정 등 앱 내부 문구에 폐기된 "테마 피드" 전제가
  남아 있는지는 보지 않았다.
