## 2. 판정 근거

### 2-1. WO 기준을 그대로 적용할 수 없었던 이유

WO-SUB-00 §4-3 의 판정 기준은 **"US-SMALL + KR-SMALL 분기 재무 확보율"** 이다.
그런데 실측 표본이 **US-SMALL 1종목 / US-MICRO 3종목**이다. 확보율이 낮은 게 아니라 **모수가 없다.**
1종목의 성패로 "확보율 0% 또는 100%"를 적는 것은 통계가 아니라 잡음이므로, **KR·US 를 분리 판정**한다.

> 이는 WO 가 정한 판정식을 바꾼 것이다. 근거는 위와 같으며, 원 기준으로 되돌리려면 **먼저 미국 유니버스를 늘려야 한다**(§4 참조).

### 2-2. KR — GO

| 기준 | 실측 | 판정 |
|---|---|---|
| 분기 재무 확보율 ≥ 90% | **97.8%** (44/45) | ✅ |
| 섹터/산업 분류 결측률 ≤ 5% | **2.2%** (44/45 확보) | ✅ |
| 밸류에이션 계산 가능(PER/PBR) | PBR 97.8% / PER 75.6% | ✅ |
| 5년 일별 종가 | 88.9% (40/45) | ✅ |
| 사업 설명 원문 | **97.8%** (44/45) | ✅ |

→ **PHASE 1~6 을 KR 유니버스에서 전면 착수할 수 있다.**

### 2-3. US — 조건부 GO

| 기준 | 실측 | 판정 |
|---|---|---|
| 롱테일 표본 수 | **4종목** | ❌ 판정 불가 |
| 대형주(CONTROL) 분기 재무 | 90.9% (10/11) | ✅ 소스는 정상 동작 |
| 사업 설명 원문 | 15/15 (전 그룹) | ✅ |
| EPS 컨센서스 | CONTROL 11/11 | ✅ |
| 5년 일별 종가 | **0/11** | ❌ 무료 경로 없음 |

**소스는 작동한다. 표본이 없을 뿐이다.** SEC XBRL·Nasdaq 은 대형주에서 정상 확보되므로, 미국 롱테일 종목이 유니버스에 늘어나면 같은 경로로 확보될 개연성이 높다 — 다만 **이는 검증되지 않은 추정이며, 표본이 확보된 뒤 재실사해야 한다.**

→ **US 는 PHASE 1(팩트시트) 착수 가능, PHASE 4(값 시각화)는 종목별 확보 여부로 게이팅**한다. 5년 종가가 없으면 밴드 백분위를 계산할 수 없으므로 US 는 `current_percentile = null` 이 기본값이 된다.

### 2-4. 컨센서스 — 보류

| 항목 | 실측 |
|---|---|
| Forward **매출** 컨센서스 | **전 그룹 0%** — Nasdaq·네이버 무료 경로에 필드 자체가 없음 |
| Forward **EPS** 컨센서스 | US CONTROL 11/11 / US 롱테일 0-1건 / KR **미확인** |

WO-SUB-00 판정 기준: *"컨센서스 확보율 40% 미만이면 WO-SUB-04 의 예상치 막대 구간을 선택적 기능으로 강등"*

→ **매출 컨센서스 0% 이므로 PHASE 4 의 "실적+컨센서스 막대" 설계는 그대로 구현할 수 없다.**
Leif 차트 형태(매출 막대 = 실적 진한색 + 예상 연한색)의 **예상 구간은 미국 대형주 EPS 에만 존재**한다.
대안은 WO-SUB-04 착수 시 결정한다(예: 실적 구간만 그리기 / EPS 축으로 치환 / 유료 소스 검토).

## 4. 이 판정이 드러낸, WO 밖의 선결 과제

**미국 유니버스가 4종목이다.** 배치 전체가 "롱테일 발굴"을 전제하는데, 실제 발행 카드에서 미국 롱테일이 사실상 없다.
이건 데이터 소스로 풀 수 없는 문제이며, 수급 신호 수집(openinsider 클러스터) 단계의 문제다.
**PHASE 4 의 A/B 를 미국 종목으로 돌리는 것은 현재 불가능하다.**
