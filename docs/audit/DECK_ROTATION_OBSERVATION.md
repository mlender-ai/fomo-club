# 덱 회전 3일 관측 (WO-DECK-01 완료조건 9)

> **완료 판정은 3일 연속 프로덕션 관측이다. 하루 보고 끝내지 않는다.**
> 판정 기준: **1페이지(1~3위) 종목이 매일 바뀐다.** 참고 목표: 1위 연속 유지 3일 이하.

## 매일 무엇을 어떻게 보나

```bash
gh workflow run quiet-pick-trigger.yml
```

크론이 이미 매일 돌므로 위 트리거는 즉시 확인이 필요할 때만 쓴다. 확인은 셋 중 아무거나:

| 수단 | 보는 것 |
|---|---|
| `quiet-pick-trigger` 워크플로 요약 | 회전율 블록 + 고착 알림 |
| `/admin/deck-rotation` | 1위 연속일 · **1페이지 누적 점유일** · 일별 회전율 |
| `GET /api/fomo/quiet-picks` → `rotation` | 원본 수치 |

`rotation.page1HeldOver` 가 **비어 있으면 그날 1페이지는 전부 교체됐다.**

> ⚠️ 조회 시각 주의 — 크론 직후 약 2분간 `/api/fomo/quiet-picks` 가 503(`EMAXCONNSESSION`)을 낼 수 있다.
> 별건이며 자가 회복한다. 503 을 "회전 실패" 로 기록하지 말 것.
