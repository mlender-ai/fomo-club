### ③ 진입 게이트가 무엇을 요구하는가 — `apps/web/lib/discovery-supply.ts:2529`

미국 종목이 카드가 되려면 셋 중 **하나**를 만족해야 한다.

```
(a) headline 이벤트가 volume_spike 또는 new_high     ← 거래량 각성 (지금 안 돔, 아래 B-2)
(b) 95개 큐레이션 시드에 들어 있고 verdict 존재       ← "아는 기업" 우회로
(c) 뉴스·공시 재료 + sourceLabel + URL 동시 확보      ← US 뉴스는 Vercel egress 차단
```

**(a)가 죽어 있고 (c)가 막혀 있으니, 실질적으로 (b)만 남는다.**
그래서 비큐레이션 451종목은 사실상 전부 탈락한다 — 동적 유니버스를 아무리 늘려도 여기서 막힌다.

## B-2 검증 — 거래량 각성이 왜 국·미 모두 0인가

**하드코딩된 국가 조건이 아니다. 순서가 뒤집혀 있다.**

```
discovery-supply.ts:2380   ranked = rankDiscoveryCandidates(candidates, { maxCandidates: 50 })
discovery-supply.ts:2390   dailyRows = ... ranked.slice(0, 50) 에 대해서만 일봉 조회
discovery-supply.ts:2449   ranked = attachReachedVolumeEvents(ranked, ..., dailyByTicker, ...)
```

`eventFromVolume` 은 **20일 평균 거래량 대비 1.8배**를 요구하는데(`discovery-supply.ts:1203`),
그 20일 거래량은 **일봉을 받아야** 알 수 있고, 일봉은 **이미 상위 50에 든 종목에만** 받는다.

> 즉 거래량 각성은 **발굴 사유가 아니라 선정 후 덧붙이는 라벨**이다.
> 거래량으로 종목을 끌어올릴 수가 없다. 국내도 같은 이유로 0이다.

WO B-2 체크리스트에 대한 답:

| 확인할 것 | 실측 결과 |
|---|---|
| 검출기가 국내 종목만 순회하나 | **아니다.** `eventFromVolume` 은 `row.country` 로 분기하지 않는다(라벨 문구만 다름) |
| 지수 데이터가 국내만 있고 미국이 없나 | **시장 역행에 지수를 안 쓴다.** 현 구현의 역행 판정은 Wyckoff(`spring`/`pullback`)로, 개별 종목 일봉만 쓴다 |
| 국가 조건이 하드코딩돼 있나 | **있다 — 검출기가 아니라 진입 게이트에.** `discovery-supply.ts:2529` (위 ③) |

**결론: 미국 지수 시계열(S&P500·나스닥)은 지금 구조에서 시장 역행에 필요하지 않다.**
필요한 것은 **일봉 조회 시점을 랭킹 앞으로 옮기는 것**이다.

출처 없는 서술을 통과시키는 변경이 아니다.

### D. 국가 상한·알림·대시보드

| 항목 | 어디 |
|---|---|
| 국가 상한 70% (넘치는 쪽을 뒤로 미룸 · 다른 국가 후보 없으면 그냥 채움 · **30장은 무조건 유지**) | `apps/web/lib/daily-30.ts` `COUNTRY_DECK_MAX_RATIO` |

| 미국 0장 **이틀 연속** 판정 + 국가별/신호별 집계 (읽기 전용 감사 라우트) | `lib/country-coverage.ts` · `api/fomo/ops/audit/country-coverage` |
| 알림 — 매일 06:45 KST 원장 조회 후 이슈 자동 생성 | `.github/workflows/us-coverage-monitor.yml` |

국가 상한은 **순서를 미루는 규칙이지 덱을 줄이는 규칙이 아니다.** 마지막 채움 패스가 상한을
내려놓고 30장을 채우며, 넘긴 사실은 `meta.countryMix.overLimit` 로 드러낸다(조용한 절단 금지).

### 성능 영향

| 단계 | 전 | 후 |
|---|---|---|
| `us-insider-cluster` (요청 경로) | **12.0초** | **~1콜** (HTML 1회 · 종목별 시세 조회 제거) |
| `us-market-prewarm` (크론) | ~4초 | **+최대 24초** (거래량 부트스트랩 예산 · `maxDuration` 60 안) |

`candles` + `basics` 27초는 그대로 남는다 — `discovery?country=US` 가 45초 마감을 넘기는
주된 이유다. 둘은 서로 독립이라 병렬화로 ~13초를 줄일 수 있지만 그러면
`api.nasdaq.com` 동시 요청이 8 → 16이 된다. **레이트리밋을 재보지 않고 올리지 않았다.**
US-02 범위 밖의 별건으로 남긴다(덱 공급 경로인 `daily-30` 은 마감 240초라 완주한다).
