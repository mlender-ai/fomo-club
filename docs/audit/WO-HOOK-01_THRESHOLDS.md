# WO-HOOK-01 θ 임계값 — 실측 근거

> WO-HOOK-01 §1-1: "θ는 실측 분포로 정한다. **감으로 정하지 않는다**."
> 이 문서가 그 근거다. 값을 바꾸려면 여기 표본을 다시 재고 이 문서를 같이 고친다.

| 항목 | 값 |
|---|---|
| 표본 | 정규 도메인 `GET /api/fomo/quiet-picks` 발행 덱 **10장** |
| 측정 시각 | 2026-08-22 (payload `date: 2026-08-22`) |
| 표본 한계 | **n=10, 발행 1일치.** `?date=` 파라미터는 무시되고 항상 최신분을 준다(실측) — 과거 덱을 API 로 못 받는다 |

## 2. 분포와 임계값

### 2-1. `RATIO_PCT` = 20.0 — B형 하한 (2026-08-24 개정)

> **개정 요약**: 10.0 → **20.0**. 아래 2-1-옛 의 논리는 그대로 유효하지만 **표본이 부족했다.**
> 08-24 에 공백 구간 한가운데(14.4)가 관측됐고, 그 값이 상세의 근거 하한(20) 아래라
> **카드는 히어로로 띄우고 상세는 근거로 안 치는 모순**이 드러났다.

#### 무엇이 잘못됐나

| | 임계 | 14.4% 를 어떻게 다루나 |
|---|---|---|
| 카드 `RATIO_PCT` | 10 | **52px 히어로 숫자** — 화면에서 가장 큰 것 |
| 상세 `VOLUME_SHARE_FLOOR` | 20 | **행을 만들지 않음** — 코드 주석: "20 미만은 소음" |

같은 필드(`volumePct`)에 임계가 둘이었다. 사용자가 카드에서 본 가장 큰 숫자가 확인하러 들어간
상세에서 **존재하지 않았다.** 앱이 자기 히어로 숫자를 스스로 근거로 안 친 것이다.

#### 왜 20 인가

1. **08-22 표본의 분류가 하나도 안 바뀐다.** 20 은 그때 관측 공백(2.5~22.7) **안**이다 —
   `{22.7, 28.1, 42.9, 75.6}` 가 B형인 것은 10 이든 20 이든 같다. 과거 판정을 뒤집지 않는다.
2. **상세 쪽 20 은 이미 실측 근거가 있다**(휴니드 0.5% 가 근거 행으로 올라온 사고).
3. 두 임계를 하나로 합치면 다시 갈릴 수 없다 — `depthSections.ts` 가 숫자를 복사하지 않고
   `RATIO_PCT` 를 **import** 하도록 바꿨다.

#### 08-24 표본 (n=7)

| 종목 | volumePct | 형 | 종전(10) | 지금(20) |
|---|---|---|---|---|
| 한글과컴퓨터 | 3.3 | A | A | A |
| **풍산** | **14.4** | **B** | **B — 히어로 14%** | **B 탈락** |
| 퍼스텍 | 0.3 | A | A | A |
| 셀바스AI | 0.2 | C | C | C |
| 휴니드 | 0.5 | A | A | A |
| 더블유씨피 | 25.8 | B | B | B (변화 없음) |
| 한화투자증권 | 6.4 | C | C | C |

**공백이 비어 보였던 것은 n=10 이어서였다.** 14.4 가 그 구간이 실재함을 보였고, 하필 그 값이
모순 구간에 있었다.

#### 곁들여 고친 것 — `상당 부분` 삭제

종전 하한 10 에서 10~25% 는 전부 `하루 거래량의 상당 부분을 사갔어요` 로 뭉뚱그려졌다.
그것은 후킹이 아니라 **말을 안 한 것**이다 — 14% 를 "상당 부분" 이라 부르면 사용자는 아무것도
알게 되지 않는다. 하한이 20 이 된 지금 전 구간이 구체적 분수를 말한다:
`≥45 절반` · `≥25 3분의 1` · `≥20 5분의 1`.

### 2-1-옛. `RATIO_PCT` = 10.0 — B형 하한 (2026-08-22 판정, 위에서 대체됨)

정렬한 `volumePct`:

```
0.2  0.2  0.3  1.1  1.5  2.5  │  22.7  28.1  42.9  75.6
                              └── 2.5 와 22.7 사이가 비어 있다
```

**분포가 두 덩어리로 갈리고 그 사이 구간(2.5 ~ 22.7)에 표본이 하나도 없다.** 임계를 이 공백
안 어디에 두든 분류 결과가 같다 — 즉 이 값은 **표본에 둔감**하다. 10.0 을 고른 것은 공백의
가운데쯤이면서 WO §5-2 카피 표의 하한(`< 10% → B형 미사용`)과 정확히 일치하기 때문이다.
두 독립적인 근거(관측 공백 · 카피 규칙)가 같은 값을 가리켰다.

### 2-2. `FLAT_PCT` = 2.0 — 정체 밴드

WO §4-1 이 `정체 (±2% 이내)` 로 **직접 고정**했다. 실측으로 유도한 값이 아니라 스펙 값이다.
표본에서 이 밴드 안은 2건(+0.07%, −1.26%)이다.

### 2-3. `QUIET_UP_PCT` = 3.0 — 소폭 상승 상한(역행으로 인정하는 최대 상승)

WO §4-1 은 `소폭 상승` 변형을 정의했지만 **상한을 주지 않았다.** 상한이 없으면 +15% 도
"주가는 조용한데"가 되어 역행이 거짓말이 된다.

정렬한 |신호 후 주가 변동|:

```
0.07  1.26  2.51  2.69  2.72  4.07  5.15  5.91  5.99  15.00
                          ↑ 중앙값 2.72
```

**중앙값 2.72% 를 반올림한 3.0 을 상한으로 둔다.** 근거: 이 덱에서 "전형적인 움직임"의 크기가
2.72% 이므로, 그 안쪽은 *이 종목군의 잡음 범위*이고 주가가 신호에 응답했다고 볼 수 없다.
바깥(+5.15 · +5.99 · +15.0)은 주가가 이미 응답한 것이라 역행이 아니다 → B/C 로 간다.

## 3. 적용 결과 (같은 표본)

| 형 | 종목 | 수 |
|---|---|---|
| A 역행 | 보성파워텍 · 퍼스텍 · 코난테크놀로지 · 솔트룩스 · 더블유씨피 · On Holding · Chiron | 7 |
| B 비율 | 한미약품(22.7) · Angel Studios(42.9) | 2 |
| C 희소성 | 셀바스AI | 1 |
| 제외 | — | 0 |

A형이 다수인 것은 의도한 결과다 — 역행이 이 제품의 유일한 후킹이고(§0-1), A 를 선택 규칙의
맨 앞에 둔 이유도 강해서가 아니라 **요구 데이터가 가장 까다로워서**다(뒤로 밀면 A 재료를 가진
종목이 B 로 새어나간다).

이 표본에서는 세 형 중 하나도 성립하지 않아 탈락한 종목이 **0건**이다. 탈락 경로는 살아 있고
(`drops.no_card_type`), 캔들이 얇아 그림 재료를 못 만드는 US 픽에서 실제로 발생한다.

## 4. 재측정 방법

```bash
curl -s "https://fomo-club-backend.vercel.app/api/fomo/quiet-picks" > picks.json
```

`picks[].signalFacts.volumePct`, `(price.current − signal.priceAtSignal) / signal.priceAtSignal`,
`signalFacts.isLongestStreak` 세 축의 분포를 다시 그린다. **공백 구간이 이동하면
`RATIO_PCT` 를, 중앙값이 이동하면 `QUIET_UP_PCT` 를 옮기고 이 문서를 같이 고친다.**

임계값 3개는 `packages/fomo-core/src/keyword-cards/card-type.ts` 상단에 상수로 있고,
`packages/fomo-core/__tests__/card-type.test.ts` 의 마지막 describe 가 위 분포와의 정합을
테스트로 고정하고 있다 — 값만 바꾸면 테스트가 깨진다.
