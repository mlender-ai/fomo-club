# LLM 유료 티어 비용 산출 (WO-SUB-03.5 PART C-1 부속)

> 요청: "LLM 유료 티어 비용을 산출해서 보고할 것. 결정은 나중에, 숫자만."

## 2. 종목당 토큰 (코드 실측 기반)

콜 수는 **종목당 3회**다 — 합성 1 + 검증 2(`synthesizeSlots` → `SYNTH_MAX_TOKENS`, 검증 2회 → `VERIFY_MAX_TOKENS`).

| 구분 | 근거 | 3,500자 | 24,000자 |
|---|---|---|---|
| 콜당 본문 토큰 | 영문 공시 ≈ 4자/토큰 | 875 | 6,000 |
| 콜당 프롬프트·스키마 | 고정 | ~300 | ~300 |
| **종목당 입력** | 3콜 | **~3,600** | **~18,900** |
| 종목당 출력(상한) | 500 + 300×2 | **1,100** | 1,100 |

출력은 `max_tokens` **상한**이라 실제는 그 이하다. 아래 비용은 상한을 썼으므로 **상한 견적**이다.

## 3. 비용

### 종목 1개

| 입력 크기 | 입력 비용 | 출력 비용 | 합계 |
|---|---|---|---|
| 3,500자 | $0.00212 | $0.00087 | **$0.0030** |
| 24,000자 | $0.01115 | $0.00087 | **$0.0120** |

### 배치 단위 (유니버스 285종목)

| 작업 | 3,500자 | 24,000자 |
|---|---|---|
| A/B 실험 (10종목 × 2조건) | \$0.03 | \$0.12 → **합 \$0.15** |
| 골든셋 30종목 1회 | \$0.09 | \$0.36 |
| 유니버스 285종목 1회 | **\$0.85** | **\$3.43** |
| 285종목 매일 (30일) | **\$26 / 월** | **\$103 / 월** |
| 285종목 주 1회 (4.3회/월) | \$3.7 / 월 | \$15 / 월 |

재합성은 입력 해시가 바뀔 때만 돈다(`needsResynthesis`). 공시는 분기마다 갱신되므로
**정상 운영은 "매일"이 아니라 "분기 + 신규 종목"에 가깝다** — 그 경우 월 비용은 위 표의 1/10 이하다.

## 4. 그래서 유료 티어가 사는 것은 비용이 아니라 **속도**다

```
비용:  285종목 전량 재합성 = 24,000자에서도 $3.43   ← 무시 가능
시간:  TPM 12,000 에서      = 약 11시간             ← 이것이 제약
```

무료 티어가 막고 있는 것은 지출이 아니라 **TPM 12,000**이다. 지금 골든셋 30종목 재실행이
90분 타임아웃에 걸린 것도(run 30678060170) 같은 원인이다 — 429 를 받을 때마다 호출 간격이
곱셈으로 늘어나 상한 30초까지 갔다.

필요 TPM 을 역산하면:

| 목표 | 3,500자 | 24,000자 |
|---|---|---|
| 285종목을 1시간에 | ~19,000 TPM | ~93,000 TPM |
| 285종목을 4시간에 | ~4,800 TPM | ~23,000 TPM |
| 골든셋 30종목을 15분에 | ~7,600 TPM | ~40,000 TPM |

**미확인 항목**: Developer 플랜의 TPM 이 공개돼 있지 않다. 위 표의 목표를 충족하는지는
계정을 올린 뒤 limits 페이지에서 읽어야 확정된다. 그 숫자를 모르는 상태로 "유료로 바꾸면
해결된다"고 쓰지 않는다.

## 5. 이 문서가 하지 않는 것

- 티어 결정을 하지 않는다.
- 입력 크기를 확정하지 않는다 — 그것은 C-1 A/B 실험의 일이고, 이 문서는 그 실험의
  **가격표**일 뿐이다(A/B 실험 자체는 $0.15 라 비용이 판단 근거가 되지 못한다).
