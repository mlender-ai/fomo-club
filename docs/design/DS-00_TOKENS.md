## 1. 두 가지 원칙

```
메인 카드 = 후킹      한 장면에 놀라움 하나. 텍스트를 최대한 없앤다.
상세 페이지 = 설득    근거를 쌓되 스캔 가능하게. 순서가 곧 논증이다.
```

이 원칙에 안 맞는 요소는 **크기를 줄이는 게 아니라 다른 화면으로 옮기거나 삭제**한다.

### 1-1. 존재하지 않는 기능의 UI를 만들지 않는다

현재 데이터로 채울 수 없는 것은 **자리도 만들지 않는다.**

| 있음 | 없음 (UI 만들지 말 것) |
|---|---|
| 훅 문장, 신호 근거 수치 | 주체 3분 (개인/기관/외국인 동시) |
| 스파크라인, 무효선 | 가격·거래량 구조 판정 |
| 회사 설명(벤더 요약) | 배경 후보 ("왜 사는가") |
| 시총·PER·EPS·PBR | 종목 고유 리스크 (대부분 미확보) |
| 최근 30일 재료 유무 | 5년 밴드 위치 (대부분 미확보) |
| 유형 리스크 템플릿 | 검증실 |
| 판단 원장 기록(발행일·당시가) | |

## 2. 색

앱은 **다크 전용**이다. 라이트 모드를 만들지 않는다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `bg` | `#000000` | 화면 배경 |
| `surface-1` | `#101010` | 카드 |
| `surface-2` | `#181818` | 카드 안 블록 |
| `border` | `#242422` | 구분선 (0.5px) |
| `text-1` | `#FFFFFF` | 본문·제목 |
| `text-2` | `#9A9A96` | 보조 |
| `text-3` | `#5A5A57` | 캡션·비활성 |
| `accent` | `#D4FF3F` | 결론 · 성적 · CTA (§2-1) |
| `accent-ink` | `#1A1A00` | accent 배경 위 텍스트 |
| `down` | `#7A7A76` | 하락 (빨강 쓰지 않음) |

### 2-1. accent 사용 규칙 — 가장 중요

> **accent 는 결론 · 우리 성적 · CTA 세 자리에 쓴다.**

기획자 모킹(2026-08-20) 기준으로 **개정했다.** 종전 문구는 "한 화면에 accent 는 한 곳(우리 성적)"
이었고 CTA 를 금지했다. 그대로 구현하니 화면 전체가 무채색으로 죽었다 — 결론이 눈에 먼저
닿지 않고, 채워진 버튼이 없어 다음 행동이 보이지 않았다.

| 자리 | 쓰는 이유 |
|---|---|
| **결론** (카드 `display`) | 이 카드에서 놀라운 것이 무엇인지 가장 먼저 닿아야 한다 |
| **우리 성적** (좌측 바 + 수익률) | 이 앱을 믿을 만한가에 대한 답 |
| **CTA** (`accent` 배경 + `accent-ink` 글씨) | 다음 행동. 화면에서 유일하게 채워진 버튼이다 |

> **[2026-08-23 개정 — 메인 카드는 예외]** WO-HOOK-01 이 메인 카드의 accent 를 **형별 1곳(그림)**
> 으로 바꿨다. 카드의 후킹·CTA·가격에는 accent 를 **쓰지 않는다.** 이유는 아래 두 가지다.
>
> 1. 카드가 3형이 되면서 각 형이 **자기 그림**을 갖게 됐다(A 누적선 · B 큰 숫자 · C 연속 막대).
>    그림이 후킹을 지므로 색이 그리로 가야 한다 — 위 개정("결론이 먼저 닿아야 한다")의 목적을
>    문장이 아니라 그림이 달성한다.
> 2. 우리 성적이 카드에서 상세로 내려갔다(WO-HOOK-01 §7-1). 마스킹된 카드에서 "8월 17일에
>    짚은 뒤"는 종목 정체를 암시하고, 남겨두면 accent 가 두 곳이 된다.
>
> 상세·성적표·덱 등 **다른 화면의 규칙은 그대로다.** 아래 표에서 메인 카드 행만 갈린다.

| 화면 | accent |
|---|---|
| 메인 카드 | **형별 1곳(그림)** — A 매수 누적선 · B 큰 숫자 · C 연속 구간 막대 (WO-HOOK-01 §7) |
| 상세 | 우리 기록의 수익률(좌측 바 포함). 상세에는 하단 CTA 가 없다 |
| 성적표 | 대표 지표 하나 |
| 지켜보는 중 · 헤더 · 덱 타이틀 · 하단 탭 | 없음 |

**여전히 accent 를 쓰지 않는 곳** — 스파크라인·차트(회색 `text-2` 선), 등락(상승 `text-1` /
하락 `down`), 근거 박스, 섹션 제목, 칩, 헤더 로고.

**성적이 없는 카드(오늘 첫 발행)는 성적 accent 가 없다.** 그건 정상이다. 색을 다른 데로 옮기지 않는다.

## 3. 타이포

| 폰트 | 용도 |
|---|---|
| Departure Mono | 티커, 종목코드, 수치, 라벨, 날짜 |
| Pretendard | 문장 전부 |

수치와 문장을 폰트로 분리한다. 이것이 "Living Terminal × Clean Sheet"의 실행 방식이다.

### 3-1. 스케일

| 이름 | px / weight / line-height / letter-spacing | 용도 |
|---|---|---|
| `display` | 24 / 500 / 1.32 / -0.02em | **결론 문장.** 카드당 1회 |
| `display-sm` | 22 / 500 / 1.32 / -0.02em | 상세의 결론 (DS-03 §4) — 카드보다 한 단 낮다 |
| `title-lg` | 20 / 500 / 1.32 / -0.01em | 덱 타이틀 (DS-02 §3) |
| `title` | 17 / 500 / 1.4 / -0.01em | 종목명, 섹션 제목 |
| `body` | 14 / 400 / 1.65 / 0 | 설명 문장 |
| `data` | 14 / 400 / 1.4 / 0 (mono) | 수치 |
| `label` | 12 / 400 / 1.4 / 0.04em (mono) | 라벨, 섹터 |
| `caption` | 11 / 400 / 1.5 / 0.02em | 출처, 주석 |

**11px 미만 금지. weight는 400과 500 두 개만.** — 아래 WO-HOOK-01 등재분에 예외 2건이 있다.

### 3-1-1. WO-HOOK-01 등재분 (2026-08-23)

메인 카드가 3형이 되면서 필요해진 단. 스케일은 닫힌 목록이 아니라 **화면 스펙이 요구하면
등재하고 쓴다**는 위 규칙에 따라 여기 올린다(등재 없이 임의 px 을 쓰는 것만 금지다).

| 이름 | px / weight / lh / ls | 용도 |
|---|---|---|
| `hook` | 19 / 500 / 1.35 / -0.02em | **카드 후킹 문장.** `display`(24)보다 작다 — 3형 전부 320px 2줄에 들어가야 한다 |
| `ratio` | 52 / **600** / 1 / -0.03em (mono) | B형 큰 숫자. SuperSignal 의 68점 자리다 |
| `ratio-line` | 16 / 500 / 1.4 / -0.01em | B형에서 큰 숫자를 문장으로 되읽는 줄 |
| `price` | 15 / 400 / 1.3 / 0 (mono) | 카드 가격. `data`(14)보다 한 단 크다 |
| `legend` | **10** / 400 / 1.4 / 0.02em (mono) | 그림 범례·캡션 전용 |

**예외 2건과 그 사유** — 규칙을 어긴 게 아니라 범위를 좁혀 허용한 것이다.

| 예외 | 어디까지 | 사유 |
|---|---|---|
| weight 600 | `ratio` **한 자리만** | 52px 에서 500 은 획이 가늘어 숫자가 물러난다. 이 숫자는 카드에서 가장 먼저 닿아야 하는 것이다 |
| 10px (11px 하한 위반) | `legend` — **그림 범례·캡션만.** 본문·라벨에 쓰지 않는다 | WO-HOOK-01 §4-2·§6-2 가 10px 로 지정. 범례가 11px 이면 두 줄이 되어 그림보다 커진다 |

> ⚠️ 10px 은 **가독성 하한을 의도적으로 넘긴 값**이다. 범례는 선 색 견본과 짝을 이뤄 보조로만
> 읽히므로 감수했지만, 이 예외를 다른 곳으로 넓히지 말 것. 넓혀야 할 이유가 생기면 하한 규칙
> 자체를 다시 논의한다.

색도 2개 등재했다(그림 전용 — 본문 텍스트에 쓰지 않는다).

| 토큰 | 값 | 용도 |
|---|---|---|
| `chart-line` | `#4A4A48` | A형 주가선. 누적선(accent)보다 한 단 물러나야 갭이 읽힌다 |
| `chart-bar` | `#252523` | C형 미매수·과거 매수일 막대 |

`display-sm`·`title-lg` 는 DS-02/DS-03 이 요구해 **추가한 단**이다. 스케일은 닫힌 목록이 아니라, 화면 스펙이 필요로 하면 이 표에 등재하고 쓴다 — 등재 없이 임의 px 을 쓰는 것만 금지다.

### 3-2. 문장 규칙

- 해요체 통일. `~하였음`, `~합니다` 금지
- 한 문장 최대 2줄. 3줄 넘으면 문장을 자른다
- 마침표: 본문에는 찍고, 라벨·제목·버튼에는 안 찍는다

## 4. 간격

4의 배수만 사용한다.

| 토큰 | px | 용도 |
|---|---|---|
| `s1` | 4 | 라벨-값 |
| `s2` | 8 | 인접 요소 |
| `s3` | 12 | 블록 내부 |
| `s4` | 16 | 카드 패딩, 블록 간 |
| `s5` | 24 | 섹션 간 |
| `s6` | 32 | 큰 구획 |

- 카드 패딩: `s4` (16px)
- 화면 좌우 여백: 20px
- 섹션 사이: `s5` (24px) + 0.5px 구분선

## 10. 미해결 (등재 시점)

- ✅ **폰트 에셋 완료(2026-08-21, DS-06 §6-2)**: Departure Mono 1.500(OFL)을 `apps/fomo-web/public/fonts` 에 넣고 `@font-face` 로 물렸다. CDN `@import` 를 제거했고 `mono` 스택 1순위가 Departure Mono 다 — **수치/문장 폰트 분리가 실현됐다.**
- **하드코딩 스윕(§8)**: 화면 단위로 진행한다. **메인 카드(DS-01)·픽 탭 셸과 덱(DS-02)·상세(DS-03)·성적표·내 기록(DS-04) 완료** — 해당 컴포넌트는 `ds` 토큰만 쓴다. 남은 화면(검색·기타)은 해당 DS 문서 도착 후. 지금 값만 바꾸면 미도착 스펙과 두 번 충돌한다.
- **lint 게이트(§8)**: 토큰 외 값 사용 시 실패시키는 규칙은 스윕이 끝난 화면 비중이 늘어난 뒤 켠다. 현재는 `ds` 토큰 ↔ 코드 드리프트 테스트 + 화면별 DS 테스트(`quietCardDs01.test.ts`, `quietDeckDs02.test.ts`, `e2e/quiet-card.spec.ts`, `e2e/quiet-deck.spec.ts`)로 지킨다.
