## 1. 목표

사용자가 카드를 보고 **2초 안에** 세 가지를 안다.

1. 무슨 일이 있었나 (결론)
2. 얼마나 드문 일인가 (근거 하나)
3. 이 앱을 믿을 만한가 (우리 성적)

**그 외 전부 상세로 내린다.**

## 3. 블록별 스펙

```

스포츠화 · $10.2B
```

| 요소 | 스펙 |
|---|---|

| 티커/종목코드 | `label` mono, `text-3`, 우측 정렬 |

### ④ 근거 한 줄

```
$4.0M · 2명 · 1년 매수 3건뿐
```

| 규칙 | 내용 |
|---|---|
| 스타일 | `label` mono 12px, `text-2` |
| 구성 | 최대 3항목, ` · ` 구분 |
| 우선순위 | 규모 → 인원 → 희소성 |

**칩(둥근 배지) 폐지.** 칩 3개는 각각 테두리를 가져서 시각 노이즈가 크고, 서로 다른 축인지 사용자가 알 수 없다. **한 줄 텍스트가 더 조용하고 더 빨리 읽힌다.**

- 같은 축의 항목을 두 개 넣지 않는다 (`거래량 30%` + `거래량 그대로` ✕)
- 결론에 이미 나온 수치를 반복하지 않는다

### ⑤ 스파크라인

| 항목 | 스펙 |
|---|---|
| 높이 | 56px |
| 선 | 1.5px, `text-2` (`#9A9A96`) |
| 면 채우기 | **없음.** 그라데이션 채우기 제거 |
| 마커 | 신호 시작 지점에 4px 원, `text-1` |
| 캡션 | **없음.** `◆ 사기 시작한 시점` 삭제 |
| 축·격자 | 없음 |

**캡션을 없애는 이유**: 마커 하나면 의미가 전달되고, 캡션이 있으면 텍스트가 한 줄 늘어난다. 상세에서 설명한다.

- 데이터가 20포인트 미만이면 **스파크라인 전체를 표시하지 않는다**

**표시 조건**

| 상황 | 표시 |
|---|---|
| 이전 발행 기록 있음 | 가장 오래된 발행일 기준 수익률 |
| 오늘 첫 발행 | **블록 전체 미표시.** 카드가 그만큼 짧아진다 |
| 발행일 가격 결손 | 미표시 |

## 8. DS-01 삭제 목록에 없었던 3건 — 판정 기록

DS-01 §2 의 6블록에 자리가 없으나 §4 삭제 목록에도 없던 요소들이다. **카드에서 빼되 상세로 옮겼다** — 지우는 것은 스펙에 없는 결정이라 하지 않았다.

| 요소 | 판정 | 옮긴 곳 |
|---|---|---|
| 재등장 사유 (`다시 올라온 이유 — …`) | 카드에서 제거. 오렌지색을 써서 DS-00 accent 규칙과도 충돌했다 | 상세 결론 바로 아래 (`depth-reentry`) |
| 이런 신호, 과거엔 어땠나 (`signalStats`) | 카드에서 제거 | 상세 §왜 지금인가 (이미 있었음) |
| 실체 한 줄 (`slots.substance`) | 카드에서 제거 | 상세 §무슨 회사인가 (신규 배선) |

되돌릴 근거가 있으면 이 표만 뒤집으면 된다.

## 9. 미해결 — 결정·데이터가 필요한 것

1. **결론 템플릿 미확정 (§3-③ 부록).** 문구 엔진(`buildQuietPickHook`)은 그대로 뒀다. 현재는 해요체 문장(`기관이 25일째 조용히 사고 있어요`)이 나오는데, 24px·줄당 14자에서 **2줄째가 `요` 한 글자로 떨어진다.** DS-01 이 제시한 명사형(`기관이 조용히 12일째 매수 중`)은 이 문제가 없다. 다만 명사형 결론은 DS-00 §3-2 "해요체 통일"과 충돌하므로, 부록 확정 시 **결론만 명사형 예외**로 둘 것인지 함께 정해야 한다.
2. **⑥ 우리 성적 데이터 부재.** `QuietPick.ourRecord` 필드와 렌더는 준비됐지만 백엔드가 값을 내려주지 않아 **항상 미표시**다(DS-01 §⑥ "오늘 첫 발행" 경로로 정직하게 동작). 종목별 최초 발행일·당시가를 발행 스냅샷에서 집계하는 작업이 선행이다. 사용자 개인 열람 기록(`discoveryPerformance.firstSeen*`)으로 채우면 안 된다 — "우리가 짚은 날"과 "당신이 처음 본 날"은 다른 사실이다.
3. **음수 수익률 색 (§⑥ 별도 결정 필요).** 지금은 스펙 문언대로 `-8.2%` 도 `accent`. `down` 회색 전환은 결정 대기.
4. **섹터 신뢰 가드 (§① · DS-05 대기).** 섹터 값이 있으면 그대로 표시한다. ONON=화학 같은 오류는 데이터 계층 문제라 카드에서 판별할 수 없다.
5. **로고 이니셜 폴백.** 로고는 제거했다. 다시 넣으려면 별도 스펙(32px 원형·흰 배경 금지·이니셜 폴백)이 필요하다.
6. **`N/10` 위치는 임시.** 덱 하단에 카운터만 남겼다 — 정본 배치는 DS-02.
7. **mono 폰트.** Departure Mono 에셋 미확보로 현재 mono 스택이 Pretendard 로 폴백한다(DS-00 §10). 수치/문장 폰트 분리는 에셋 셋업 후 완결된다.

1차 구현(8/19)은 **이 문서의 문구만 보고** 만들었고, 기획자가 제안한 화면(모킹)과 인상이 크게
달랐다. 지적받은 세 가지와 판정이다.

| 항목 | 1차 구현 (문서 문구) | 모킹 = 현재 구현 |
|---|---|---|
| 결론 색 | `text-1` 흰색 | **`accent`** — 화면에서 가장 먼저 닿는다 |
| 결론 문구 | 해요체 (`기관이 3일째 조용히 사고 있어요`) | **명사형** (`기관이 조용히 3일째 매수 중`) |
| CTA | `surface-2` + 0.5px 테두리 | **`accent` 배경 + `accent-ink` 글씨** |
| 근거 | 회색 한 줄 (`919주 · 거래량 평소의 25%`) | **`surface-2` 박스, 라벨(좌)-값(우) 3행** |
| 티커 | 우측 정렬 + `US`/`KR` 배지 | 종목명 옆에 나란히 |
| 결론 아래 | 없음 | **`주가는 3일간 -0.8%`** 한 줄 |
| 가격 | `4.945` (통화 불명) | **`$4.95` / `4,560원`** — 통화 기호 필수 |

### 왜 틀렸나 (같은 실수를 막기 위해)

- DS-00 §2-1 의 종전 문구("accent 는 화면당 1회, CTA 금지")를 **모킹보다 위에 뒀다.** 문구와
  그림이 어긋나면 그림이 정본이다 — DS-00 권위 행에 그 순서를 명시했다.
- 검증을 **스펙 항목 체크로만** 했다. "accent 노드가 2개인가" 는 통과했지만 "이 화면이 살아
  있는가" 는 아무도 보지 않았다.
- **데스크톱 폭을 한 번도 재지 않았다.** 375px 만 봤다(상세가 1280px 에서 양끝으로 벌어졌다 —
  DS-03 §12 에 수정 기록).

### 결론 문구 엔진

`buildQuietPickHook` 을 명사형으로 교체했다(§3-③ 표 기준). 실측 결과 전부 28자(2줄 × 14자) 안이다.

| 신호 | 결론 | 자수 |
|---|---|---|
| 임원, 1년 매수 ≤1건 | `1년 만에 임원이 처음으로 대량 매수` | 20 |
| 임원 3명 | `임원 3명이 닷새 새 함께 매수` | 18 |
| 기관, 창 내 최장 | `기관이 40거래일 중 가장 긴 25일 매수` | 23 |
| 기관 | `기관이 조용히 3일째 매수 중` | 16 |
| 외국인+기관 | `외국인과 기관이 나흘째 같이 매수` | 18 |

결론 요소에는 `break-keep`(한국어 단어 단위 줄바꿈)을 걸었다 — 없으면 `가장 긴 5` / `일 매수` 처럼 숫자와 단위가 갈린다.

모킹 표의 최장 문구(`기관이 40거래일 중 가장 길게 매수 중`)에 **일수를 넣었다.** 창(40)이 같은
종목이 덱에 여러 장 있으면 문장이 전부 같아져서다 — 한 화면에 같은 말 일곱 번은 소음이다
(반복도 CI 불변식이 이걸 잡았다).

payload 는 하루 한 번 구워지므로, 배치 전까지는 읽는 쪽(`pickHook`)이 해요체 결론을 같은
사실로 다시 만든다. 다음 배치 뒤에는 이 경로가 자동으로 꺼진다.

### 남은 차이 (데이터가 없어서 못 채운 것)

- 모킹 2행의 `시총 $10.2B · 일 거래 $180M` — 카드 페이로드에 시총·거래대금이 없다.
  `liquidityNote` 가 있는 종목만 `방산 · 시총 894억 · 일 거래 5.2억` 형태로 나온다.
- 모킹은 `-9%` 처럼 신호 후 하락폭이 크지만, 실제 값은 종목마다 다르다(그대로 쓴다).
