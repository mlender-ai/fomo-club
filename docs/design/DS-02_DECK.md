| 항목 | 값 |

## 3. ② 덱 타이틀

```
오늘의 조용한 돈  9곳
뉴스 나오기 전에 돈이 먼저 들어간 곳
```

| 요소 | 스펙 |
|---|---|
| 주 문구 | `title` 20/500, `text-1` |
| 개수 | 같은 크기, `text-1` — **accent 사용 금지** (성적과 경쟁) |
| 부제 | `caption` 12, `text-2` |
| 상하 여백 | 위 16px, 아래 20px |

- 현재 개수만 라임색인데, **그 색을 우리 성적에 넘긴다**
- 개수가 매일 달라지는 것은 정상이다 (덱 회전 결과). 숨기지 않는다

## 4. ③ 카드 영역

| 항목 | 스펙 |
|---|---|
| 좌우 여백 | 20px |
| 카드 폭 | 화면폭 - 40px |
| 배치 | 한 번에 한 장. 세로 중앙 정렬 아님 — **상단 정렬** |

### 4-1. 스와이프

| 제스처 | 동작 |
|---|---|
| 좌 스와이프 | 다음 카드 |
| 우 스와이프 | 이전 카드 |
| 탭 (카드 어디든) | 상세 진입 |

- 카드 전체가 탭 타겟. CTA 버튼은 시각적 힌트일 뿐 유일한 진입점이 아니다
- 스와이프 중 다음 카드가 8px 정도 미리 보이면 스와이프 가능함이 전달된다 (peek)
- 관성 스크롤 금지. 한 번 스와이프 = 한 장

### 4-2. 마지막 카드

마지막 장에서 좌 스와이프하면 **지켜보는 중 섹션으로 스크롤**된다. 별도 종료 화면을 만들지 않는다.

## 5. ④ 진행 인디케이터

```
· · ● · · · · · ·
```

| 항목 | 스펙 |
|---|---|
| 형태 | 점 (dot). `N/10` 텍스트 폐지 |
| 크기 | 비활성 4px `text-3`, 활성 6px `text-1` |
| 간격 | 8px |
| 위치 | 카드 아래 16px, 가운데 |

- **`9곳 남음` 텍스트 폐지.** 점으로 충분하다
- 카드 수가 12개를 넘으면 점 대신 `3 / 14` mono 텍스트로 전환

## 6. ⑤ 지켜보는 중

현재 이 섹션이 **제품에서 가장 정직하고 가장 안 읽히는 부분**이다. 제외 사유가 실제로 유용한 정보이므로 유지하되 압축한다.

| 요소 | 스펙 |
|---|---|
| 섹션 제목 | `title` 17/500, `text-1` |
| 개수 | 우측, `label` mono, `text-2` |
| 부제 | `caption`, `text-2` |
| 행 | 카드가 아니라 **구분선으로 나눈 리스트.** radius 없음, 0.5px `border` 하단 |
| 행 높이 | 최소 64px, 패딩 상하 12px |
| 종목명 | `body` 14/500, `text-1` |
| 종목코드 | `label` mono, `text-3`, 우측 |
| 사유 | `caption` 12, `text-2`, 최대 2줄 |
| 로고 | **제거** |

**개별 카드에서 리스트 행으로 바꾸는 이유**: 10개가 각각 둥근 카드면 시각 무게가 픽 카드와 비슷해져서 위계가 무너진다. 구분선 리스트는 조용하다.

- 기본 5개만 표시하고 `더 보기` 로 확장
- 행 탭 시 상세로 진입 (픽과 동일)

## 7. ⑥ 하단 탭

```
   픽          성적표         내 기록
   ──
```

| 항목 | 스펙 |
|---|---|
| 높이 | 56px + 세이프 에어리어 |
| 배경 | `bg`, 상단 0.5px `border` |
| 라벨 | `label` 12, 비활성 `text-3` / 활성 `text-1` |
| 활성 표시 | 라벨 아래 2px 바, 폭 16px, `text-1` |

- 아이콘을 빼는 이유: 3개뿐이고 라벨이 짧아서 아이콘이 정보를 더하지 않는다. 터미널 느낌과도 맞다
- 탭 영역은 각 1/3 폭 전체, 높이 56px

## 8. 스크롤 동작

| 영역 | 동작 |
|---|---|
| 헤더 | 고정 |
| 덱 타이틀 ~ 카드 | 함께 스크롤 |
| 지켜보는 중 | 이어서 스크롤 |
| 하단 탭 | 고정 |

- 헤더와 콘텐츠가 겹칠 때 헤더 하단에 0.5px `border` 등장
- 배경 블러 금지. 불투명 `bg`

## 9. 로딩 상태

| 상태 | 표시 |
|---|---|
| 로딩 | 카드 형태의 스켈레톤 1장. `surface-1` 배경에 `surface-2` 블록 3개. **애니메이션은 opacity 0.4↔0.7, 1.4s** |
| 실패 | `잠시 후 다시 열어주세요` + 재시도 버튼 |
| 스테일 (직전 페이로드) | 카드는 정상 표시 + 덱 타이틀 아래 `caption`으로 `N시간 전 기준` |

**스피너 금지.** 스켈레톤이 레이아웃 점프를 막는다.

## 10. 완료 기준

1. 헤더·덱 타이틀에 accent가 없다
2. `N/10`·`N곳 남음` 텍스트가 사라지고 점 인디케이터로 대체됐다
3. 지켜보는 중이 카드가 아니라 구분선 리스트다
4. 하단 탭에 아이콘이 없다
5. 카드 전체가 탭 타겟이다
6. 스켈레톤 로딩이 동작한다
7. 스테일 서빙 시 기준 시각이 표시된다

## 12. 스와이프 의미 변경 — 판정 기록

DS-02 §4-1 이 스와이프를 **탐색 제스처**로 재정의했다. 종전과 다르다.

| | 종전 | DS-02 |
|---|---|---|
| 좌 스와이프 | 넘김(패스) + 취향 신호 `less` | 다음 카드 |
| 우 스와이프 | **관심 저장 + 취향 신호 `more`** | 이전 카드 |
| 관심 담기 | 우 스와이프 또는 카드의 ★ | **★ 버튼만** |
| 마지막 장 이후 | "오늘 픽을 다 봤어요" 종료 화면 | 지켜보는 중으로 스크롤(종료 화면 폐기) |

- 우스와이프가 하던 **저장(사유·섹터 포함)과 `card_watchlist_add` 지표는 ★ 버튼이 이어받았다.** 기능이 사라진 게 아니라 입구가 하나로 줄었다.
- `recordTaste` 호출은 되살리지 않았다 — 그 함수는 이미 no-op(WO-M1 에서 폐기)이라 덱에서 부르는 것이 신호를 만들지 않았다.
- DESIGN.md §7(모션)의 "우=관심 / 상=슈퍼관심" 서술은 이 문서가 대체한다. 슈퍼관심(상 스와이프)은 원래 구현돼 있지 않았다.

## 13. 미해결 — 결정·후속이 필요한 것

1. **`title` 20px 은 DS-00 스케일에 없다.** DS-00 §3-1 은 `title` 17 / `display` 24 두 값만 둔다. DS-02 §3 이 지정한 20px 을 그대로 구현했으므로, **DS-00 에 `title-lg`(20) 를 추가할지** 아니면 덱 타이틀을 17이나 24로 맞출지 정해야 한다. 지금은 카드 안 `display`(24)보다 작아 위계는 지켜진다.
2. **peek 8px 은 스와이프 중에만 보인다(§4-1).** 앞뒤 카드가 같은 `surface-1` 이라 정지 상태에서는 8px 띠가 눈에 띄지 않는다. 드래그 중에는 앞 카드가 밀려 뒤 카드가 드러난다. 정지 상태에서도 보이게 하려면 뒤 카드에 별도 명도를 줘야 하는데, 그건 DS-00 §5(깊이는 배경 밝기 차이로만)와 상의가 필요하다.
3. **미사용 first-visit 고지 시트가 v1 네온을 쓴다.** `HomeView` 안의 `FirstVisitNoticeSheet` 는 현재 아무도 렌더하지 않는 죽은 코드다. 되살릴 계획이면 CTA 를 `surface-2`로 바꿔야 한다(DS-00 §2-1 CTA accent 금지). DS-02 범위 밖이라 손대지 않았다.
4. **`내 기록` 탭 내용은 DS 스펙 미도착.** 탭 셸만 DS-02 를 따르고, 안쪽(`KeywordHistory`)은 v1 스타일 그대로다. 성적표(`/track-record`)도 마찬가지 — DS-03~06 이 오면 정리한다.
5. **좌우 스와이프에 히스토리 개념이 없다.** 우 스와이프는 인덱스를 1 줄이는 단순 이동이다(첫 장에서는 무동작). 본 카드/안 본 카드 구분은 두지 않았다.
