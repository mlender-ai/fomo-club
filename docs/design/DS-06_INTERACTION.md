# DS-06 — 인터랙션 · 앱 출시 요건

| 항목 | 값 |
|---|---|
| 선행 | DS-00 ~ DS-05 |
| 전제 | **앱 출시.** 웹은 같은 스펙을 중앙 정렬로 재사용 |
| 상태 | **v2 정본 (2026-08-21 등재·구현).** 웹(`apps/fomo-web`) 적용 완료 · 네이티브 셸은 미착수 |

---

## 1. 인터랙션 원칙

> **누르고 싶게 만드는 건 장식이 아니라 반응 속도다.**

애니메이션을 더하는 게 아니라, **탭에 즉시 반응**하고 **레이아웃이 점프하지 않게** 하는 것이 심리스함을 만든다.

## 2. 탭 피드백

| 대상 | 반응 |
|---|---|
| 카드 | `scale(0.985)`, 120ms `ease-out`. 배경 변화 없음 |
| 버튼 | `scale(0.97)` + 배경 변화 |
| 리스트 행 | 배경 `transparent` → `surface-1`, 즉시 |
| 관심(★) | `scale(1.15)` 후 복귀, 180ms |

모든 탭에 **햅틱 light**, 관심 등록만 **medium**.

## 3. 카드 전환

수평 슬라이드 260ms · `cubic-bezier(0.32, 0.72, 0, 1)` · peek 8px · 드래그 임계 **카드 폭 25% 또는 속도 0.5px/ms** · 미달 시 원위치 200ms. **관성 금지 — 한 번 스와이프 = 한 장.**

## 4. 상세 진입/이탈

진입 하단→위 300ms, 이탈 역방향 260ms, 좌측 엣지 스와이프 백, **헤더는 진입 즉시**(카드 데이터 재사용), 본문만 스켈레톤. 전체 로딩 화면 금지.

## 5. 스크롤

iOS 바운스 유지 · Android 글로우 제거 · 스크롤바 숨김 · 헤더 경계선은 `scrollY > 8px` 에서 160ms 페이드 인 · 상세에서 뒤로 시 덱 위치 유지.

## 6. 앱 출시 요건

### 6-1. 레이아웃
세이프 에어리어 상하 준수(하단 탭은 세이프 아래까지 배경 연장) · 최소 320px(결론 3줄 금지) · 최대 **콘텐츠 480px 중앙 정렬** · **다크 전용 강제**.

### 6-2. 폰트
Departure Mono·Pretendard **번들 포함**, 웹폰트 지연 로딩 금지, FOUT 방지.

### 6-3. 스플래시
`FOMO CLUB` 텍스트만, 애니메이션 없음, 최대 1.5초 → 스켈레톤.

### 6-4. 앱 아이콘
검정 배경 + 라임 마크. 그라데이션·그림자 금지.

### 6-5. 심사 대응
면책 고지 1회 · 데이터 출처 명시 · **목표가·매매 의견 없음** · 유사투자자문 법무 검토 · 개인정보 저장 위치 명시.

### 6-6. 성능
콜드 스타트 → 첫 카드 2.5초 · 스와이프 60fps · 상세 헤더 즉시/본문 1초 · 초기 경로에 무거운 의존성 금지.

## 7. 접근성

대비(`text-3` 는 캡션 전용, 본문 금지) · 최소 11px · 터치 44×44 · 다이내믹 타입 · 카드 전체 스크린리더 라벨 · `prefers-reduced-motion` 시 전환 0.

## 8. 완료 기준

1. 모든 탭에 햅틱과 scale 피드백이 있다
2. 카드 전환이 60fps다
3. 상세 진입 시 헤더가 즉시 뜬다
4. 세이프 에어리어를 침범하지 않는다
5. 320px 폭에서 결론이 3줄이 되지 않는다
6. 폰트가 번들에 포함되어 FOUT이 없다
7. `text-3`가 본문에 쓰이지 않는다
8. 모션 감소 설정이 동작한다
9. 콜드 스타트 2.5초 이내

### DS-00 §10 이 닫혔다 — Departure Mono

DS-00 부터 `mono` 스택이 Pretendard 로 폴백해 왔다("수치는 mono, 문장은 Pretendard" 분리가 미완).
공식 배포본(1.500, OFL)을 `public/fonts` 에 넣고 `@font-face` 로 물렸다. 실측에서 `065450`·
`3,035원`·`평소의 57%` 가 픽셀 모노로 렌더된다. 라이선스 원문도 함께 뒀다.

### 실측으로 잡은 결함 — `border-hairline` 이름 충돌

`borderWidth.hairline`(0.5px)과 레거시 `colors.hairline`(#2A2A2A)이 **같은 클래스명**을 만들어,
`border-b-hairline border-ds-border` 로 쓴 곳의 색이 전부 `#2A2A2A` 로 덮여 있었다. DS 화면의
경계선 색이 조용히 어긋나 있던 것이다. 폭 토큰을 **`hair`** 로 바꿔 충돌을 끊었다
(`border-t-hair` / `border-b-hair`). 레거시 화면의 `border-hairline`(색)은 그대로 둔다.

## 10. 미해결 — 네이티브 셸이 필요한 것

1. **햅틱은 웹에서 반쪽이다.** Android 는 `navigator.vibrate` 로 동작하지만 **iOS Safari 에는 API 가 없다.** `impactLight`/`CONTEXT_CLICK` 은 네이티브 셸(`apps/fomo-club`)에서 `lib/haptics.ts` 구현만 바꿔 붙인다.
2. **스플래시(§6-3)·앱 아이콘(§6-4)** — 네이티브 셸 작업이다. 웹에서는 스켈레톤이 그 역할을 겸한다(전체 로딩 화면이 없다).
3. **60fps 측정(§완료 기준 2)** 은 실기기에서 재야 한다. 이 환경(백그라운드 탭)에서는 CSS 전환·타이머가 멈춰 프레임을 못 센다 — 전환 시간·이징 값과 "관성 없음" 만 코드로 고정했다.
4. **iOS 스와이프 백은 브라우저 제스처와 겹친다.** 웹에서는 좌측 24px 드래그를 직접 처리하지만, 네이티브에서는 OS 제스처에 맡기는 것이 맞다.
5. **다이내믹 타입(§7)** — 본문 ±2단계는 미구현. `rem` 기반이라 브라우저 폰트 크기 설정은 따라가지만, 결론 2줄 상한과 함께 검증하지 않았다.
6. **유사투자자문 법무 검토(§6-5)** — 코드로 할 수 없는 항목이다. 목표가·투자의견이 화면에 없다는 것은 테스트로 고정했다(전 DS 화면 스캔).
7. **Pretendard 는 subset 이 아니라 전체 woff2**(766KB + 778KB)다. 동적 서브셋(unicode-range 분할)으로 줄이는 것은 후속 작업.
