# WO-SUB-05 축 커버리지 사전 확인 (WO-SUB-03.5 PART E-2)

| 항목 | 값 |
|---|---|
| 확인일 | 2026-07-29 |
| 입력 | `docs/fundamentals/COVERAGE_dashboard.md` (KR 40 / US 16 실측) |
| 성격 | 시뮬레이션 — `WO-SUB-05` 구현 전 |

> WO 지시: *"결과가 KR 다수에서 `N/A` 라면, 05의 4축 설계 자체를 재검토해야 한다."*

---

## 0. 결론 — 축이 비는 게 아니다. **얇다.**

WO-SUB-03.5 는 "사업 체력 축이 KR 다수에서 N/A" 를 전제했다. **실측은 다르다.**
`WO-SUB-05` 강제 규칙 1(근거 2개 이상, 미달 시 `판정 불가`) 기준으로 계산하면
KR 에서 **95% 가 등급을 받을 수 있다.** 문제는 다른 데 있다.

## 1. 사업 체력(fundamentals) 축의 근거 후보

`WO-SUB-05` §4축 표: *"매출·이익·마진이 어느 방향인가 ← PHASE 1 팩트시트"*

| 근거 후보 | KR (n=40) | US (n=16) |
|---|---|---|
| `growth.revenue_yoy` | **95%** (38/40) | 81.3% (13/16) |
| `margin.operating_ttm` | **95%** (38/40) | 56.3% (9/16) |
| `margin.trend_8q` | **0%** — 8분기 필요, 네이버 5개 | 사용 가능(8분기 확보) |
| `margin.operating_stdev_8q` | **0%** | 50% |
| `growth.revenue_cagr_3y` | **0%** — 연간 4개 필요, 네이버 3개 | 68.8% |

**근거 2개 이상 확보율: KR 95% / US 81%.** 축은 계산된다.

## 2. 그런데 KR 은 **전 종목이 같은 2개 근거를 받는다**

KR 에서 확보되는 근거는 항상 `revenue_yoy` + `operating_ttm` 뿐이다. 이게 뜻하는 것:

| | 결과 |
|---|---|
| 등급 산정 | 가능 (근거 2개 = 최소 요건 정확히 충족) |
| 근거의 다양성 | **없음** — 40종목이 동일한 두 지표로만 판정된다 |
| 방향성 정보 | **없음** — `trend_8q` 가 0% 라 "마진이 개선 중인가"를 말할 수 없다 |
| 변동성 정보 | **없음** — `stdev_8q` 0% |
| 중기 성장 | **없음** — `cagr_3y` 0%. 1년 YoY 만 있다 |

즉 KR 의 사업 체력 등급은 **"최근 1분기 매출 증감 + 현재 영업이익률"** 두 점으로 결정된다.
`WO-SUB-05` 예시가 요구하는 형태 —
> `· 매출이 8분기 중 5분기 전년 대비 감소` / `· 영업이익률 12.4% → 8.1% (2024Q2 → 2026Q1)`

— 는 **둘 다 KR 에서 만들 수 없다.** 전자는 8분기, 후자는 추이가 필요하다.

## 3. 04·05 설계에 주는 함의

**축을 없앨 이유는 없다.** 95% 가 등급을 받는다. 다만 다음을 인지하고 설계해야 한다.

1. **근거 문장의 형태가 시장별로 달라진다.** US 는 추이 서술("12.4% → 8.1%")이 되고
   KR 은 시점 서술("영업이익률 4.7%, 매출 전년동기 +11.7%")이 된다. 템플릿을 하나로 두면
   KR 에서 빈 슬롯이 생긴다
2. **변별력을 점검해야 한다.** 두 지표로만 판정하면 등급 분포가 뭉칠 수 있다.
   구현 시 KR 등급 분포를 확인하고, A/B/C 가 실제로 갈리는지 봐야 한다
3. **DART 가 열리면 이 절이 무효가 된다.** 8분기·5개년이 확보되면 US 와 같은 형태가 된다

## 4. 다른 세 축

| 축 | 입력 | KR 확보 | 비고 |
|---|---|---|---|
| 수급·타이밍 | 기존 수급 엔진 | 문제 없음 | 이 배치와 무관 |
| **값의 위치** | 밴드 백분위 | **0%** | 실공시일 부재로 유효 관측 10~25% → `sufficient: false` |
| 걸린 리스크 | WO-SUB-06 | 유형 템플릿은 가능 | 종목별 고유 리스크는 DART 의존 |

**'값의 위치' 축이 KR 에서 실제로 0% 다.** 사업 체력이 아니라 이 축이 재검토 대상이다.
`WO-SUB-05` 4축 중 하나가 KR 전 종목에서 `판정 불가` 로 나온다.

## 5. 04 착수 전 결정이 필요한 것

- `WO-SUB-04`(값의 상태 시각화)는 밴드 백분위를 전제한다. **KR 0% 면 04 의 KR 렌더가 비어 있다.**
  DART 없이 04 를 착수하면 US 16종목용 화면을 만드는 것이다
- 대안: KR 은 밴드 대신 **네이버가 주는 PER/PBR 현재값 + 컨센서스 예상 막대**로 구성 가능
  (WO-SUB-01 실측: KR 매출 컨센서스 52.5%·EPS 55% 확보). 이건 "값의 위치"가 아니라
  "값과 예상"이라 축의 의미가 바뀐다 — **제품 결정 사항이다**
