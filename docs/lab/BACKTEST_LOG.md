# 백테스트 기록 — STRATEGY LAB

> **진 결과를 기록으로 남기는 게 이 랩의 존재 이유다.**
>
> 여기에 적힌 것은 지우지 않는다. 파라미터를 바꿔 다시 돌리면 **새 항목을 추가**하고,
> 옛 항목은 그대로 둔다 — 몇 번 바꿔 가며 돌렸는지가 곧 다중 비교의 N 이다.

## 2026-09-19 · 1차 백테스트

| 항목 | 값 |
|---|---|
| 데이터 | 2023-09 ~ 2026-09 · **3.0년** · 26,315봉 × 3종목(H1) · 구멍 0 |
| 검증 구간 | 2024-09 ~ 2026-09 (**앞 1년은 학습**, 저장하지 않음) |
| 전략 | 추세 스윙 v1 · 평균회귀 v1 · 고래 추종 v1 |
| 후보 | **12개** (전략 + 파라미터 조합) |
| 체결 | 무레버리지 · 수수료·슬리피지·펀딩비 반영 |

### 결과

| 전략 | CAGR | MDD | C/M | 승률 | 거래 | 판정 |
|---|---|---|---|---|---|---|
| BTC 보유 *(기준)* | +37.2% | −53.0% | **0.70** | — | — | — |
| 추세 스윙 v1 | +1.3% | −4.3% | 0.30 | 35% | 80 | **기준 미달** |
| 평균회귀 v1 | +3.9% | −26.2% | 0.15 | 58% | 388 | **기준 미달** |
| 고래 추종 v1 | 0.0% | 0.0% | — | — | 0 | **데이터 없음** |

**1위가 우연일 확률 약 99%.**

### 판정

> **벤치마크를 이긴 전략 0개. 이 검증으로는 어느 것도 실전 투입 불가.**

우연 확률이 99%라 **순위를 매기는 것 자체가 의미 없다.** 화면도 번호를 주지 않는다.

추세 스윙의 낙폭 −4.3% 는 얕아 보이지만 **안전한 게 아니라 거의 안 나간 것**이다 —
2년에 80거래, CAGR +1.3%. 같은 기간 BTC 를 그냥 들고 있으면 +37.2%였다.

### 고래 추종이 0거래인 이유 — 전략 탓이 아니다

Hyperliquid `clearinghouseState` 는 **현재 포지션만** 준다. 과거 이력 API 가 없다.
그래서 `WhalePosition` 은 수집을 시작한 시점부터만 쌓인다:

```
백테스트 구간    2024-09 ~ 2026-09
고래 데이터      2026-09-17 ~        (수집 시작일)
구간 내 표본     0건
```

`whale_flow` 지표는 자료가 없으면 `null` 을 내고, **null 인 조건은 통과하지 않는다**.
그래서 진입이 한 번도 없었다. 임계(`min_usd`)를 낮춰도 달라지지 않는다.

**처리:** 화면에서 `종료` 가 아니라 `데이터 없음` 으로 표시한다(LAB-FIX2 PART B-3).
과거 이력을 구할 방법이 없으므로 **고래 전략은 페이퍼로만 검증한다.**

### 다음

| # | 할 것 | 왜 |
|---|---|---|
| ① | 고래 전략을 페이퍼 전용으로 돌린다 | 과거 데이터가 존재하지 않는다 |
| ② | 데이터 3년은 확보됨 — **더 긴 구간**을 볼지 결정 | 크립토 3년도 사이클 하나가 안 된다 |
| ③ | 진입 규칙 재설계 | 청산을 바꿔도 수익률이 안 움직였다(LAB-09) |

**②는 데이터 문제가 아니라 판단 문제다.** Binance 현물은 2017년부터 받을 수 있다.
다만 그 구간을 넣으면 검증 구간이 달라져 지금까지의 숫자와 비교가 끊긴다 — 광혁이 정한다.

### 하지 않은 것

**파라미터를 다시 돌리지 않았다.** 결과가 나쁘다고 조합을 더 시도하면 후보 N 이 늘고,
그만큼 1위가 우연일 확률이 올라간다. 이미 12개에서 99%다.

## 2026-09-22 · 전략 3종 폐기 (LAB-BRIDGE 0-3)

**추세 스윙 v1 · 평균회귀 v1 · 고래 추종 v1 — `STOPPED`.**

새 결과가 나와서가 아니다. **랩의 역할이 바뀌었다.**

```
FCE   엔진. 전략 실행 · 페이퍼 체결 · 리스크 · 지갑 심사
LAB   창구. FCE 가 하는 것을 보여준다
```

랩이 고래 추종을 `데이터 없음` 으로 띄우고 있는 동안, FCE 에서는 같은 이름의 트랙이
**N=71 로 돌고 있었다.** 같은 것을 두 번 만들고 있었던 것이다.

### 지운 것 — 없다

| | |
|---|---|
| `Strategy.status` | `RUNNING`/`DRAFT` → **`STOPPED`** + 사유 |
| `Run` · `Trade` · `Equity` · `Metric` | **그대로** |
| 백테스트 보관함 화면 | **그대로** — 이제 `폐기` 로 표시된다 |

진 결과를 지우면 다음에 같은 걸 또 만든다. 그리고 이긴 것만 남은 표는 생존 편향
그 자체다. 위 1차 백테스트 판정(**우연 확률 99% · 벤치마크를 이긴 전략 0개**)이
이 폐기의 근거다.

### 폐기 시점에 열려 있던 것

추세 스윙 v1 이 `SOL 롱` 을 하나 들고 있었다(진입 115.95 · +1.75% · 28시간).
**청산하지 않았다.** 거기서 멈춘 것이 사실이고, 마지막에 유리한 값으로 닫아주면
기록이 좋아진다.

### 같이 끈 것

| | 왜 |
|---|---|
| 러너의 `paper` 잡 | 돌릴 전략이 없다 |
| `lab-collect` 의 페이퍼 크론 | 같음. 켜두면 매시 아무것도 안 하고 `/data` 에 초록 줄만 쌓는다 |

`paper-tick` 은 `status in (RUNNING, DRAFT)` 만 고른다. 랩이 다시 전략을 돌리게 되면
크론의 `#` 만 떼면 된다.

### 보류 — 폐기가 아니다

**랩의 백테스트 엔진은 지우지 않는다**(지시서 0-3 "보류"). FCE 것과 중복이지만,
FCE 에는 **백테스트 루프가 없다**(`docs/lab/FCE_INVENTORY.md`). 무엇을 남길지는
중복을 확인한 뒤 판단할 일이다.
