## 다중 비교 확률 — 계산 방법 (PART D-1)

구현은 `packages/lab/src/multiple-comparison.ts`. **순수 함수**라 화면과 무관하게 검증된다.

### 1. 단일 검정 p값

전략 하나의 연율화 샤프 `S` 를 `T` 년 관측했을 때, 샤프의 표준오차가 대략 `1/√T` 이므로

```
t = S × √T
p = 1 − Φ(t)        (단측, Φ 는 표준정규 누적분포)
```

### 2. 가족단위 보정 — Šidák

전략 `N` 개가 **전부 무능**하다는 귀무가설에서, 그중 **적어도 하나**가 이만큼 좋아 보일 확률:

```
P = 1 − (1 − p)^N
```

이것이 화면에 나오는 **"1위가 우연일 확률"** 이다.

`N` 이 커지면 같은 성적이라도 `P` 가 커진다 — **전략을 많이 돌릴수록 1위를 믿기 어려워진다**는
사실이 수식에 그대로 있다. `LAB-00` §7 의 "전략 5개 이하" 가 같은 이야기다.

실측에서도 그대로 나온다: 전략 3개일 때 79% → 4개일 때 **88%**.

### 3. 표본 규칙

거래 `MIN_SAMPLE`(30)건 미만인 전략은 **순위와 검정에서 뺀다**(LAB-00 §7).
전부 표본 부족이면 확률이 **`null`** 이다 — **0% 라고 말하지 않는다.**
0% 는 "우연이 아니다" 라는 주장이고, 모르는 것과 다르다.

### 4. 이 방법의 한계 — 적어둔다

- **전략들이 독립이라고 가정한다.** 같은 종목·같은 기간을 도는 전략은 실제로 상관돼 있어
  Šidák 은 `P` 를 **과대평가**한다(보수적이다). 보수적으로 틀리는 쪽이 낫다 —
  1위를 과신하지 않게 된다.
- 수익률 정규성을 가정한다. 크립토는 꼬리가 두꺼워 실제 p값은 이보다 클 것이다.
- 샤프의 표준오차 `1/√T` 는 근사다. 자기상관이 있으면 더 크다.

> **정확한 방법론보다 존재하는 게 중요하다.** 없으면 스스로를 속인다(PART D-1).

## 표 (PART B)

| 순위 | 전략 | CAGR | MDD | **C/M** | 샤프 | 승률 | 거래 |
|---|---|---|---|---|---|---|---|

- 정렬은 **`C/M` 내림차순.** 수익률 순위는 레버리지가 이긴다(`LAB-00` §7)
- **벤치마크는 항상 표 맨 아래**, 2px 구분선으로 나눈다
- 표본 30 미만은 순위 없이 `표본 부족` 표시
- 종료된 전략은 **회색으로, 순위 없이, 맨 아래** — **진 걸 지우면 전부 거짓이 된다**
- 행을 누르면 자산곡선이 바뀐다. 선택은 **URL 쿼리**(`?run=`)라 새로고침·링크로 남는다

### 벤치마크를 가짜 전략으로 만들지 않았다

`Benchmark` 테이블 시세로 **직접 계산**한다. 가짜 `Strategy` 행을 만들면
언젠가 순위에 낀다. 벤치마크는 전략이 아니다.

## 기간 (PART E)

`전체` · `최근 3년` · `최근 1년`.

> **기간을 바꾸면 순위가 바뀐다. 그게 정보다.**

그래서 **구간 안에서 지표를 다시 잰다.** 저장된 `Metric` 은 Run 전체 구간의 값이라
그대로 보여주면 단추를 눌러도 숫자가 안 바뀌고, 그러면 위 문장이 거짓이 된다.

두 가지를 구간 기준으로 다시 계산한다:

| 항목 | 왜 |
|---|---|
| 기준 자본 | 구간 **첫 자산값**. Run 초기 자본으로 재면 구간 앞의 손익이 섞인다 |
| 낙폭 | 구간 안 고점 기준. 저장값은 Run 전체 고점이라 구간에 없던 고점이 낙폭을 만든다 |

실측: 전체 기간 1위는 `눌림 매수`(C/M 0.20), **최근 1년 1위는 `거래량 돌파`**(0.07).
나머지 넷은 1년 구간에서 거래가 30건 미만이 되어 순위를 잃는다.
벤치마크도 +37.3% → **−33.2%** 로 뒤집힌다.

## 자산곡선 (PART C)

인라인 SVG. **차트 라이브러리를 넣지 않았다** — 선 두 개에 라이브러리는 과하고,
라이브러리는 대개 채우기·애니메이션·그림자를 기본으로 켠다(PART G-1 금지).

| 항목 | 구현 |
|---|---|
| 선 | 선택 전략(`--accent`) + 벤치마크(`--text-faint` 점선) |
| 채우기 | 없음 |
| 격자 | 최고·0·최저 세 줄뿐 |
| 구간 | **검증 구간만** — 학습 구간은 애초에 DB 에 없다 |
| 높이 | 240px |

### 선을 끊는 규칙

`packages/lab/src/curve.ts` `splitCurveSegments` — **순수 함수**.
조각마다 별도 `<path>` 라 끊긴 곳이 이어지지 않는다.

이웃 간격이 **중앙값의 2배**를 넘으면 자른다. 봉 주기를 인자로 받지 않는다 —
받으면 호출자가 틀린 주기를 넘길 수 있고, 그러면 멀쩡한 선이 조각나거나 **구멍이 이어진다.**

**한계:** 간격의 절반 이상이 구멍이면 중앙값이 구멍 위에 앉아 일부를 놓친다.
실제 자산곡선은 점이 수천 개라 그 상황이 오지 않지만, 테스트가 이 성질을 박아뒀다.

실측 확인: BTC 1시간봉에서 2주(336봉)를 지우고 백테스트를 다시 돌리자
선이 **2조각**으로 갈라지고 범례에 그 사실이 표시됐다.
