## PART B-2 — 청산 조건은 화면 밖으로 나가지 않는다

| 보여준다 | 보여주지 않는다 |
|---|---|
| 진입가 · 현재 손익 · 보유 기간 · 청산 **후** 결과(`exitReason`) | 목표가 · 손절선 · 청산 조건 |

혼자 쓰는 단계지만 **한 번 새면 되돌릴 수 없어서** 경계를 지금 만들었다.

문제는 저장된 포지션 객체(`OpenPosition`)에 `stopPrice`·`targetPrice`·`maxHoldBars` 가
**같이 들어 있다**는 것이다. 그대로 내보내면 아무도 눈치채지 못한다. 그래서:

1. `toLivePosition`(`packages/lab/src/live-view.ts`)이 **칸을 하나씩 옮긴다.**
   `{ ...position }` 을 쓰지 않는다 — 스프레드는 오늘의 칸만 여는 게 아니라
   **내일 추가될 칸까지 자동으로 연다.**
2. `findForbiddenKeys` 가 나가는 JSON 전체를 훑는다. `/api/lab/live` 는 하나라도
   나오면 **500 을 낸다.** 조용히 지우지 않는다 — 지우면 다음에 또 들어오고 그때는
   아무도 모른다. 화면이 잠깐 비는 쪽이 손절선을 흘리는 것보다 낫다.
3. `verify-live` 가 손절선을 `91234.5678` 로 심고 **응답 문자열에 그 숫자가 없는지**
   확인한다. 칸 이름만 지우는 것으로는 부족하다.

## PART D — 갱신: 전체 리렌더 금지

> **1분마다 갱신. 깜빡이지 않게 값만 바꾼다. 바뀐 값만 0.3초 밝아졌다 돌아온다.**

보통의 폴링 화면은 `setState` 로 표를 통째로 다시 그린다. 그러면 스크롤·선택·포커스가
흔들리고, "무엇이 방금 바뀌었는지" 가 사라진다.

| 상황 | 처리 |
|---|---|
| 숫자가 바뀐다 | 그 **텍스트 노드만** 직접 고쳐 쓴다 (`CellStore` → `Cell`) — 리렌더 없음 |
| 전략이 늘거나 멈춘다 | 그때만 리렌더 (`shapeKey` 가 달라진 경우) |

**측정한 결과**(개발 모드, `window.__labBoardRenders`):

```
렌더 횟수   폴링 전 2 → 폴링 후 2     (늘지 않았다)
DOM 변경    5건 — 바뀐 셀 하나뿐
깜빡임      갱신 시각 셀 1개, 0.3초 뒤 사라짐 (남아 있는 .is-flash 0개)
```

색이 아니라 **밝기**만 올린다(`filter: brightness`). 색을 바꾸면 손익 부호와 섞여 읽힌다.
`prefers-reduced-motion` 이면 값만 바뀌고 안 움직인다.

## A-2 — 경고는 표 **위**에 있다

표 안에 섞으면 숫자를 먼저 읽는다. 지금 나올 수 있는 경고:

| 종류 | 언제 |
|---|---|
| 시세 끊김 | `feedStatus` 가 stale — **신규 진입이 막혀 있다**는 사실까지 적는다 |
| 봉 구멍 | `DataGap` 에 행이 있을 때. **메우지 않았다**고 적는다 |
| 페이퍼 정지 | 마지막 처리 봉이 2시간 넘게 오래됨 — **표의 숫자가 그 시각 기준**이라고 적는다 |
| 워밍업 재생 | 자산곡선이 Run 시작보다 앞에서 시작할 때 (아래) |

### 운용 일수를 자산곡선에서 세지 않는다

페이퍼 첫 실행은 지표를 데우려고 **과거 200봉을 재생한다**(LAB-07). 그래서 자산곡선은
페이퍼가 시작되기 8일 전부터 그려져 있다. 그 첫 점부터 세면 **8일을 공짜로 얻는다** —
실제로는 2일째인데 화면이 10일째라고 말한다. 처음에 그렇게 짰고, 화면에서 보고 고쳤다.

지금은 **`Run.periodStart` 부터** 센다. 재생 구간이 있다는 사실은 경고와 곡선 아래 주석으로
따로 적는다. 백테스트 대비 비교(30일 문턱)도 같은 셈을 쓴다 — 아니면 비교가 8일 일찍 열린다.

## 검증 — `npm run lab:verify-live`

진짜 페이퍼는 2일째고 청산된 거래가 0건이라 화면에서 확인할 수 없는 것이 많다:
순위가 30건에서 열리는지, 정지된 전략이 남는지, 손절선이 새지 않는지.
**그것들은 데이터가 있어야 보인다.**

그래서 `__검증` 이라는 임시 전략 3종(오래 돈 것 · 갓 시작한 것 · 정지된 것)을 심고,
화면 데이터 계층을 그대로 태운 뒤 **지운다.** 진짜 페이퍼 숫자는 건드리지 않는다.
`--keep` 로 남겨 화면으로 보고, `--clean` 으로 지운다.

### 이 검증이 잡은 것

> **자산곡선 구멍을 Run 별로 재지 않고 한데 모아 재고 있었다.**
>
> 한 전략이 멈춘 구간을 **다른 전략의 점이 덮어서** 구멍이 사라졌다. 전략이 하나뿐일
> 때는 맞게 동작해서 눈에 안 띈다. 지금은 `runId` 가 같은 이웃 점끼리만 잰다.
