## 0. 결론 — **갭이 아니다**

```
고래 자신의 승률   65.8%
우리 추종 승률     32.4%
차                 33.4%p
```

**두 숫자는 같은 기준이 아니다.** 빼면 안 되는 두 수를 뺀 것이다.

지시서 E-1 이 마지막 후보로 적은 "승률 정의 차이" 가 답이고,
**FCE 문서가 이미 그렇게 적어두고 있었다.**

---

## 1. FCE 가 뭐라고 적어뒀나

`docs/validation/WHALE_FOLLOW.md` 의 `### 그리고 두 축은 다른 것을 잰다 ★`:

| | 재는 것 |
|---|---|
| 승격 심사 | **고래 자신의 승률** |
| 추종 트랙 | **이 고래를 신호로 삼고 우리 사이징·출구로 거래하면 버는가** |

> 고래 승률이 55% 가 아니어도 우리 손익비가 붙으면 벌 수 있고, 승률 70% 고래를
> 따라가도 지연·비용 때문에 잃을 수 있다. **후자는 추종 트랙 없이는 영원히 측정되지 않는다.**
>
> 그래서 추종 트랙 성과를 승격 근거로 쓰지 않는다(C11). **다른 질문의 답이다.**

★ 표시까지 붙여 강조해둔 문단이다. 갭을 계산한 쪽이 이 문단을 안 읽은 것이다.

---

## 2. 두 모집단이 어떻게 다른가

| 축 | 65.8% | 32.4% |
|---|---|---|
| 누가 거래했나 | 고래 본인 | **우리** |
| 거래 목록 | 그 지갑의 온체인 체결 전부 | 우리가 따라 들어간 건만 |
| 진입 시점 | 고래의 체결 시각 | **고래 체결을 관측한 뒤** |
| 진입 가격 | 고래의 체결가 | 관측 시점 시세 |
| 사이징 | 고래의 자본·판단 | `policy.plan_position_size` (리스크 기준) |
| 청산 | 고래의 판단 | **우리 규칙** (무효선·TP1/TP2·시간) |
| 레버리지 | 고래가 정함 | `paper_leverage` |
| 승패 판정 | 그 지갑 기준 | 우리 `net_pnl` 기준 |

**여덟 축 중 일치하는 것이 하나도 없다.** 거래 목록부터 다르다 —
고래가 100건 하고 우리가 74건 따라갔다면 그 74건은 100건의 부분집합조차 아니다
(자격 심사를 통과한 지갑의, 관측에 성공한, 지연 안에 들어온 건만이다).

---

## 3. 그러면 무엇을 비교해야 하나

**같은 거래 목록 위에서 한 축만 바꿔야 한다.** FCE 는 이미 그걸 하고 있다:

```
반사실: 고래 청산을 그대로 따랐다면  -49.58 (75건)
```

이게 옳은 비교다 — **우리 진입 75건을 고정하고 출구만 고래 것으로 갈아 끼운 것.**
결과는 더 나빴다. 즉 **우리 청산 규칙이 갭의 원인이 아니다.**

### 남은 축

| 축 | 어떻게 재나 | 상태 |
|---|---|---|
| 청산 | 반사실 −49.58 (75건) | ✅ **원인 아님** — 따라가면 더 나빴다 |
| 진입 지연 | 고래 체결 ↔ 우리 진입 시각 | ✅ **이미 재고 있다**(아래) |
| 진입 가격 드리프트 | 손절폭 대비 이동 | ✅ **이미 재고 있다**(아래) |
| 사이징 | 같은 진입에 고래 비중으로 잰 반사실 | 미측정 |
| 지갑 선정 | 자격 통과분의 사후 성적 | 미측정 — 리더보드에 재료 있음 |

> ⚠️ **정정.** 처음 이 문서를 쓸 때 지연·드리프트를 "미측정" 으로 적었다. **틀렸다** —
> FCE 가 이미 재고 있었고 `/api/onchain/follow/trades` 가 분포까지 준다.
> 레포 문서만 읽고 API 를 안 열어본 탓이다.

### 지연·드리프트 실측 (2026-09-21 · FCE API)

```
지연      중앙값 0.69분(41초) · p90 20.51분 · 최대 28.8분     상한 30분
드리프트   중앙값 0.00%      · p90  9.01%  · 최대 18.13%      상한 25% (손절폭 대비)
```

**중앙값 41초면 지연 가설은 약하다.** 절반 이상이 1분 안에 들어갔는데 승률이 31.9%다.
다만 p90 이 20분이라 꼬리가 길다 — **p90 구간만 떼어 승률을 내면 지연 기여분이
바로 나온다.** 재료가 이미 다 있고, 그게 다음 차례다.

## 4. 이 조사가 정한 것

| | |
|---|---|
| 고래 전략을 고칠까 | **아직 아니다** |
| 왜 | 고칠 대상(33.4%p)이 실재하지 않는다 |
| 대신 할 것 | 진입 지연·가격 슬리피지를 재고, **같은 거래 목록 위에서** 비교한다 |

지시서 하지 말 것 — *"갭 조사 전에 고래 전략을 고치지 말 것"* — 이 맞았다.
조사 결과는 **고칠 것이 없다** 가 아니라 **아직 무엇을 고칠지 모른다** 다.

```
                    ↳ 같은 진입 75건에 출구만 바꾼 것. 우리 청산이 원인은 아니다
```
