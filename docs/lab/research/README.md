# 연구 노트

**랩이 새로 갖는 유일한 데이터다**(UI-02 PART E). FCE 에 없다 — 무엇을 확인하고
있고 무엇을 알아냈는지는 엔진이 아니라 사람이 갖는 기록이다.

## 편집

파일이 정본이다. **main 에 올리면 `lab-research` 워크플로가 시드와 조립본을 돌린다**(UI-08 PART D) —
화면이 따라온다. 손으로 돌릴 때:

```bash
npm run lab:research-seed          # 파일 → DB
npm run lab:research-seed -- --dry # 무엇이 들어갈지만 (규칙 검사도 이것으로)
```

편집 UI 는 나중이다.

## 파일 모양 (UI-08)

```markdown
---
no: "01"
title: 고래는 65.8% 맞히는데 우리는 왜 32.4%인가   # 질문형 — 명사형이면 시드가 멈춘다
status: open            # open | testing | blocked | closed
verdict:                # 닫혔을 때만 — yes | no | inconclusive
summary: 가장 중요한 숫자 한 줄 (목록 · 32자 안)
opened_at: 2026-09-19
closed_at:
tracks: [whale]
blocks:                 # 이것 때문에 막힌 것 (예: 실매매)
live_gate:              # 실매매 전에 풀려야 하면 그 이름 — "실제 돈을 넣으려면" 에 뜬다
---

## 왜 궁금한가
문단.

## 가설
1. 하나
2. 둘

## 어떻게 확인하나
1. 하나

## 지금까지 알아낸 것
- ✓ 확인된 것 | 출처
  → 그래서 무엇을 뜻하나
- ✗ 기각된 것 | 출처
- · 진행중 · 미착수 | 출처 (없으면 —)

## 결정
닫힌 노트는 결정이 있어야 한다.

## 관련
- 트랙 | 고래 추종
- 문서 | docs/lab/WHALE_GAP.md
- 화면 | /whales

## 근거
- 라벨 | 값 | 출처
```

## 규칙

| | |
|---|---|
| **닫아도 지우지 않는다** | 진 질문이 남아 있어야 같은 걸 다시 묻지 않는다 |
| 근거에 출처를 적는다 | 출처 없는 수치는 다음 사람이 검증할 수 없다 |
| `inconclusive` 를 쓴다 | 모르는 걸 `no` 로 닫으면 기록이 거짓이 된다 |
| **제목은 질문형** | `고래 갭 조사` ✗ — 시드가 멈춘다 |
| **결정 없이 닫지 않는다** | 시드가 멈춘다 |
| **알아낸 것에 출처** | 줄마다 `| 출처` — 없으면 시드가 멈춘다 |
| 결론이 바뀌면 고쳐 쓴다 | 지우지 말고 **무엇이 언제 바뀌었는지** 적는다(01 의 청산 반사실 09-19 → 09-26) |
