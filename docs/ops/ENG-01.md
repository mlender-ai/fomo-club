# ENG-01 — 강제청산 모델 · 결과

지시서: `docs/wo/ENG-01-liquidation.md` · 2026-09-29 · 연구 02(닫음) · 05(다시 열어 갱신 · 닫음).

## 한 줄

**3배에서는 청산이 성과를 바꾸지 않는다** — 닫힌 거래 299건(크립토 183 · 고래 116)을 Bitget 청산 규칙으로 다시 돌렸더니
청산됐어야 할 거래 0건, 가장 가까이 간 거래도 청산가까지 14.5% 남았다. **모델이 무딘 게 아니다** — 같은 거래를 10배로
돌리면 크립토 청산 2 · 손절 먼저 6, 고래 청산 2 가 나온다. 청산 모델은 FCE 에 들어갔다(FCE #38).

## A — 청산가 (출처)

| 무엇 | 값 | 출처 |
|---|---|---|
| 공식 (격리) | `[증거금 + 단계 공제 − 수량 × 진입가 × 방향] ÷ [수량 × (MMR + 테이커 − 방향)]` · 방향 롱 1 · 숏 −1 | Bitget Support 12560603808759 (2025-09-18) |
| 유지증거금률 | 명목 단계 `keepMarginRate` (ADA 1단계 0.66% · BTC 0.40%) — 페이퍼 명목은 늘 1단계 · 공제 0 | Bitget API `query-position-lever` |
| 테이커 수수료 | 0.0006 | Bitget API `contracts` `takerFeeRate` |
| 마진 모드 | **격리** — FCE 페이퍼는 포지션마다 `margin_usdt` 를 따로 둔다 | FCE `PaperTrade` |
| 펀딩 (A-3) | 누적 펀딩을 격리 증거금에서 뺀다 → 청산가가 진입가 쪽으로 · 정산마다 다시 잰다 | Bitget API `history-fund-rate` |

예 — 3배 롱 ADA: 진입가 × (1 − 1/3) ÷ (1 − 0.0072) = **0.6715**(−32.85%). 숏은 × 1.3238(+32.38%).

**펀딩은 청산가에만 쓴다.** FCE 페이퍼는 펀딩을 손익에 세지 않는다 — 손익 모형 변경은 별건이다(합계는 따로 알린다:
크립토 1.10 · 고래 0.54 USDT · 299건 전체). ENG-02 실험 후보.

## B — 체결

| | |
|---|---|
| 봉 저가(롱) · 고가(숏)가 청산가에 닿음 | 그 봉에서 청산가로 |
| 갭 — 시가가 이미 청산가 너머 | 시가로(청산가보다 나쁘다) · 손실은 격리 증거금에서 멈춘다 |
| 같은 봉에서 손절선도 닿음 | 손절선이 청산가보다 진입가에 가까우면 **손절 먼저**, 아니면 청산 |
| 청산 손익 | 남은 몫의 격리 증거금 전부 · 청산 수수료는 공식의 수수료율에 이미 들어 있다 |

## C — invariant

**가격 손익이 증거금 아래로 갈 수 없다** — `gross_pnl < −margin` 이면 `PositionLossInvariantViolation` → 그 트랙 정지
(`paper_engine_states __track__` · 대시보드 `track_halts` · 랩은 트랙을 `정지` 로 · 감시 알림은 틱이 멈춰 30분 안에 온다).
사람이 원인을 고치고 표식을 지울 때까지 돌지 않는다.

- **D-1 기록을 덮어쓰지 않았다** — 재채점은 `FceRescore`(`rescored_with_liquidation`) 한 줄. `FceTrade` 는 그대로
- 화면 — 전략 상세 `강제청산 재채점`(청산 반영 기본 · 기록 나란히 · 배수 표) · 복기 거래 상세 `청산 모델`
  (진입 때 청산가 · 최근접 · 1배였으면). 재채점 성적은 **화면 모집단과 같은 거래**로 센다 — 바뀐 게 없으면 MDD 는 FCE 값
- **D-2 1배 · 3배** — 3배에서 청산되고 1배에서 산 거래 0. 3배는 1배의 배율이다(청산을 넣어도) → 연구 05 갱신

재채점 방식의 한계: 청산가에 닿은 봉에서만 규칙을 더한다 — 청산과 무관한 봉의 손절 방식(종가 · 봉 중간)을 다시 채점하지 않는다.
봉은 거래 timeframe(4시간). 정산 시각 가격은 그 시각 봉 종가로 근사한다.

## E — 이후 운용

- FCE 페이퍼(크립토 · 고래 추종)는 봉마다 청산가를 다시 재고 청산 규칙으로 닫는다(FCE #38 · 테스트 8 · 전체 1,992)
- 포지션 레일 — 무효화선 바깥 청산가를 레일 아래 한 줄로(`청산 0.6715 · 31.2% 남음`). FCE 가 잰 `liquidation_price` 그대로
- 청산 위험 알약 — 증거금 대비 −80% 아래 **또는 청산가까지 8% 안**
