지시서: `docs/wo/ENG-02-research-loop.md` · 2026-09-30.

## 한 줄

엔진이 매일 자기 성과에서 약점을 찾아 가설을 세우고, **파라미터 하나만** 바꾼 그림자를 본 트랙과 같은 신호로 따로 돌리고,
**시작 때 잠근 기준**과 **누적 시도 수로 보정한 우연 확률**로 판정해 연구 노트를 올린다. 본 트랙을 바꾸는 길은
사람의 `/approve` 하나다. 첫 실험 셋이 등록돼 돌기 시작했다.

## 규칙이 어디서 강제되나 (완료 3 · 4 · 5)

| 규칙 | 코드 | DB · 실행부 |
|---|---|---|
| 한 번에 하나 | `registrationProblem`(허용 목록 · 한 칸) | FCE `load_active` 가 칸이 둘 이상이면 거부 · `shadow_policy` 가 두 칸 이상 달라지면 예외 |
| 동시 3 | `registrationProblem` | 트리거 · FCE `MAX_ACTIVE` |
| 기준 시작 전 고정 | 시작 순간 `criteriaFingerprint`(바꿀 것 · 값 · 지금 값 · 시작 시각 · 기준) | 트리거: 지문이 있으면 그 칸들 수정 거절 · 판정 때 지문이 다르면 `invalid` |
| 누적 다중 비교 | `cumulativeTries` = 시작한 그림자 전부 · Šidák `1 − (1 − p)^N` | 트리거: 행 삭제 거절 — 시도 수가 줄 수 없다 |
| 실패를 지우지 않는다 | 실패 → `failed` · 노트 `없음` 으로 닫힘 | 트리거 |
| 같은 시도 두 번 금지 | `key` = param:value | `@unique` |
| LLM 이 숫자를 안 고른다 | 값 = 데이터 규칙(`hypothesesFrom`) · 문장도 틀 | LLM 을 부르지 않는다 |
| 자동 승격 금지 | 승인은 `awaiting` 에서만 · 자본은 승인 불가(보고만) | FCE 봇은 기록만 · 정책 파일은 LAB `toApply` 만 쓴다 |

단일 p — 본 트랙과 그림자의 **일별 손익 차이**에 대한 짝지은 t 검정(단측). 같은 신호를 받아 서로 상관돼 있어서 짝지어 본다.
판정 기준(사전 등록 · 잠금): 거래 ≥ 30 AND 일 ≥ 14 · 수익÷낙폭 > 본 트랙 · 누적 보정 우연 확률 < 20% · 비용 후 손익 > 본 트랙 ·
판단 불가면 기준 그대로 14일 **한 번만** 연장.

## F — 승인 · 시험 (완료 7 · 8)

**승인은 `awaiting`(통과 · 승인 대기)에서만 열린다.** 그 밖은 거절 — 판정 전 · 실패 · 판단 불가 · 자본(보고만).

| 시험 | 결과 |
|---|---|
| 그림자를 켜도 본 트랙 원장이 같다 | ✅ FCE `test_shadow_does_not_touch_main_track` — 같은 신호 · 같은 진입가 · 같은 손절, 그림자는 1R 금액만 4배 |
| 깨진 `active.json` 이 본 트랙을 멈추지 않는다 | ✅ FCE `test_broken_shadow_file_never_breaks_main` |
| 판정 전 `/approve` 는 거절 · 정책 파일 그대로 | ✅ **실경로** 09-29 14:19 UTC — FCE 봇과 같은 함수(`record_decision`)로 `/approve 1` → 러너 → LAB: `승인 대기가 아니다 — 지금 filtering` · `crypto-v3.json` 지문 동일 · 새 버전 파일 없음 |
| `/approve` · `/reject` 는 봇에서 **기록만** | ✅ FCE `test_decision_is_only_recorded` · 허용 채팅만(`guarded`) |
| 텔레그램 실제 메시지 | 봇(FCE `telegram_bot`)이 새 명령을 가진 채 돈다(23:06 KST 재기동). 광혁이 `/approve 1` 을 보내면 "접수" 답과 함께 같은 거절이 나와야 한다 |

승인되면: 러너가 가장 큰 `crypto-vN.json` 을 그대로 승계해 한 칸만 바꾼 `crypto-v(N+1).json` 을 쓴다(`_inherits` · `_why` · `_rollback`).
FCE 로더는 가장 큰 버전을 고르므로 재기동 없이 다음 판정부터 적용된다. 옛 버전은 파일로 남는다 — 되돌리기 = 새 파일 지우기.
