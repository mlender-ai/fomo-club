- **윗단이 멈추면 아래는 판정하지 않는다** — 맥이 죽으면 알림 **하나**(맥 · 러너). FCE 가 죽으면 FCE 하나
- **장외 주식은 판정하지 않는다** — 장 시간 · 휴장일은 랩이 안다(`lib/lab/market-hours.ts` · FCE 확정 휴장일과 같은 날짜 ·
  US 서머타임 · 조기 폐장). FCE `market_state` 만 믿으면 FCE 가 멈춘 순간의 `closed` 로 굳어 멈춤을 못 잡는다
- 문구(A-3) — `🔴 크립토 트랙 42분째 멈춤` / `마지막 틱 10:18 · FCE 는 살아 있음` / `→ FCE 워커 확인: …` · 복구 `🟢 … 복구 · 멈춤 51분`
- 보낸 것 · 못 보낸 것 전부 `LabNotice` — `GET /api/lab/watch` 로 누구나 본다

## PART C — 유효일

5분 칸(`LabTickSlot`) — 감시가 칸마다 "그 트랙에 틱이 있었나" 를 적는다. 크립토 · 고래는 24시간, 주식은 정규장 · 휴장 제외.
하루 커버리지 = 산 칸 ÷ 있어야 했던 칸(감시 시작 뒤 · 오늘은 지금까지) · **유효일 = 90% 이상**.
맥이 죽은 칸은 죽은 칸이다 — 맥 밖에서 세니까 절전도 유실로 잡힌다.

연구 03 — 한 시간마다 "맥 밖 감시 N일 — 크립토 유효 a/n · 고래 … · 연속 k일" 한 줄을 갈아 끼운다.
크립토 · 고래가 **30일 연속 유효**면 `닫을 수 있다` 로 바뀐다(닫기는 사람이 md 에 결정을 쓴다 — 결정 없는 닫힘은 파서가 거절한다).

## PART D — 평가 자산

| | |
|---|---|
| Hero · 수익률 | **실현 그대로** (FCE 와 같다 — `fce-match.test.ts`) |
| Hero 아래 | `지금 평가 $46,608.73 (미실현 −$5.90)` — 30초 |
| 차트 | 실현(굵은 파랑 · 계단) · 평가(옅고 얇은 파랑) — 평가 점은 감시가 5분마다 |
| 포지션 탭 | `오늘 +$0.41` — 크립토 · 고래 USDT 원래 금액의 오늘(KST) 평가 변화. 환산값과 섞지 않는다 |

미실현 = FCE 가 업로드 때 낸 값(비용 반영) + **그 뒤 가격 움직임만**(수량 × (Bitget 지금가 − FCE 표시가) × 방향).
주식은 FCE 트랙 미실현 그대로. 비용을 랩이 다시 계산하지 않는다.
