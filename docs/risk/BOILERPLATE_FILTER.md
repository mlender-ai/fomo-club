# 보일러플레이트 필터 사전 (WO-SUB-06 §5-2)

> **생성 문서다.** 정본은 `packages/fomo-core/src/risk/boilerplate.ts` 이고 이 파일은 그것의 렌더다.
> 고칠 때는 소스를 고치고 `npx tsx scripts/risk-boilerplate-render.ts` 를 다시 돌린다.
> 이 문서를 직접 편집하면 테스트(`risk-boilerplate.test.ts`)가 실패한다.

## 왜 필요한가

공시 위험요소 섹션은 절반이 **모든 기업에 해당하는 문구**다("경쟁이 치열합니다",
"경제 상황에 영향을 받습니다"). 그대로 종목 고유 리스크로 내보내면 소스는 진짜인데
정보가 0 인 문장이 화면에 나간다 — WO §10 의 "위험요소 섹션의 보일러플레이트를 그대로 노출".

## 적용 경계 — 유형 리스크에는 쓰지 않는다

이 필터는 **§5-2 공시 추출 경로 전용**이다. 독트린의 유형 리스크에는 적용하지 않는다.

독트린에는 `quality-competition`("새로 들어오는 회사가 늘거나 가격 경쟁이 붙으면…") 항목이 있고
아래 `generic_competition` 패턴과 문구 계열이 겹친다. 둘은 다른 것이다:

| | 주장 | 일반론일 때 |
|---|---|---|
| 유형 리스크 | "이 유형에 흔히 해당한다"고 **고지를 붙여** 일반론임을 밝힌다 | 정상 |
| 종목 고유 리스크 | **이 회사만의 사실이라고 주장**한다 | 거짓 |

그래서 필터를 공용 유틸로 만들지 않는다. 하나로 합치면 독트린 확정 항목이 조용히 지워진다.
`risk-boilerplate.test.ts` 가 이 경계를 두 방향으로 고정한다 — 독트린 문안에 필터를 걸면
실제로 지워진다는 것과, 유형 리스크 로더가 필터를 부르지 않는다는 것.

## 사전 v1

§11 지침대로 **작게 시작한다.** 과하게 잡으면 종목 고유 리스크가 함께 지워지고, 그 손실은
커버리지 숫자로만 보이고 무엇이 지워졌는지는 안 보인다. 그래서 `filterBoilerplate` 는
지워진 항목과 사유를 함께 돌려준다(조용한 절단 금지).

| 규칙 | 패턴 | 사전에 들어온 이유 |
|---|---|---|
| `generic_competition` | `(경쟁이?\s*(치열\|심화\|격화)\|시장\s*경쟁.{0,8}(있\|하)\|경쟁\s*업체가?\s*(많\|증가))` | 어느 상장사나 쓰는 문구. 경쟁 리스크는 '누가·어떤 제품에서'가 붙어야 사실이 된다 |
| `generic_macro` | `(경기\s*(변동\|침체\|둔화).{0,12}(영향\|따라)\|경제\s*(상황\|환경).{0,12}영향\|국내외\s*경제\|거시\s*경제.{0,10}영향\|금리[·, ]?환율[·, ]?유가)` | 매크로 노출은 전 종목 공통이라 이 회사를 설명하지 않는다 |
| `generic_regulation` | `(법규?의?\s*제정.{0,8}개정\|관련\s*법령.{0,10}변경.{0,10}(영향\|있)\|정부\s*정책.{0,10}변화.{0,10}영향)` | 규제 변화 일반론. 어떤 규제가 어느 품목에 걸리는지가 없으면 정보가 0 |
| `generic_disaster` | `(천재지변\|자연재해\|전쟁.{0,6}테러\|감염병.{0,10}확산.{0,10}영향\|예측할\s*수\s*없는\s*사유)` | 불가항력 조항. 위험요소 섹션의 법률 방어 문구지 관측 가능한 리스크가 아니다 |
| `generic_personnel` | `(우수?\s*인력.{0,10}(확보\|유치\|이탈)\|핵심\s*인력.{0,10}(이탈\|의존).{0,12}(있\|영향))` | 인력 리스크 일반론. 특정 인물·조직 사실이 없으면 전 기업 공통 |
| `generic_cyber` | `(해킹\|사이버\s*공격\|정보\s*보안\s*사고).{0,16}(가능성\|우려\|발생할\s*수)` | 보안 사고 가능성은 모든 기업에 열려 있다. 실제 사고·과징금은 사실이므로 남는다 |
| `generic_ip` | `(지식재산권?.{0,10}(침해\|분쟁).{0,14}(가능성\|우려)\|특허\s*분쟁.{0,10}(발생할\s*수\|가능성))` | IP 분쟁 가능성 일반론. 계류 중인 특정 소송은 사실이므로 남는다 |
| `no_specifics` | `길이 ≤ 45자 AND 숫자·영문 고유명사 없음` | 위 패턴을 피해가는 일반문의 마지막 그물. 수치나 고유명사가 있으면 통과시킨다 |

## 키우는 방법

1. 골든셋 실행 결과에서 `dropped` 와 `kept` 를 둘 다 본다
2. `kept` 에 일반론이 남아 있으면 패턴을 **좁게** 추가한다(주어가 특정되지 않은 서술만)
3. `dropped` 에 종목 고유 사실이 들어갔으면 그 패턴을 좁힌다 — 커버리지가 아니라 **정직성** 손실이다
4. 규칙마다 `note` 를 채운다. 사유 없는 패턴은 나중에 중복·과잉을 판단할 수 없다
