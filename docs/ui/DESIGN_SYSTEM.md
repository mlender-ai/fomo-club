## 1. 어두운 라임 토큰은 폐기됐다

옛 값(`--bg: #0b0d0e` · `--accent: #d4ff3f` · 모노스페이스)은 **코드에 없다.**

다만 **옛 이름은 잠시 남는다** — 값은 전부 새 팔레트를 가리킨다:

```css
--surface: var(--bg-2);
--text:    var(--ink);
--accent:  var(--blue);
--mono:    var(--font);   /* 모노스페이스를 없앴다 */
```

### 왜 이름을 한 번에 안 지웠나

아직 옛 이름을 쓰는 화면이 다섯이다:

```
(lab)/page.tsx · (lab)/live · (lab)/whale · (lab)/trades · (lab)/data
components/lab/EquityCurve.tsx · components/lab/LiveBoard.tsx
```

이름까지 같이 지우면 이 다섯이 한꺼번에 깨진다. 그건 `UI-00 §6` 이 금지한
**"여러 탭을 동시에 반쯤 만든 상태"** 다. `UI-03`~`UI-09` 가 화면을 하나씩 다시
만들면서 별칭도 같이 사라진다.

> 별칭이 남아 있는 한 이 문서의 위 목록이 **남은 일 목록**이다.

## 2. 색을 하드코딩할 수 없다

```bash
npm run lint:tokens
```

`:root` 블록 **밖**에 `#색` · `rgb(` · `hsl(` 이 있으면 실패한다.

어두운 테마를 나중에 만들 수 있는 유일한 조건이 이것이다 — 색이 한 곳에만 있어야
값만 바꿔서 뒤집을 수 있다. 화면 코드에 `#0052FF` 가 하나 박히면 **그 자리는 영원히
밝은 테마다.**

처음 돌렸을 때 세 곳이 걸렸고 전부 토큰으로 옮겼다:

| 자리 | 있던 값 |
|---|---|
| `globals.css` 상태 경고색 | `#fbbf24` |
| `login/PasswordInput.tsx` | `rgba(255,255,255,0.05)` · `rgba(255,255,255,0.1)` |

## 3. 숫자

**화면에 나가는 모든 수가 `components/ui/format.ts` 를 지난다.**

| 규칙 | 예 |
|---|---|
| 음수는 `−` (U+2212) | `−$3,770.70` · `−36.89%` |
| 통화 기호는 숫자 앞 | `$46,229.30` · `₩99,999,340` |
| 퍼센트는 소수점 둘째까지 | `+4.27%` · `−27.71%` |
| 모르는 값은 `—` | **`0` 으로 채우지 않는다** |

고정폭(`tnum`)은 `body` 에서 전역으로 건다. 화면마다 따로 걸지 않는다.

### 모노스페이스는 사라졌다

전에는 `.num · th · td` 에 등폭을 걸었다. 뺐다 — 금융앱은 **비례 폰트 + 고정폭
숫자**다. `code` · `pre` 만 등폭을 남긴다. 그건 글씨가 아니라 코드다.

## 4. 부품 12개

`/ui` 에서 전부 볼 수 있다. **여기 있는 것만 쓴다** — 화면마다 새로 만들면 같은
알약이 화면마다 조금씩 달라지고, 색 하나 바꾸려면 전부 뒤져야 한다.

| 부품 | 쓰는 곳 |
|---|---|
| `Hero` | **화면당 하나.** 그 화면의 답 |
| `Delta` | 금액 + 알약(%) + 기간 |
| `Pill` | up · dn · warn · blue · mute |
| `StatGroup` | 가로 통계 칸 |
| `AreaChartCard` | 자산 곡선 + 기준선 + 벤치마크 점선 + 기간 |
| `Sparkline` | 행 안 추이 |
| `AssetRow` | 트랙 한 줄 |
| `Card` | 제목 · 설명 · 내용 |
| `ResearchItem` | 연구 번호 · 상태 |
| `CompareBar` | 기준선 대비 비교 |
| `Empty` | 없을 때 — **왜 없는지까지** |
| `Skeleton` | 로딩 |

### 부품이 규칙을 지킨다

| 부품 | 지키는 규칙 |
|---|---|
| `AreaChartCard` | 벤치마크가 없으면 **없다고 말한다.** 조용히 빼면 화면이 좋아 보인다 |
| `AreaChartCard` · `Sparkline` | `null` 구간에서 **선을 끊는다.** 이으면 끊긴 수집이 완만한 상승으로 보인다 |
| `CompareBar` | 기준을 넘은 막대만 파랗다. 넘지 못한 것은 강조하지 않는다 |
| `CompareBar` | 값에 **손익 색을 자동으로 주지 않는다** (아래) |
| `Empty` | 왜 없는지·무엇을 하면 되는지. 빈 화면은 고장과 구분이 안 된다 |

#### 초록이 손익이 아닌 곳에 쓰인 적이 있다

`CompareBar` 가 값의 부호로 색을 정하게 짰더니 C/M `0.70` 이 **초록**으로 나왔다.
그건 이익이 아니다. `UI-01 A-2` — **초록·빨강은 손익에만.** 지금은 부르는 쪽이
`tone` 을 줄 때만 색이 붙는다.

## 5. 차트

| 용도 | 라이브러리 |
|---|---|
| 영역 차트 · 스파크라인 | **Recharts** |
| 캔들 | Lightweight Charts (이미 설치돼 있다 — 포지션 탭에서) |

**SVG 로 직접 그리지 않는다.** 전에 자산곡선을 직접 그렸다가 `height` 하나 때문에
폰에서 깨진 적이 있다.

## 6. 반응형

| 폭 | 무엇이 숨나 |
|---|---|
| < 1200 | 추이선 |
| < 768 | 변동 · 상태 · 부제 · hero 44px |

**값과 원래 금액은 끝까지 남는다** — 그게 행의 답이다. 폰 폭(375)에서 가로
스크롤이 생기지 않는 것을 확인했다.
