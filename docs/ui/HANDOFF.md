## 3. 에이전트가 정한 것 (검수 대상)

| # | 결정 | 이유 | 되돌리려면 |

| 1 | **공개 사이트는 페이퍼만.** 실계좌 포지션 · 계좌 성적표는 안 올린다 | 로그인 없는 사이트 — UI-06 때 광혁 결정 유지 | 로그인 뒤 화면을 따로(새 WO) |

## 5. 남은 것 · 운영 (광혁 손이 필요한 것)

| # | 무엇 | 왜 에이전트가 못 했나 | 할 일 |
|---|---|---|---|
| 1 | **러너를 Claude 샌드박스 밖에서 다시 띄운다** | 지금 러너는 Claude 세션 안이라 `~/Documents`(FCE)를 못 읽는다 → 사이드카 캐시로 우회 중. 토큰은 에이전트가 다루지 않는다 | `LAB_INGEST_TOKEN=… scripts/lab/launchd/install.sh` |
| 2 | 사이드카(`npm run lab:fce-sidecar`)는 nohup 프로세스 — **재부팅하면 죽는다** | 위와 같음 | 1 을 하면 러너가 직접 읽어 필요 없어진다. 아니면 launchd 로 |
| 3 | 목표 화면 `UI-target-overview.html` | 받은 적 없음 | 주면 다시 대조 |
| 4 | 실계좌 화면 | 결정 사항 | 두려면 인증 포함 새 WO |
| 5 | 콜드 스타트 첫 요청 ~2.3초 | Vercel 서버리스 특성 | 문제면 크론 워밍 |
| 6 | 텔레그램 리포트와 직접 대조 | 랩이 텔레그램을 안 읽는다 | FCE API(리포트 원천)와 대조함 |

사이드카 · 캐시가 끊기면: 업로드는 2시간까지 캐시로 버티고, 그 뒤 포지션 분석 칸이 "FCE 분석 없음" 으로 정직하게 바뀐다
(지어낸 값은 안 나간다).
