# UI-06 — 포지션 결과 보고

지시서: `docs/wo/UI-06-positions.md` · 조립: `apps/web/lib/lab/positions.ts` · 화면: `components/tabs/PositionsBody.tsx` · `PositionDetailBody.tsx`

## 먼저 정한 것 — 페이퍼만 (광혁 결정 2026-09-26)

FCE 로컬 UI 의 라이브 포지션 화면(`/api/live/positions`)은 **Bitget 실계좌**다(TRUMP 10배 · PONS 5배 …).
이 사이트는 로그인 없이 열린다. 물었고, 답은 **페이퍼 포지션만** 이다.

| | 결정 |
|---|---|
| 올리는 것 | FCE 페이퍼(`/api/paper/dashboard` `open_trades`) |
| 가격선 | **낸다** — 무효화 · 손절 · 익절1 · 익절2. LAB-08 의 목표가·손절선 금지는 **랩 자체 엔진**에 남는다(`packages/lab/src/live-view.ts` 머리말) |
| 라이브 계좌 | **받지 않는다.** 심볼로 빌려 오지도 않는다 — 실계좌에 무엇을 들고 있는지가 샌다 |

## FCE 기능 9개 — 어디까지 왔나

| FCE | 여기 | |
|---|---|---|
| 포지션 카드 (심볼 · 방향 · 배수 · 손익 · 건강도 원) | 카드 | ✅ 건강도 원은 **값이 있을 때만** — FCE 가 페이퍼에 안 싣는다 |
| 상태 배지 | FCE 스탠스(`롱 우세` · `엇갈림` …) · 포지션과 엇갈리면 주의색 | ✅ FCE 라이브의 `관찰 필요` 류 판정은 페이퍼에 없다 |
| 고래 추적군 | — | ❌ 라이브 전용 |
| 가격 레일 | 카드 · 상세 | ✅ |
| 지금 볼 것 | 그 자리에 FCE 가 페이퍼에 내는 **선까지 거리** (파랑 왼쪽 바) | ⚠️ 문장은 라이브 전용 |
| 유효 시간 | — | ❌ 라이브 전용 |
| 패턴 시간봉 | — | ❌ 라이브 전용 (`/api/live/positions/{id}/pattern-matrix`) |
| 실시간 동기화 | 30초마다 다시 읽는다 | ⚠️ 값은 업로드(15분)마다 바뀐다 |
| 미니멀 / 프로 | 폰 미니멀 · 데스크톱 프로 · 기억 | ✅ |

라이브 전용 다섯은 화면에 **이름으로** 남는다(`FCE 라이브 전용` 카드 · ⓘ 에 이유). 지어내지 않는다.
**완료 확인 1 · 6 · 9 는 못 채웠다** — FCE 가 페이퍼에 그 값을 내야 채워진다(FCE 레포 작업, 별도 지시).

## 실측에서 밟은 것 — 레일 왼쪽 끝은 **지금 걸린 손절**이다

ADA 는 FCE 가 `무효화까지 −0.548%` 라고 냈는데, 현재가 0.2555 와 무효화 0.24599 사이는 −3.7% 다.
FCE `paper/service.py` 는 거리를 **`stop_price`** 로 잰다 — 부분 익절(00:00) 뒤 손절을 본전(0.2541)으로 올렸다.
레일 왼쪽 끝을 무효화로 두면 FCE 숫자와 그림이 서로 다른 말을 한다. 그래서 왼쪽 끝 = `stop_price`, 옮겨졌으면 이름이 `손절` 이 되고
차트에는 무효화와 손절을 둘 다 긋는다.

## 캔들

FCE 는 페이퍼 포지션의 캔들을 내지 않는다(차트 분석은 라이브 계좌 id 에만 붙는다). **시세는 시장 데이터**라 Mac 업로더가
Bitget 공개 시세(`/api/v2/mix/market/candles`)에서 받아 올린다 — 심볼 × 4 시간봉 × 200개. 판정(선)은 전부 FCE 값이다.

## 줄 세우기 (A-3)
