원인: FCE 는 검증 앵커(`scoreboard.started_at` 07-17 05:46) 뒤에 닫힌 거래만 센다. 랩은 원장 전부(부트스트랩 5건 더)로
다시 셌고 MDD 는 자기 곡선으로 다시 쟀다 — 지시서가 경고한 "LAB 이 계산을 다시 하면" 그대로였다.
앵커를 받아(`FceTrack.validationFrom`) 같은 거래만 세고 MDD 는 FCE 값을 쓴다 → 소수점까지 같다(`fce-match.test.ts`).
세 화면(Overview 259 · 전략 165+94 · 복기 259)이 같은 수다. 복기 목록에는 창 밖 5건도 `창 밖` 으로 남는다.

고래 추종: 94 · 36.2% · PF 0.647 · 자본 470.22 — FCE 와 같다(승률 36.17 은 FCE 가 소수 첫째 자리로 반올림).
포지션 4건: 손익 · 현재가 · 진입가 · 무효화 전부 FCE `exit_monitor` 와 같다.
**텔레그램 리포트 대조는 못 했다** — 랩이 텔레그램을 읽지 않는다. FCE API(리포트의 원천)와 대조했다.

6. **FCE 대결 탭 캡처에 실계좌가 찍힌다** — 레포에 넣지 않았다
