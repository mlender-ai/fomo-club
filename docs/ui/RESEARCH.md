# UI-08 — 연구 결과 보고

지시서: `docs/wo/UI-08-research.md` · 노트: `docs/lab/research/*.md` · 파서: `apps/web/lib/lab/research-note.ts`
조립: `apps/web/lib/lab/research.ts` · 화면: `components/tabs/ResearchBody.tsx` · `ResearchDetailBody.tsx`

## 파일 → DB → 화면

```
docs/lab/research/*.md ──(main 에 push)──▶ lab-research 워크플로
                                           ├─ npm run lab:research-seed   (규칙 검사 + DB)
                                           └─ npm run lab:snapshot        (연구 탭 조립본)
```

시드가 **멈추는** 규칙 — 어기면 워크플로가 빨갛게 떨어지고 DB 는 그대로다:

| 규칙 | 지시서 |
|---|---|
| 제목은 질문형 | 하지 말 것 1 |
| 결정 없이 닫지 않는다 · 닫힌 것은 verdict 필수 | 하지 말 것 3 |
| "알아낸 것" 줄마다 출처 | 하지 말 것 4 |

테스트(`research.test.ts`)가 **실제 파일 일곱 장**을 같은 파서로 읽어 같은 규칙을 검사한다.

## 시드 일곱 — 지시서 예시와 다르게 쓴 곳

| | 지시서 예시 | 노트 | 왜 |
|---|---|---|---|
| 01 알아낸 것 | "✓ 반사실 −49.58 (75건) → 청산은 원인이 아니다. 가설 3 기각" | **· 진행중** — 09-19 −49.58 (75건) → 09-26 FCE 대조 고래 청산 +236.86 · 우리 −32.90 (99건, `EXIT_B_BETTER`). 단 우리 출구 결함(`holding_bars`) 단서 | FCE 가 결론을 뒤집었다. 기각으로 적으면 근거 없는 "알아낸 것" 이 된다 |
| 01 제목 | 65.8% · 32.4% | 그대로 | 질문을 연 날의 값이다. 지금 값(72.3% · 37.0%)은 한 줄 요약과 알아낸 것에 |
| 04 한 줄 | "청산 10조합 바꿔도 CAGR −1.1~+0.3%" | "우연 확률 99% · 기준선 넘은 전략 0개" | 그 수치의 출처를 레포에서 찾지 못했다 — 근거 없이 쓰지 않는다 |
| 03 유효일 | 2/49 · 3/48 | US 2/53 · KR 3/52 (FCE 09-26) | 오늘 값 |
| 02 청산 경고 | — | −80% (UI-06) | 노트의 −90% 는 옛 값이었다 |

## 상태 알약 (A-4) — 한 곳에서

`components/ui/ResearchItem.tsx` `researchPill` — 진행중 `warn` · 실매매 차단 `dn` · 닫힘·있음 `up` · 닫힘·없음 `mute` · 판단 불가 `mute`.
Overview · 전략 · 포지션 · 고래의 연구 칸도 같은 부품이라 같은 색이다(전에는 진행중이 파랑이었다).

## 실제 돈을 넣으려면 (PART E)

노트 frontmatter `live_gate` 로 표시한 질문(02 강제청산 모델링 · 03 호스트 상시화) + 전략 탭의 기준선을 넘은 전략 수.
질문은 **닫혀야(판단 불가가 아니라)** 풀린 것으로 센다. 지금 **3개 중 0개 해결**.
