지시서: `docs/wo/UI-05-strategies.md` · 조립: `apps/web/lib/lab/strategies.ts` · 화면: `components/tabs/StrategiesBody.tsx` · `StrategyDetailBody.tsx`

## UI-FIX 와 부딪친 곳 — UI-FIX 를 따랐다

UI-05 A-1 은 **문장**(`기준선을 넘은 전략 없음`, 36/600)을 가장 큰 글자로 두라고 했다. UI-FIX(09-25, "05 이후 작업보다 먼저")는
바로 그 문장이 폰에서 `없` / `음` 으로 깨진 것을 고쳐 **숫자**(`0 / 2`)로 바꾸게 했다(B-6 · C-2). 결론은 그대로 두고 모양만 UI-FIX 를 따랐다.

```
기준선을 넘은 전략          ← 라벨
0 / 2                       ← hero
운용 2 · 멈춤 3             ← 이긴 전략이 생기면 `1위 고래 추종`
```

설명 문단은 전부 `ⓘ` 로 접었다. 텍스트 예산 테스트가 목록 + 상세 두 장(크립토 · 주식 US)까지 잰다.

## 랩이 새로 재는 것 — 둘

FCE 가 내지 않는 값이다. FCE 가 낸 값은 다시 계산하지 않는다.

| 값 | 어떻게 | 한계 |
|---|---|---|
| 샤프 | 일별 실현 자본 변화 · 연율 √365 | 호스트가 잔 날은 변화 0 으로 들어가 샤프를 낮춘다 |
| 평균 보유 | 진입~청산 평균 | 두 시각을 다 아는 거래만 |

## 배포 — 조립본 형식 5

`SNAPSHOT_VERSION` 4 → 5. 배포 직후 탭은 옛 형식이라 503 이다. #1285 때는 FCE 업로드가 죽어 있어 몇 시간 비었다.
이번에는 **FCE 를 기다리지 않고** 바로 만든다:

```bash
gh workflow run lab-collect.yml -f job=snapshot
```

(`npm run lab:snapshot` — 랩 DB 만 읽는다.)
