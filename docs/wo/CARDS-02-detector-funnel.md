# CARDS-02 — 카드 종류가 세 개뿐이다

> 정본은 이 문서다. **WO 의 전제 두 개가 실측과 달랐다** — 아래 「전제 정정」을 먼저 읽는다.

## 전제 정정 — 자금 흐름 카드는 사라지지 않았다

WO 는 이렇게 적었다.

```
"돈이 빠지고" / "전자장비와기기" — 소스 트리 전체에 없음
업종 단위 순매수 집계 코드 없음
화면에는 있는데 코드에 없다
```

**둘 다 사실이 아니다.**

| WO 전제 | 실측 |
|---|---|
| 소스에 없다 | `packages/fomo-core/src/keyword-cards/sector-flow.ts:159` 가 그 문구를 만든다 |
| 업종 집계 코드가 없다 | `aggregateSectorFlow()` (같은 파일 `:61`). 배선 `quiet-pick.ts:1694·2358·3195` → `QuietPickDeck.tsx:137·191` |

### 왜 못 찾았나 — 두 가지가 겹쳤다

1. **표시명이 바뀌었다.** 8월 31일 화면은 **원문 업종명**(`반도체와반도체장비`,
   `전자장비와기기`)이었다. DETAIL-01 이 `sectorDisplayName` 을 넣어 이제 `반도체`,
   `전자부품` 으로 나간다. **원문 이름으로 그렙하면 템플릿에서 안 나온다** — 템플릿에는
   업종명이 문자열로 없고 변수로 들어간다.
2. **배럴에서 일부러 뺐다.** `sector-flow` 는 `keyword-cards/index.ts` 에서 제외돼 있다
   (번들 격리 — 조회 라우트 콜드스타트). 배럴 기준 심볼 검색으로는 안 잡힌다.

**교훈**: 「화면에는 있는데 코드에 없다」가 나오면 **표시 계층의 변환**을 먼저 의심한다.
문자열이 코드에 없는 것이 정상인 경우가 있다.

## 보고할 것 1 — 등록 검출기 vs 실제 실행

**전부 돈다.** 계수기가 증거다(프로덕션 2026-09-03).

| 검출기 | 실행 증거 | 검출 수 |
|---|---|---|

| 임원 클러스터 (US) | `usInsiderRaw: 60` · `usWithSignal: 20` | 20 |
| **시장 역행** | `priceSignals.divergence: 178` | **178** |
| **거래량 각성** | `priceSignals.awakening: 0` | **0** |
| 자금 흐름 | `sectorFlow.cards: 1` | 1 |
| 거시 | `macro.cards: 2` | 2 |
| 인물(ARK 등) | `investorSignals` 배선 있음 · 수집 미가동 | 0 |

**「만들어놓고 파이프라인에 안 붙인 검출기」는 없었다.** 문제는 다른 곳이다.

## 보고할 것 2 — 역행 178건이 덱에 0장인 이유

`watching` 선반에도 없다(전부 streak). 즉 **품질 게이트 전에** 사라진다.

```ts
const ordered = [...tagged].sort(
  (a, b) => noveltyScore(b.sig.days) - noveltyScore(a.sig.days) || b.sig.baseStrength - a.sig.baseStrength
);
const considered = ordered.slice(0, MAX_FRONT_ASSEMBLIES);   // 60
```

`noveltyScore(ageDays)` 는 **경과일 지수 감쇠**다(`0.5^(age/halflife)`). 그런데 인자로
`sig.days` — **연속일수**를 넣는다. WO-DECK-01 이 의도한 것이다(9일 이어진 신호는 9일 전에
시작했다는 대리 지표). 문제는 그 대리 지표가 형마다 공평하지 않다는 것이다.

| 형 | `days` 분포 | 정렬 위치 |
|---|---|---|
| 수급 streak | **3**(하한) 부터 | 최상위 |
| 시장 역행 | 3~9 (`maxDivergenceDays: 9`) | 아래로 밀린다 |

후보가 **256+** 인데 상한이 **60** 이다. `days=3` streak 이 60칸을 다 채우고 역행은
한 장도 못 들어온다. **오늘 발행된 15장 전부 `days: 3`** — 정렬 키가 `days` 이고 3이 하한임을
그대로 보여준다.

**이것은 조건이 센 것이 아니라 정렬·상한의 구조적 편향이다.** 임계를 풀어 고칠 문제가 아니다
(WO 「하지 말 것」 3번). 조치 후보는 세 갈래이고 **덱 구성 불변식을 건드리므로 별도 판단이 필요하다**:

| 후보 | 내용 | 위험 |
|---|---|---|
| ㄱ | 형별 최소 할당(예: 조립 상한 60 중 형마다 최소 N칸) | 덱 구성 규칙 변경 — `guard:discovery` 불변식 재검토 필요 |
| ㄴ | `noveltyScore` 인자를 실제 경과일로 (신호 시작일 기준) | `days` 를 나이 대리로 쓴 WO-DECK-01 결정을 되돌리는 것 |
| ㄷ | `MAX_FRONT_ASSEMBLIES` 상향 | 조립 비용 증가(성능 예산) |

**아무것도 고르지 않았다.** 덱 고착(WO-DECK-01)은 3일 관측까지 하고 통과시킨 사안이라,
그 정렬을 건드리는 것은 이 WO 범위를 넘고 광혁 판단이 필요하다. → 아래 「결정 요청」.

## 보고할 것 3 — 검출기별 후보 수 → 덱 진입 수

**계수기를 만들었다**(완료조건 1·10). `qualification.detectorFunnel`:

```
{ <kind>: { detected, deduped, considered, published, watching } }
```

| 단계 | 지점 |
|---|---|
| `detected` | 검출기가 만든 후보 (`dedupeSignalsByStock` **전**) |
| `deduped` | 종목당 한 신호로 줄인 뒤(`baseStrength` 최대값 승리) |
| `considered` | 조립 상한(`MAX_FRONT_ASSEMBLIES`) 안에 든 수 |
| `published` | 덱에 나간 수 |
| `watching` | 「지켜보는 중」 선반 |

**`detected` 는 큰데 `considered` 가 0 이면 정렬·상한이 밀어낸 것이고, `considered` 는 있는데
`published` 가 0 이면 품질 게이트·덱 구성이 잘라낸 것이다.** 두 원인은 조치가 다르므로
계수기가 갈라 준다 — 종전 총합 계수기로는 이 구분이 불가능했고, 그래서 이번에 소스를 읽어
내려가야 했다.

테스트가 단계 단조성(`deduped ≤ detected ≤ …`)과 총합 일치(`Σconsidered == afterQuiet`)를 막는다.

## C-2 거래량 각성 — **이미 적용돼 있다**

WO: `전 급증 당일 가격 변동 ≤ 3%` → `후 급증 시작일부터 오늘까지 순변동 ≤ 5%`

`detectVolumeAwakening`(`quiet-signals.ts:190`)은 **이미 순변동을 쓴다**:

```ts
// 급증 시작 **직전** 종가 → 오늘 종가의 순변동. 당일 변동이 아니다(§0-1).
const beforeSpike = window[Math.max(0, spikeFrom - 1)]!;
const movePct = ((latest.close - beforeSpike.close) / beforeSpike.close) * 100;
if (Math.abs(movePct) > VOLUME_AWAKENING_MAX_MOVE_PCT) return null;
```

**지표 변경은 끝났다.** 임계값만 3% 로 남아 있고, 그건 사유가 문서화된 결정이다
(`quiet-signals.ts:160-168`):

> 이제 가장 좁은 값도 공급이 된다. 그러면 **가장 좁은 값을 쓴다** — 7%로 두면 카드가
> `주가 6.3%` 같은 칩을 달고 나가는데(실측), 6.3% 움직인 종목을 두고 "아직 안 움직였다"
> 고 말하는 것은 거짓이다. **이 카드의 문장이 참이 되는 선이 임계다.**

**3 → 5 로 올리지 않았다.** 카드 수를 늘리려고 임계를 푸는 것은 WO 「하지 말 것」 3번이고,
무엇보다 그 문장을 거짓으로 만든다. 오늘 `awakening: 0` 인 것은 임계 탓이 아니다 —
`spikeNetUnder3: 10` 은 **거래량 급증 여부와 무관하게** 순변동만 센 분포이므로,
두 조건의 교집합이 0 일 수 있다(별개 계수기다).

→ 임계를 올릴지는 **문장의 참·거짓 문제**라 광혁 판단이다. 아래 「결정 요청」.

### ⚠️ 앞 절의 「역행 178 → 덱 0장」을 정정한다

그 값은 **2026-09-02 21:53 페이로드 한 판**이었다. 오늘 02:41 판은 역행 46 검출 → **1장 발행**,

그러나 **구조적 편향은 그대로이고, 이제 정확히 계량됐다.** `deduped → considered` 생존율을
`days` 순으로 늘어놓으면 완전한 단조 관계가 나온다:

```
volume_awakening   days 1     100%   (3/3)
multi_cluster      days 3    37.5%   (3/8)
insider_cluster    days 2~3  30.0%   (6/20)
foreign_streak     days 3+   25.2%   (28/111)
institution_streak days 3+   14.2%   (19/134)
market_divergence  days 3~9   3.3%   (1/30)   ← 가장 긴 형이 가장 심하게 밀린다
```

`noveltyScore(sig.days)` 가 `days` 가 작은 형에 유리하다는 가설을 이 표가 그대로 확증한다 —
`days=1` 인 각성은 후보 전원이 통과하고, `days` 가 가장 큰 역행은 30건 중 1건만 통과한다.
**후보 306건에 조립 상한 60이라 이 편향이 곧 탈락이 된다.**

**조치는 여전히 고르지 않았다** — 세 후보 모두 덱 고착(WO-DECK-01, 3일 관측 통과)의 정렬을
건드린다. 다만 이제 근거가 가설이 아니라 **계량된 표**다.

### 자금 흐름 카드 — 정규 도메인 DOM
