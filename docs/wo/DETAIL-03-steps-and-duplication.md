# DETAIL-03 — 사라진 걸음 되살리기 + 중복 지우기

> 정본은 이 문서다. 문안·조건을 바꿀 때 코드와 함께 바꾼다.

## 보고할 것 1 — 3걸음은 **왜** 사라졌나

조건이 **하나**뿐이었다.

```ts
if ((pick.companyRead?.length ?? 0) > 0) out.push("company");
```

`companyRead` 는 팩트시트에서만 온다. 팩트시트가 없으면 걸음이 통째로 없어진다 —
프로덕션 실측(2026-09-03) **15장 중 7장**이 그 상태였다.

그런데 WO-RESET-05 §4(=이 문서 A-4)는 이미 이렇게 정해 뒀다:

| 확보 | 표시 |
|---|---|
| 회사 설명만 | 회사 설명만 보여주고 나머지 생략 |
| 재무만 | 재무만 |
| 둘 다 없음 | 걸음을 건너뛴다 |

**규칙은 있었고 조건이 그것을 안 봤다.** 실측으로 확인했다 — 팩트시트가 없는 7종목 중
**6종목이 회사 설명 문자열을 갖고 있고**, `companyBlurb` 가 연혁 문장을 걷어내고
「무엇을 파는가」를 남긴다:

```
신성이엔지    → "미국, 스페인 등 11개국에 해외법인을 운영하고, 클린룸 장비와 태양광 사업을 영위해요."
빙그레        → "중국, 미국, 베트남, 호주에 현지법인을 두고 식품 수입·제조·판매업을 영위해요."
에이치브이엠   → "20년 이상의 업력을 보유하며 고청정 진공용해 기술로 특수합금을 생산해요."
스튜디오드래곤 → null (쓸 수 있는 문장이 없다 → 그 줄만 없다)
```

→ 조건을 `hasCompanyMaterial`(companyRead **또는** 설명 **또는** 실체)로 바꿨다.

### 걸음을 번호가 아니라 **id** 로 들고 있는다

회사 설명은 벤더 요약이라 **열릴 때 받는다**(늦게 온다). 그래서 걸음 목록이 도중에 3→4 로
늘어난다. 번호로 들고 있으면 그 순간 **같은 번호가 다른 걸음을 가리킨다** — 4걸음(결정)을
보던 사용자가 3걸음(회사)으로 뒤로 밀린다. id 는 목록이 바뀌어도 같은 걸음을 가리킨다.

## 보고할 것 2 — 섹터는 **왜** 안 나왔나

국내 섹터를 `sectorOf()` **하나로만** 찾았다. 그건 손으로 관리하는 사전이고 **80종목**뿐인데
픽 유니버스는 **760종목**이다.

```
프로덕션 실측 (2026-09-03, 15장)
  섹터 있음   2장  (네패스 반도체 · Agree Realty 부동산)
  섹터 없음  13장  (86.7%)
```

**신뢰도 게이트가 거른 것도, 표시 로직이 빠뜨린 것도 아니었다 — 찾을 곳이 하나뿐이었다.**
(WO 가 의심한 「과한 조치」는 아니었다. 게이트는 테마 라벨만 막고 있고 그건 옳다.)

팩트시트는 `classification.industry` 를 종목별로 들고 있고 **452종목**을 덮는다.
**이미 읽어둔 데이터다.** 사전이 못 찾으면 거기서 받는다.

```
반도체와반도체장비 → 반도체        (sectorDisplayName 표)
게임엔터테인먼트   → 게임
손해보험          → 손해보험       (표에 없으면 원문 그대로)
```

원문은 분류용 이름이라 화면에 그대로 쓰면 넘치거나 안 읽힌다. `sectorDisplayName` 이
표시명으로 옮기고, **표에 없으면 원문을 그대로 쓴다 — 모르면 지어내지 않는다.**

### 섹터 신뢰도 판정 기준 (완료조건 7)

정본 구현: `apps/fomo-web/lib/sectorTrust.ts`. 아래 하나라도 걸리면 **섹터 줄을 그리지 않는다.**

| # | 기준 | 왜 |
|---|---|---|
| 1 | **테마·거시 라벨** (`코인`·`환율`·`금리`·`유가`·`국채`·`지수`·`원자재`·`달러`·`관세` 등, 부분 일치) | 회사의 업종이 될 수 없다. 실측: 한화투자증권 → `코인`, On Holding → `화학` |
| 2 | **폴백 라벨** (`기타 업종`·`기타`·`미국주식`·`미분류`·`N/A`·`-`) | 섹터 자리를 채우려고 만든 말이라 정보가 0이다 |
| 3 | **20자 초과 · 빈 값** | 섹터가 아니라 문장이다 |

서버(`companyIdentity`)도 같은 차단 목록(`NON_SECTOR_LABELS`)과 20자 상한을 폴백에 적용한다 —
**틀린 섹터를 보여주느니 안 보여주는 게 낫다.** 화면은 시총·거래 규모로도 회사 규모를 전한다.

## 보고할 것 3 — 나무위키 툴팁 원인

**우리 코드에 없다.** 실측:

```
소스 전수 검색 (ts·tsx·js·json·css·html)   `namu` 0건
빌드 산출물 검색                            1건 → `NaMUQsb` (Next.js 벤더 청크 난독화 식별자)
우리가 참조하는 외부 호스트 전수            dart.fss.or.kr · ssl.pstatic.net · t1.kakaocdn.net ·
                                           assets.parqet.com · eodhd.com · financialmodelingprep.com ·
                                           raw.githubusercontent.com · 우리 백엔드 — **위키 없음**
```

`title` 속성으로 만든 툴팁도 없고(`title=` 은 전부 React 컴포넌트 prop 이다),
`dangerouslySetInnerHTML` 도 없다.

캡처된 문구 「완성형/특수 문자 - 나무위키」는 나무위키의 **완성형 특수문자 문서**다.
우리 화면은 `·` `→` `★` `○` 를 쓰는데 그 문서가 다루는 문자들이 정확히 그것이다.
**브라우저 확장(사전·위키 조회) 또는 OS 사전 조회**가 문자 선택·호버에 반응한 것으로 본다.

**확인 방법**: 확장 없는 새 프로필(시크릿 창)에서 같은 화면을 연다. 거기서 안 뜨면 환경이다.
지금은 재현 수단이 없어 **환경으로 판단하고 코드 변경은 하지 않았다** — 없는 원인을 고칠 수 없다.

## PART B — 중복 지우기

### `시장 대비 3일 연속 · 3일 연속` 의 정체

```ts
const buy = [actor, scale].filter(Boolean).join(" ");           // "시장 대비 3일 연속"
const withDays = days > 0 ? [buy, `${days}일 연속`].join(" · ") : buy;
//                                                              → "시장 대비 3일 연속 · 3일 연속"
```

`market_divergence` 는 `scale` 에 **기간**을 넣는다(`3일 연속`) — 규모가 없는 형이라 그 자리를
기간으로 채운 것이다. 그 뒤에 `days` 로 같은 말을 또 붙였다.

**더 나쁜 것은 라벨이다.** `매수 | 시장 대비 …` — **`시장 대비` 는 아무것도 사지 않는다.**
`why-now.ts` 가 같은 함정을 이미 적어 뒀다(`시장 대비이 사기 시작했어요` 방지).

### 왜 화면이 이 형을 구분할 수 없었나

프론트 타입 `QuietPickSignalKind` 에 **WO-RESET-03 이 추가한 두 형이 없었다.**
서버는 `market_divergence`·`volume_awakening` 을 내려주는데 화면 타입은 4종만 알고 있었다.
`signalFacts` 의 `indexChangePct`·`stockChangePct`·`indexLabel` 도 서버는 보내는데 타입에 없었다.

**베끼면 갈라진다** — 이제 `@fomo/core` 타입을 타입 전용으로 재수출한다(번들 영향 0).

### 바꾼 것

| 형 | 종전 | 지금 |
|---|---|---|
| `market_divergence` + 실수치 | `매수 \| 시장 대비 3일 연속 · 3일 연속` | `기간 \| 최근 3거래일` · `이 종목 \| +36.3%` · `코스닥 \| -3.3%` · `차이 \| 39.6%p` |
| `market_divergence`·`volume_awakening` (실수치 없음) | 같은 중복 | `기간 \| 최근 3거래일` 만. **`매수` 라벨을 쓰지 않는다** |
| 주체 있는 형 | `임원 3명 $2.8M · 5일 연속` | 그대로. `scale` 이 이미 기간을 담고 있을 때만 연속일수를 뺀다 |

훅이 이미 말한 종목 수익률은 `이 종목` 줄로 반복하지 않는다.

### ⚠️ B-1 을 **그대로** 적용하지 않은 곳 — 광혁 확인 필요

WO B-1 은 「한 화면에 같은 숫자가 두 번 나오면 안 된다」다. 이것을 문자 그대로 적용해
**훅과 겹치는 숫자를 근거 줄에서 전부 지웠더니 e2e 가 잡았다**:

```
훅    임원 3명이 5일 새 함께 매수
종전  매수 | 임원 3명 $2.8M · 5일 연속
전부 지운 결과  매수 | $2.8M          ← 줄이 무너진다
```

`임원 3명` 과 `5일` 둘 다 훅에 있으므로 규칙대로면 `$2.8M` 만 남는다. 그런데 이 줄의 일은
WO-HOOK-02 §3 이 정한 **「수치 확인」**이다 — 훅을 읽고 "진짜야?" 로 들어온 사용자에게
같은 값을 다시 확인해 주는 자리다.

그래서 **주체 있는 형에서는 훅 중복을 허용**했다. B-1 을 문자 그대로 적용할지는
카피·UX 결정이라 광혁 몫으로 남긴다. 지금 막은 것은 **같은 렌더 문자열이 한 줄에 두 번
나오는 것**과 **틀린 `매수` 라벨**이다.

## PART D — 기간 표시

```
종전   9,850원  -10.4%          ← 오늘치인데 표시 없음
       (훅) 혼자 36.3%          ← 여러 날치인데 표시 없음
```

## PART E — 빈 화면

내용을 억지로 만들지 않는다(WO 「하지 말 것」). **배치로 푼다.**

```
스크롤 컨테이너   flex flex-col   (min-h-0 flex-1 overflow-y-auto 유지)
본문              my-auto
```

여유 공간이 있으면 auto 마진이 나눠 가져 중앙에 오고, 내용이 화면보다 크면 auto 가 0 으로
풀려 위에서 시작하고 스크롤된다. `justify-center` 는 **두 번째 경우에 위쪽이 잘려서** 쓰지 않는다.

**래퍼를 끼우면 안 된다** — `depth-scroll` 의 `lastElementChild` 가 본문이어야 DS-07 §3
(마지막 줄이 하단 바를 비켜간다) 측정이 성립한다. 래퍼를 넣었더니 그 e2e 가 깨졌다.

로컬 실측(2걸음): 컨테이너 756px · 하단 패딩 112px · 본문 515px → 위 여백 64px = 정확히 중앙.
