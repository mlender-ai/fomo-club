> 함께 바꾼다. 지시: 2026-09-04 광혁 — "「어떤 회사인가」에 회사 설명이 나오고, 업종 비교가 맞다."

## 0. 먼저 확인한 것 — 원인이 넷 다 갈렸다

지시서가 「확인」을 요구한 자리를 **실측으로 먼저 닫았다.** 추측으로 고치면 엉뚱한 데를 고친다.

| 증상 | 실측 결과 | 원인 |
|---|---|---|
| 0-1 회사 설명 없음 | **국내 12/12 종목이 200자 넘는 요약을 갖고 있었다.** 화면에 나온 건 5종목 | **우리가 버렸다** — 아래 A |
| 0-1 미국 설명 없음 | 나스닥에 설명이 **3/3 있다**(884·924·126자). 우리 응답은 **0/3** | 번역 단계 실패 — 아래 A-4 |
| 0-2 업종 평균 = 자기 값 | 5종목 게이트가 **그룹 크기**만 봤다 | **지표별 표본을 안 봤다** — 아래 B |
| 0-4 섹션 들쭉날쭉 | 빈 덩어리를 서버가 **말없이 뺐다** | 아래 D |

## PART A — 회사 설명 (A-1 확인 결과: **데이터가 아니라 우리 필터**)

벤더 요약은 언제나 이 순서다 — **답이 맨 끝에 있다**:

```
① 동사는 1990년 대원공업으로 설립되었으며 … 2023년 유가증권시장에 상장됨.      ← 연혁
② 연결대상 종속회사로 비상장 3개사를 보유하며, 미국 법인을 운영하고 …           ← 지배구조
③ 동사는 강관의 생산과 판매가 주요사업으로, OCTG, 송유관, … 수출·판매하고 있음.  ← 이것이 답
```

`rewriteCompanySummary` 는 **원문 순서대로 훑다가 두 문장을 채우면 멈췄다.** ①은 연혁이라
버려도 ②가 통과해 자리를 차지하고 ③에는 **도달하지 못했다.** 그 뒤 화면 필터(`companyBlurb`)가
②를 연혁으로 다시 버리니 남는 게 없어 **설명이 사라졌다.**

두 번째 함정도 같은 뿌리였다: 길이 초과 시 `kept.pop()` 으로 **배열 끝**을 잘랐다 —
고른 문장을 원문 순서로 늘어놓으면 사업 문장이 끝에 오므로 **정작 필요한 문장이 날아갔다.**

### 고친 규칙

| 규칙 | 구현 |
|---|---|
| **위치가 아니라 내용으로 고른다** | 문장마다 점수(무엇을 파는가 +2 · 사업 낱말 +1 · 사업부·제품 +1 · 연혁 −1 · 계열사 −1), 높은 것부터 둘, **원문 순서로 되돌려** 출력 |
| 연혁은 **더 나은 문장이 있으면 아예 안 쓴다** | A-3 「설립·상장 연도 금지」 |
| 지배구조만 말하는 문장은 버린다 | A-3 「계열사 수 금지」 — 실측에서 `대한항공`·`유진기업` 설명 자리를 계열사 나열이 차지했다 |
| 길이 초과 시 **점수 낮은 문장**을 버린다 | 배열 끝을 자르지 않는다 |

### 실측 결과 (보고할 것 1)

| | 요약 원문 | 화면에 나온 설명 |
|---|---|---|
| 국내 12종목 | **12** | 5 → **12** (고친 뒤) |
| 미국 3종목 | 0 (우리 응답) / **3** (나스닥 원문) | 0 |

국내 12종목 전부가 「무엇을 파는가」로 시작한다:
`강관의 생산과 판매가 주요사업으로 …` · `주요 사업은 식자재 유통 …` ·
`스티렌, 자이데나 … 전문의약품을 제조·판매하며 …` · `이동통신 사업부는 무선망 최적화 …`

### A-4. 미국은 소스가 아니라 **우리 파이프라인**이 막혀 있다

`getUsCompanyAbout` 은 나스닥 `company-profile` 의 영문 설명을 **LLM 으로 한국어 요약**해
영구 캐시에 넣는다(영문 원문 노출 금지 정책 때문에 번역이 필수다). 실측:

```
UAMY  884자 · ANGX  924자 · AVBC  126자   ← 소스에는 있다
우리 stock-basics 응답: 3/3 summary 없음   ← 번역·캐시 단계에서 끊긴다
```

**이 배치에서 고치지 않았다.** 캐시가 DB(`DATABASE_URL`)에 있어 로컬에서 그 경로를 실행할 수
없고, 실패 원인(LLM 레이트리밋 429 · 요청 경로 9초 타임아웃)은 **요청 시점에 고칠 수 있는
것이 아니다.** 다음 배치 후보는 **백필 스크립트**다(요청 경로 밖에서 재시도하며 캐시를 채운다) —
`disclosure-figures` 백필과 같은 모양이면 된다. SEC 10-K Item 1 파싱(A-4 대안)은 그보다 크다.

## PART B — 업종 평균이 자기 자신이었다

### B-1 확인 결과 — 원인은 **하나가 아니라 둘**

```
① 5종목 게이트를 `rows.length`(그룹 크기)에만 걸었다.
   중앙값은 **그 지표를 가진 종목만**으로 낸다 → 6종목 그룹에서 pbr 을 가진 종목이
   하나뿐이면 그 하나가 중앙값이다. 그 하나가 조회 종목이면 **자기와 자기를 견준다.**
② 표본에서 자기 자신을 빼지 않았다. `다른 은행 12곳 평균` 이라고 말할 수 없었다.
```

Pinnacle Financial 의 `PBR 1.02배 = 업종 중간값 1.02배` 와 `부채비율 770.3% = 중간값 770.3%` 가
이 둘로 설명된다 — **두 지표가 동시에 같았던 것**이 ①의 지문이다(둘 다 표본이 자기 하나).

### 고친 것

| 규칙 | 구현 |
|---|---|
| 게이트를 **지표별 표본 수**로 옮긴다 | `SectorStat` 이 중앙값을 미리 굳히지 않고 **표본 목록**을 든다 |
| **자기 자신을 뺀다** | `sectorComparison(candidates, metric, own)` — 같은 값 **하나만** 지운다 |
| 5곳 미만이면 상위 분류 → 그래도 모자라면 업종 비교 안 씀 | 후보를 `[industry, sector]` 로 넘기고 지표별로 사다리를 탄다 |
| **몇 곳과 견줬는지 밝힌다** | `다른 은행 12곳 평균 1.31배보다 낮아요` (B-4) |

표본 목록은 **굽는 경로 안에만 있다** — 페이로드에 실리지 않는다(화면에 가는 것은 문장이다).

## PART C — 업종마다 다른 기준

### C-2. B 를 제대로 하면 대부분 풀린다

`다른 은행 12곳 평균 812%보다 낮아요` 는 `770%` 를 무서운 숫자가 아니게 만든다.

### C-3. 은행에는 **부채비율을 쓰지 않는다**

지시서가 남긴 선택지(자기자본비율 확보 가능하면 그것, 아니면 섹션 생략) 중 **첫 번째**를 골랐다.
확보 가능하기 때문이다 — 팩트시트에 총자산 항목은 없지만 `debt_to_equity` 하나로 나온다:

```
자산 = 자기자본 + 부채  →  자기자본비율 = 1 / (1 + 부채/자기자본)
부채비율 770.3%  →  자기자본비율 11.5%
```

**새 수집이 없다.** 금융 업종(은행·저축은행·증권·자산운용·보험·리츠·여신 …)일 때만 바꾼다.
자기자본비율은 부채비율의 단조 감소 변환이라 **비교 방향이 그대로 뒤집힌다**(빚이 적으면
자기자본비율이 높다) — 문장은 변환된 값으로 만들므로 저절로 맞는다. 왜 다른 지표를 쓰는지는
계산 방법 줄이 밝힌다(`은행·보험은 예금이 부채로 잡혀 …`).

## 보고할 것 — 못 잰 것은 못 쟀다고 적는다

| 항목 | 결과 |
|---|---|
| 1. 회사 설명 확보율 | **국내 5/12 → 12/12** · **미국 0/3**(소스에는 3/3 있다, A-4) |
| 2. 업종별 종목 수 분포 | **유니버스 전수는 못 쟀다** — 팩트시트가 DB(`DATABASE_URL`)에 있어 로컬에서 못 읽는다. 오늘 덱 페이로드에서는 업종 비교가 붙은 종목이 **1개**였고 그 모수는 `바이오 9종목`이었다. 전수 분포는 배포 후 `companyPeers` 로 센다 |
| 3. 업종 평균 = 자기 값 종목 수 | 오늘 덱 페이로드에서 **0건**(비교가 1건뿐이라 표본이 작다). 원인은 코드에서 확정했고 테스트로 고정했다 — 배포 후 `companyPeers.min` 이 5 이상인지로 재확인 |
| 4. 섹션별 확보율 | 배포 후 `companySections` 로 센다. 고치기 전 페이로드는 16종목에서 덩어리 **12개**(= 종목당 0.75개)였다 |

## 하지 말 것

1. **회사 설명 없이 「어떤 회사인가」를 보여주지 않는다** — 다만 설명이 없으면 그 줄만 빠지고 재무는 그대로다(A-3).
2. **자기 자신을 포함한 업종 평균을 쓰지 않는다.**
3. **종목 수가 적은데 억지로 비교하지 않는다** — 5곳 미만이면 5년 밴드로 간다.
4. **섹션을 말없이 빼지 않는다.**
5. **은행에 부채비율을 그대로 보여주지 않는다.**
