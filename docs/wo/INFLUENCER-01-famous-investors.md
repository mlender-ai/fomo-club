# INFLUENCER-01 — 유명 투자자 포트폴리오

> 정본은 이 문서다. 코드(`packages/fomo-core/src/keyword-cards/investor-holdings.ts` ·
> `apps/web/lib/investor-collect.ts` · `apps/web/app/api/fomo/investors/[id]/route.ts` ·
> `apps/fomo-web/components/QuietPickDepth.tsx`)와 함께 바꾼다.
> 지시: 2026-09-07 광혁 — "인물 카드가 덱에 나오고, 포트폴리오 전체를 볼 수 있다."

## PART A — 왜 미착수였나 (**답: 미착수가 아니었다**)

지시서의 세 갈래(코드가 있나 / 크론에 안 붙었나 / 아예 없나)에 **어느 것도 해당하지
않았다.** 파이프라인은 다 있고 **매일 돌고 있다.** 두 곳이 막혀 있었다.

| 층 | 상태 | 증거 |
|---|---|---|
| 수집 코드 | **있다** | `investor-collect`(ARK CSV 4펀드 + 13F 12명) · `investor-store` · `investor-holdings` |
| 크론 | **매일 성공** | `investor-collect.yml` 08:20 KST · 최근 5회 연속 success |
| 신호 생성 | **있다** | `detectInvestorSignals` → `investor_move` |
| 카드 형·그림 | **있다** | `investorCard`(F형) + `WeightGauge` 비중 게이지 |
| 덱 상한 | **있다** | 40% · 13F 시즌 60% · 같은 인물 2장 (`deck-ranking`) |
| ARK 데이터 | **온다** | 90종목(4펀드 합산), asOf 2026-09-04 |
| **13F** | **프로덕션 전멸** | 5명 전부 실패. **로컬에서는 정상**(버핏 28종목·테퍼 19·콜먼 35) |
| **카드 후보** | **0** | 90종목 중 주식 수 2% 이상 변한 것 **0개**(최대 1.6%), 신규·전량매도 0 |
| **화면** | **없었다** | 상세·인물 페이지 어디에도 인물 렌더 코드가 없었다 |

### ① 카드 후보 0 — 임계가 아니라 **재료의 성질**이 문제였다

2026-09-07 수집 응답 그대로:

```
cathie-wood: holdings 90 · hasPrior true · fresh true · changes 0
changeDistribution: total 90 · over2 0 · over5 0 · over20 0 · max 1.6 · new 0 · exited 0
```

**임계(20%)를 낮추는 것은 답이 아니다.** ETF 는 자금 유출입만으로 전 종목 주식 수가 매일
조금씩 움직이고(그래서 이 임계가 있다), `0.5% 늘렸어요` 는 카드가 아니다.

레퍼런스가 후킹으로 쓴 것도 변화가 아니라 **비중 그 자체**였다(`$SNDK 28.1%`).
그래서 **큰 비중** 카드 종류를 더했다(지시서 C-2 마지막 줄) — 변화가 없는 날에도
「이 사람이 무엇을 크게 들고 있나」는 말할 수 있다.

**4% 하한은 실측에서 골랐다** (ARK 4펀드 합산 90종목, 2026-09-04):

```
TSLA 7.1 · CRCL 4.9 · TEM 4.6 · SPCX 4.5 · COIN 4.1 · HOOD 4.0 · CRSP 3.8 · SHOP 3.7
  10% 이상 0종목 · 7% 이상 1 · 5% 이상 1 · 4% 이상 6 · 3% 이상 10
```

레퍼런스의 `28%` 같은 집중 포지션은 ARK 에 **없다**(ETF 라 분산돼 있다). 5% 로 두면 후보가
TSLA 하나뿐이고, 유니버스에 없는 티커 하나만 걸러도 0장이 된다. 3% 로 내리면
`포트폴리오의 3.0%를 담고 있어요` 가 나가는데 그건 「크게 담았다」로 읽히지 않는다.

유니버스 게이트까지 통과한 실측: **4종목**(TSLA·SPCX·COIN·HOOD) → 같은 인물 상한이
그중 **2장**을 덱에 올린다.

### ② 비교 창이 주말에 쪼그라들었다

`pickComparisonSnapshot(history, today, 5)` 가 **수집 실행일**에서 5일을 셌다. ARK 파일은
미국 장 마감 뒤 나오므로 월요일 아침 실행에서 최신이 금요일자면 창이 `금 ~ (오늘-5일)` 로
**2거래일**이 된다. → **최신 데이터 날짜 기준**으로 세도록 고쳤다(창이 항상 같은 폭).

### ③ 13F — 로컬은 되고 프로덕션은 안 된다

프로덕션 수집 오류: `sec: company_tickers 조회 실패` · `warren-buffett: 13F 조회 실패` ·
애크먼·버리·테퍼 동일. **같은 코드를 로컬에서 돌리면 전부 성공한다**:

```
warren-buffett   기준 2026-08-14 · 보유 28 · 미해결 0
david-tepper     기준 2026-08-14 · 보유 19 · 미해결 8
chase-coleman    기준 2026-08-14 · 보유 35 · 미해결 11
michael-burry    기준 2025-11-03 · 보유 8  · 미해결 0
```

ARK CDN 은 프로덕션에서도 되고 **SEC 만 전부 실패**한다 → SEC 가 Vercel 런타임의 아웃바운드를
막고 있다고 본다(UA 문자열 문제가 아니다 — 코드의 기본 UA 로 로컬에서 200 이 온다).

**이 배치에서 고치지 않았다.** 고치는 길은 수집 위치를 옮기는 것이다:
GitHub Actions 에서 SEC 를 받아(위 로컬 성공이 그 증거다) 인증된 적재 엔드포인트로 밀어넣는
방식이다. 워크플로가 이미 있으므로 단계 하나를 더하는 일이지만 **쓰기 창구가 생기는
변경**이라 광혁 판단이 필요하다.

## PART C — 카드 (이미 있었다 + 큰 비중 훅 추가)

훅·보조 줄·비중 게이지가 전부 있었다. 큰 비중 종류만 더했다:

```
캐시 우드가
포트폴리오의 7.1%를 이 종목에 담고 있어요
[비중 게이지]
9월 4일 기준 보유 · 207만주 · $780M
ARK 전체의 7.1%
```

**「샀어요」로 쓰지 않는다** — 오늘 산 것이 아니라 크게 들고 있는 것이고, 그 둘을 섞으면
없는 매매를 말하는 것이 된다. 보조 줄도 `공시` 가 아니라 `기준 보유` 라고 쓴다.
인물 사진은 쓰지 않는다(§C-3) — e2e 가 `img` 0개를 고정한다.

## PART D-2 — 「이 사람은 요즘 뭘 사나」 (신규)

```
캐시 우드는 요즘
ARK · 9월 4일 기준 · 8월 28일과 비교

최근 산 것    TTMI  TTM TECHNOLOGIES   새로 샀어요
             TSLA  TESLA INC          더 샀어요
최근 판 것    ZM    ZOOM COMMUNICATIONS 전부 팔았어요
상위 보유     TSLA 7.1% · CRCL 4.9% · TEM 4.6%
             전체 포트폴리오 보기 (90종목)
```

- 매매가 하나도 없는 날은 **그 사실을 쓴다**(`8월 28일 이후로는 사고판 게 없어요`) —
  빈 섹션을 만들지 않고, 고장이 아니라는 것을 말해야 한다.
- 변화 판정·상위 보유는 **카드·덱이 쓰는 것과 같은 함수**(`diffHoldings`·`topWeightHoldings`)로
  낸다. 화면과 카드가 다른 규칙으로 같은 것을 말하는 일을 막는다.

## PART E — 인물 페이지 (신규)

`전체 포트폴리오 보기` → **상세 안에서 열리는 한 겹**이다(별도 탭 금지, WO 하지 말 것).

```
←  캐시 우드
   ARK · 9월 4일 기준
   보유 종목 90개 · 총 자산 $6.2B · 그 사이 샀어요 2종목 · 팔았어요 1종목
   TSLA  TESLA INC              7.1%   +0.3%p
   CRCL  CIRCLE INTERNET GROUP  4.9%   -0.8%p
   TEM   TEMPUS AI              4.6%
```

| 규칙 | 구현 |
|---|---|
| 정렬 | 비중 순 |
| 변화 | 직전 공시 대비 %p. **없으면 칸을 비운다** — 대시를 값처럼 두지 않는다(DS-05 §3) |
| 종목 탭 | 오늘 덱에 있는 종목만 열린다. 못 여는 줄은 **눌리지 않는다** |
| 위치 | 상세 위 `z-90` — 하단 바(`z-80`)가 이 화면 위로 뚫고 나오지 않는다(FIX-03 PART C 와 같은 종류의 사고를 미리 막는다) |

90종목을 픽 페이로드에 넣지 않는다 — **상세를 열 때 받는다**(`/api/fomo/investors/[id]`).
같은 인물 카드가 여러 장 있어도 복제되지 않고, 인물 카드를 안 여는 사용자에게는 실리지 않는다.

## 보고할 것

### 1. 왜 미착수였나

**미착수가 아니었다.** 수집·신호·카드 형·덱 상한이 전부 있고 크론도 매일 성공한다.
막힌 곳은 둘 — **카드 후보 0**(ARK 일별 변화가 임계 미달)과 **화면 없음**(상세·인물 페이지).
여기에 **13F 프로덕션 접근 실패**가 겹쳐 인물이 사실상 ARK 하나였다.

### 2. 인물별 데이터 확보 가능 여부와 주기

| 인물 | 소스 | 주기 | 프로덕션 | 로컬 검증 |
|---|---|---|---|---|
| 캐시 우드(ARK) | ARK CSV 4펀드 | **매일** | ✅ 90종목 | ✅ |
| 워런 버핏 | 13F | 분기 | ❌ SEC 실패 | ✅ 28종목(2026-08-14) |
| 데이비드 테퍼 | 13F | 분기 | ❌ | ✅ 19종목 |
| 체이스 콜먼 | 13F | 분기 | ❌ | ✅ 35종목 |
| 마이클 버리 | 13F | 분기 | ❌ | ✅ 8종목(2025-11-03 — 오래됨) |
| 빌 애크먼 | 13F | 분기 | ❌ | ✅ 8종목(2026-05-15) |
| 미 의회 · 국민연금 | STOCK Act · 대량보유 | 수시 | **미구현** | — |

13F 는 **코드가 아니라 실행 위치**가 문제다(위 PART A ③).
개인 공개 포트폴리오는 쓰지 않았다(§B-2: 공시 기반만).

### 3. 하루 평균 인물 카드 발생 수

**2장** — 큰 비중 후보 6종목 중 유니버스 통과 4종목, 같은 인물 상한(2장)이 그중 둘을 올린다.
변화 카드는 그날 ARK 가 실제로 매매했을 때 더해진다(실측일에는 0건).
13F 가 살아나면 시즌(2·5·8·11월 중순)에 인물 수만큼 늘고 상한이 60%까지 열린다.

## 하지 말 것

1. **인물 사진을 쓰지 않는다.**
2. **`따라 사세요` 류를 쓰지 않는다** — 벌어진 일만 말한다.
3. **개인이 공개한 포트폴리오를 쓰지 않는다**(공시 기반만).
4. **별도 탭을 만들지 않는다** — 인물 페이지는 상세 안의 한 겹이다.
5. **공시 지연을 숨기지 않는다** — 날짜를 그대로 쓴다(`9월 4일 기준`).
6. **큰 비중을 「샀어요」로 쓰지 않는다** — 상태와 매매는 다르다.
