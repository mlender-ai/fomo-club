# 표시명·영향표 사람 검토 초안 (LAUNCH-P1 §D)

> 에이전트가 초안을 내고 **사람이 검토하는 목록**이다. 검토 전까지는 원본 그대로 나가되,
> 그 사실을 여기 적는다(§D-1).

실측일: 2026-09-08 · 근거: 거래소 벤더 업종 API 전수(79개 업종 · 3,180종목) + 프로덕션 페이로드

---

## 0. 먼저 — 표에 적힌 개수가 실측과 다르다

지시서 §D 의 표는 「국내 78 · 미국 23 초안 대기」였다. 실측 결과는 다르다.

| 표 | 지시서 | 실측 | 무엇이 달랐나 |
|---|---|---|---|
| 국내 업종 표시명 | 78건 대기 | **0건 필요** | 79개 중 50개는 이미 표시명이 있고, 남은 29개는 **전부 상한(7자) 안**이다 — 자를 일이 없으므로 원문이 곧 표시명이다 |
| 미국 업종 표시명 | 23건 대기 | **0건 노출 중** | 오늘 페이로드 `untranslatedIndustries` = **빈 배열**. 표에 없는 이름이 화면에 나간 건이 없다 |
| 공시 제목 번역 | 완료(95.8%) | 같음 | 후속 PR #1216 이 머지되면 프로덕션에서도 95.8% |
| 지표별 영향 업종 | 대기 | **대기**(아래 §3) | 사람 검토가 실제로 필요한 유일한 표다 |

**즉 급한 것은 업종 표시명이 아니라 §2 의 「기타」 문제와 §3 의 영향표다.**

## 2. 「기타」 389종목 — **표시명 문제가 아니라 분류 문제였다** (조치 완료)

실측 중 찾은 것이다. 벤더 업종 79개 중 **가장 큰 것이 `기타`(389종목)** 다.

```
389종목  기타        ← 업종이 아니다. 벤더가 「분류 못 함」을 담는 자리다
171종목  제약
154종목  자동차부품
```

우리 규칙은 「모르는 종목을 기타로 묶지 않는다」였는데, **벤더가 이미 묶어서 보내고 있었다.**
얇은 업종 기준(5종목)을 가볍게 넘으므로 어느 날 카드가 이렇게 말할 수 있었다:

```
기타에서 돈이 빠지고
무역으로 들어오고 있어요     ← 아무 뜻도 없는 카드
```

**조치**: `isPlaceholderSector()` 로 `기타` · `기타업종` · `미분류` · `분류없음` 을 미분류로
세고 버린다(집계·일별 원장 양쪽). `기타금융` · `기타제조` 는 실제 업종이라 살린다.

> 검토 요청: 이 네 이름 말고 벤더가 쓰는 자리표가 더 있는지 — 사람이 목록을 확인해 주면 좋다.

## 3. 지표별 영향 업종 — **사람 검토가 필요한 표** (코드에서 그대로 옮김)

예측이 아니지만, **방향이 틀리면 카드가 통째로 거짓이 된다.**

### 검토 방법

**한 줄씩 「반대로 말해도 그럴듯한가」를 본다.** 그럴듯하면 그 줄을 지운다 — 애매한 원리는
카드에 쓰지 않는 것이 맞다. 특히 사람이 봐 줄 자리 셋:

| 줄 | 왜 봐야 하나 |
|---|---|
| `usdkrw` 불리에 **식품** | 원재료 수입 비중이 근거인데, 내수 식품은 환율보다 원자재 가격이 먼저다 |
| `oil` 유리에 **조선** | 해양 발주 논리인데 유가와 발주 사이 시차가 길다 |
| `jpykrw` 불리에 **호텔,레스토랑,레저** | 엔저 = 일본 여행 증가라는 논리인데, 국내 레저에는 반대로 작용할 수도 있다 |

## 4. 미국 업종 표시명 101종 — 검토는 남아 있다 (급하지 않다)

FIX-01 에서 자동 생성한 표다. 오늘 화면에 나가는 미번역 이름은 0건이지만, **표 자체의
오역 가능성은 사람이 봐야 한다.** 우선순위는 낮다 — 미국 종목이 덱에 올라오는 날에만 보인다.

우선 검토 대상(미국 픽에 자주 나오는 순): `Semiconductors` · `Biotechnology` ·
`Software—Infrastructure` · `Banks—Regional` · `Oil & Gas E&P` · `Aerospace & Defense` ·
`Medical Devices` · `Specialty Retail` · `Asset Management` · `REIT—Industrial`.
