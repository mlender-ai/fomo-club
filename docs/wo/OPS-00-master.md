## 2. 문서

| ID | 제목 | 마감 | 담당 |
|---|---|---|---|
| `OPS-01` | **오늘 밤 — 24시간 가동** | **오늘 밤** | **광혁 + 에이전트** |
| `OPS-02` | 주식 트랙 복구 | **KR 월 09:00 · US 월 22:30 (KST)** | 에이전트 |
| `OPS-03` | 가동 감시 · 자산 표시 | 화요일 | 에이전트 |

```
오늘 밤    OPS-01 ─────────────▶ 크립토·고래 24시간
월 아침    OPS-02 ─────────────▶ 주식 KR·US 재개
화         OPS-03 ─────────────▶ 멈추면 바로 안다

금         ENG-02 ─────────────▶ 엔진이 스스로 실험
다음 주    OPS-04 ─────────────▶ 맥 없이 돈다
```

**OPS-01이 안 되면 나머지는 다 무의미하다.** 먼저 끝낸다.

## 3. "내일 아침부터 모든 게" — 되는 것과 안 되는 것

| 트랙 | 내일 아침 | 이유 |
|---|---|---|
| 크립토 | ✅ | OPS-01만 되면 |
| 고래 추종 | ✅ | OPS-01만 되면 |
| 주식 KR | ✅ 목표 (09:00) | 봉 불일치 원인이 작으면. 크면 오후 |
| 주식 US | ✅ 목표 (22:30 KST) | KR과 같은 뿌리 |
| **폴리마켓** | **❌** | **지역 차단. 우회하지 않는다.** 제외 유지 |

**폴리마켓을 VPN·해외 서버로 우회하지 않는다.** 서비스 약관 위반이고, 나중에 실매매할 때 계정이 막힐 수 있다.

## 4. 실매매로 넘어가는 조건

"자동매매로 자산이 늘고 줄어드는 것" — **지금은 페이퍼다.** 실제 돈은 아래가 **전부** 충족돼야 한다.

| # | 조건 | 지금 |
|---|---|---|
| 1 | 24시간 가동 **30일 연속** · 유효일 ≥ 90% | 37% |
| 2 | 강제청산 모델 반영 (ENG-01) | ❌ |
| 3 | 기준선을 넘은 트랙 ≥ 1 · **우연 확률 < 20%** · 거래 ≥ 100 | 0개 |
| 4 | 페이퍼 결과가 백테스트와 크게 어긋나지 않음 | 미확인 |
| 5 | 킬 스위치 — 일 손실 한도 · 총 손실 한도 넘으면 전 트랙 정지 | ❌ |
| 6 | 거래소 키 분리 — 조회용 · 주문용 따로, 출금 권한 없음 | 미확인 |
| 7 | 시드 금액 — **광혁이 정한다** | 미정 |

**하나라도 빠지면 실매매하지 않는다.** 이 표는 연구 탭에 `실제 돈을 넣으려면` 블록으로 이미 있다 — 이 7개로 갱신한다.

## 5. 원칙

1. **완료는 가동으로 판정한다.** 머지도 배포도 완료가 아니다. **재부팅 후에도 도는 것**이 완료다
2. **토큰·키는 사람이 넣는다.** 에이전트는 명령만 준다. 자리표시(`…`)를 그대로 두지 않는다 — 지난번 그걸로 러너가 전부 실패했다
3. **invariant는 끄지 않는다.** 원인을 고쳐서 통과시킨다
4. **옛 주문을 지금 가격에 체결하지 않는다.** 성과가 오염된다
5. **엔진 개선은 자동 적용하지 않는다.** 검증은 자동, 적용은 사람

## 6. 매일 아침 확인 (광혁)

```
□  헤더 동기화 점이 초록인가
□  트랙 4개가 전부 ● 운용중인가
□  밤사이 거래가 있었나
□  어제 유효일이었나 (커버리지 ≥ 90%)
```

하나라도 아니면 에이전트에게 그 화면을 보낸다.
