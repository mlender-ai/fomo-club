## PART A — 심장박동

### A-1. 트랙별 마지막 틱

| 대상 | 기준 | 넘으면 |
|---|---|---|
| 크립토 | 30분 | 🔴 알림 |
| 고래 추종 | 30분 | 🔴 알림 |
| 주식 KR | **장중에만** 30분 | 🔴 알림 |
| 주식 US | **장중에만** 30분 | 🔴 알림 |
| FCE 데몬 | 10분 | 🔴 알림 |
| 러너 업로드 | 30분 | 🔴 알림 |
| 시세 수집 | 10분 | 🟠 알림 |

**주식은 장외 시간에 알림을 내지 않는다.** 밤마다 "KR 멈춤" 알림이 오면 아무도 안 본다.

### A-2. 누가 확인하나

**맥 밖에서 확인한다.** 맥이 죽으면 맥 안의 감시도 같이 죽는다.

```
Vercel 크론 (5분)
  → DB에서 트랙별 마지막 틱 확인
  → 기준 넘으면 텔레그램
```

### A-3. 알림 문구

```
🔴 크립토 트랙 42분째 멈춤
마지막 틱 14:08 · 러너는 살아 있음
→ FCE 데몬 확인: launchctl list | grep fce
```

**무엇이 · 얼마나 · 뭘 해보면 되는지.** 세 줄.

### A-4. 복구 알림

```
🟢 크립토 트랙 복구 · 멈춤 51분
```

### A-5. 반드시 시험한다

```
1  러너를 일부러 멈춘다
2  30분 안에 알림이 오는지 본다
3  다시 올리고 복구 알림이 오는지 본다
```

**시험 안 한 알림은 없는 것과 같다.** 이 프로젝트에서 알림을 걸어만 두고 안 온 적이 있다.

## PART B — 아침 리포트

매일 **07:30 KST** 텔레그램.

```
☀️ 9월 28일 아침

어제 유효일  ✅ 크립토 98% · 고래 98% · KR — · US —

자산 (트랙당 $10,000 환산)
  $46,515 → $46,702   +$187 (+0.40%)

밤사이
  진입 3 · 청산 2 · 승 1
  고래 추종 BABAUSDT 숏 청산 +2.1%

멈춘 것  없음

연구
  02 강제청산 — 모델 반영 완료, 재채점 중
```

**FCE 기존 텔레그램 리포트를 대체하지 않는다.** FCE 리포트는 FCE가 보내고, 이건 랩이 보낸다. 겹치는 내용은 줄인다.

## PART C — 유효일 추적

연구 03 (호스트가 자는 동안 잃은 날은 며칠인가) 를 **매일 자동 갱신**한다.

```
하루 커버리지 = 그날 틱이 있었던 시간 ÷ 있어야 했던 시간
유효일        = 커버리지 ≥ 90%
```

| 트랙 | 있어야 하는 시간 |
|---|---|
| 크립토 · 고래 | 24시간 |
| 주식 | 정규장 시간만 · 휴장일 제외 |

**OPS-01 이후 유효일이 90%대로 올라가야 한다.** 안 오르면 OPS-01이 안 된 것이다.

연구 03은 **30일 연속 유효** 가 되면 닫는다.

## PART D — 자산이 움직이는 게 보이게

### D-1. 지금 문제

```
자본 = 시작 자본 + 실현 손익
```

FCE 규칙이다. **거래가 닫힐 때만 움직인다.** 차트가 계단이고, 포지션을 들고 있는 동안은 아무 변화가 없다.

"자동매매로 자산이 늘고 줄어드는 게 보여야" 한다 — 지금은 안 보인다.

### D-2. 평가 자산을 같이 보여준다

```
평가 자산 = 시작 자본 + 실현 손익 + 미실현 손익
```

| 요소 | 처리 |
|---|---|
| **수익률 · hero** | **실현 기준 유지.** FCE와 같게. 바꾸면 FCE와 숫자가 달라진다 |
| hero 아래 한 줄 | `지금 평가 $46,702 (미실현 +$187)` |
| 차트 | 선 두 개 — 실현(파랑 굵게) · 평가(파랑 옅게 얇게) |
| 갱신 | 평가 선은 30초 |

**두 개를 섞지 않는다.** 실현은 확정, 평가는 지금 청산하면 얼마다.

### D-3. 포지션 탭

hero 옆에 `오늘 +$12.40` — 오늘 하루 평가 변화.

## PART E — 사이트 헤더

지금은 점 하나(전체 동기화). **트랙별로 쪼갠다.**

```
● ● ● ●    ← 크립토 · 고래 · KR · US
```

- 초록 운용중 · 회색 장외 · 주황 지연 · 빨강 멈춤
- 누르면 트랙별 마지막 틱 시각
- 폴리마켓은 빼거나 회색 고정

## 완료 확인

1. 트랙별 심장박동 기준이 있다
2. **맥 밖(Vercel 크론)에서 확인한다**
3. 주식은 장외 알림이 없다
4. **알림 · 복구 알림을 실제로 시험했다**
5. 07:30 아침 리포트가 온다
6. 유효일이 매일 자동 갱신된다
7. 평가 자산 선이 차트에 있고 30초 갱신
8. hero는 실현 기준 그대로 (FCE와 일치)
9. 헤더에 트랙별 점이 있다
