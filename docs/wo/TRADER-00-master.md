## 원칙

1. **실계좌 데이터는 비공개.** 공개 사이트 · 공개 레포에 안 올린다 (인계서 결정 1)
2. **거래소 키는 조회 전용 · 출금 권한 없음 · 값은 광혁이 넣는다**
3. **%로 비교하지 않는다.** 입출금이 %를 왜곡한다. **손익 구조**로 비교한다
4. **광혁이 먼저 말로 쓰고, 그다음 데이터를 본다** (TRADER-02 PART A)
5. **규칙은 앞 기간에서 뽑고 뒤 기간에서 검증한다.** 같은 거래로 뽑고 맞히면 속임수다
6. **규칙으로 설명 안 되는 거래는 지우지 않고 「재량」으로 표시한다**

## 마지막 질문

> **「광혁 복제」 전략이 같은 기간 광혁 실계좌를 따라가는가?**

| 답 | 뜻 |
|---|---|
| 따라간다 | 매매법이 규칙이다 → 엔진에 넣는다 |
| 일부만 | 규칙 부분과 재량 부분이 갈린다 → 재량이 어디서 버는지 안다 |
| 못 따라간다 | 광혁의 엣지는 규칙 밖에 있다 → 그것도 답이다 |

세 답 모두 결과다.
