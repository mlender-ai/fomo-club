## 0. 두 가지를 맞대본다

```
말한 매매법     광혁이 스스로 설명하는 규칙
실제 매매법     거래 데이터가 보여주는 규칙
```

**둘은 보통 다르다.** 그 차이가 가장 큰 발견이다.

순서가 중요하다. **광혁이 먼저 쓰고, 그다음 데이터를 본다.** 데이터를 먼저 보면 거기에 끌려 말한 매매법이 오염된다.

---

## PART A — 🧑 광혁이 먼저 쓴다 (데이터 보기 전)

`docs/trader/stated-rules.md` — 비공개

아래 질문에 **짧게, 숫자로** 답한다. 모르면 "모름". 경우에 따라 다르면 경우를 나눈다.

### A-1. 무엇을 거래하나

```
어떤 종목을 보나 (메이저 · 알트 · 신규상장 · 고래가 들어간 것 · ...)
안 건드리는 종목은
하루에 몇 번 정도 들어가나
```

### A-2. 언제 들어가나

```
들어가기 전에 반드시 확인하는 것 3개
그중 하나라도 아니면 안 들어가는 것
주로 보는 시간봉
추세 따라가나, 되돌림을 노리나, 둘 다면 언제 어느 쪽인가
진입은 한 번에인가, 나눠서인가
```

### A-3. 얼마나 싣나

```
레버리지 기준
한 거래에 증거금의 몇 % 쯤
자신 있을 때 더 싣나 — 무엇이 자신 있게 만드나
```

### A-4. 언제 자르나

```
손절 기준 (가격 % · 구조 이탈 · 시간 · 느낌)
손절 주문을 미리 걸어두나
손절 후 같은 종목 다시 들어가나
```

### A-5. 언제 파나

```
익절 기준
나눠서 파나 — 어떻게
끌고 가는 경우는 언제
"이제 나와야겠다" 싶은 신호
```

### A-6. 안 하는 때

```
매매를 쉬는 조건 (시간대 · 연속 손실 · 시장 분위기 · ...)
```

### A-7. 🤖 에이전트는

광혁 답변을 **질문 목록 순서대로 구조화만** 한다. 해석을 덧붙이지 않는다.

## PART B — 🤖 실제 매매법 추출

TRADER-01 거래 데이터로.

### B-1. 기간 나누기 — 먼저

```
앞 70%   규칙을 뽑는 기간
뒤 30%   규칙을 검증하는 기간 (이 기간 거래는 B-2~B-5 에서 보지 않는다)
```

**뒤 30%를 보면서 규칙을 다듬으면 무조건 맞는 규칙이 나온다. 그건 매매법이 아니다.**

### B-2. 기술 통계

앞 70% 기간에서:

```
진입 시점 특징 분포   이긴 거래 vs 진 거래로 나눠서
MFE · MAE 분포       이긴 거래 vs 진 거래
보유 시간 분포
분할 청산 패턴       몇 번 · 몇 % 씩 · 어느 수익에서
레버리지 · 사이징 분포
청산 방식 비율
연속 손실 후 행동    쉬나 · 크기를 줄이나 · 그대로인가
```

### B-3. 진입 규칙 후보

**단순한 것부터.** 조건 1~3개 조합.

```
"4H 20선 위 + 거래량 1.5배 이상 + 고래 분포 롱 우세" 일 때 진입한 비율
```

평가:

| 지표 | 뜻 |
|---|---|
| 재현율 | 광혁 실제 진입 중 이 규칙이 잡는 비율 |
| 정밀도 | 이 규칙이 진입하라 한 시점 중 광혁이 실제로 들어간 비율 |

**둘 다 봐야 한다.** 재현율만 높으면 아무 때나 진입하는 규칙이다.

### B-4. 청산 규칙 후보

MFE · MAE · 분할 패턴에서.

```
손절  MAE 분포의 이긴 거래 상한 → "이 이상 불리하면 광혁은 거의 이긴 적이 없다"
익절  분할 청산 지점 분포 → "첫 익절은 대개 +N%에서 M%"
끌고가기  마지막 몫은 무엇이 나오면 파나 (청산 시점 특징)
```

### B-5. 사이징 규칙

```
레버리지 · 증거금 비율이 무엇과 같이 움직이나
(진입 조건 개수 · 변동성 · 연속 손실 ...)
```

### B-6. LLM 쓰지 않는다

규칙은 **데이터에서** 뽑는다. LLM에게 "이 사람 매매법을 요약해줘"를 시키지 않는다. 그럴듯한 말만 나온다.

## PART C — 말한 것 vs 실제

`docs/trader/stated-vs-revealed.md` — 비공개

```
항목        말한 것              데이터                 일치
손절        −3% 에서 자른다      이긴 거래 MAE 중앙값 −1.8% · 진 거래 −4.6%   부분
익절        반 팔고 반 끌고 간다  분할 청산 71% · 첫 익절 +3.2% 중앙값        일치
쉬는 조건   3연패면 쉰다         3연패 후 다음 거래까지 중앙값 40분          불일치
```

**불일치가 나오면 둘 중 하나다.**
- 말한 게 맞고 실제로 안 지켰다 → 지키면 더 나아질 수 있다
- 실제가 맞다 → 말하지 못한 진짜 규칙이 있다

광혁이 판단한다.

## PART D — 규칙으로 옮기기

### D-1. 형식

LAB-02 전략 정의 스키마 그대로. **엔진이 바로 돌릴 수 있게.**

```
{
  "name": "광혁 v1",
  "market": "crypto",
  "universe": { ... },
  "entry": { "all": [ ... ] },
  "exit": {
    "stop": { ... },
    "scale_out": [
      { "at_pct": 3.0, "size": 0.5 },
      { "trail": { ... }, "size": 0.5 }
    ]
  },
  "sizing": { ... },
  "leverage": ...,
  "pause": { "after_consecutive_losses": 3, "minutes": 120 }
}
```

**분할 청산(`scale_out`)과 쉬는 규칙(`pause`)이 스키마에 없으면 추가한다.** 광혁 매매법의 핵심일 가능성이 크다.

### D-2. 두 버전

| 버전 | 근거 |
|---|---|
| `광혁-말` | PART A 말한 매매법 그대로 |
| `광혁-데이터` | PART B 데이터에서 뽑은 규칙 |

**둘 다 만든다.** 어느 쪽이 실제 광혁에 가까운지가 C의 답이다.

## PART E — 검증 (뒤 30% 기간)

**여기서 처음으로 뒤 30%를 본다.**

### E-1. 재생

두 버전을 뒤 30% 기간의 과거 데이터로 돌린다.

```
                광혁 실계좌   광혁-말   광혁-데이터
거래 수
순손익
PF
평균 이익/손실
최대 일손실
재현율 · 정밀도     —
```

### E-2. 재량 거래

규칙으로 설명 안 되는 광혁 거래를 **따로 모은다.**

```
재량 거래 N건 · 그 손익 합 · 전체 손익 중 비중
```

**재량 거래가 이익의 대부분이면** 우위는 규칙이 아니라 판단에 있다. 그게 답이다.

---

## PART F — 페이퍼로 올린다

뒤 30%에서 **광혁-데이터 버전이 실계좌 손익 구조를 따라가면**:

```
광혁 복제 트랙을 페이퍼로 운용 시작
광혁 실계좌와 같은 기간을 계속 나란히 기록
```

**따라가지 못해도 페이퍼로 올린다.** 비교 대상으로. 단 실매매 후보에서는 뺀다.
