## 0. 비공개

**공개 사이트에 실계좌를 올리지 않는다** (인계서 결정 1). 대신 로그인 뒤에 둔다.

### 0-1. 로그인

```
/me/*  경로 전체를 잠근다
방식   단일 사용자 비밀번호 (환경변수) + httpOnly 쿠키 · 30일
실패   5회 틀리면 15분 잠금
```

- 🧑 비밀번호는 광혁이 환경변수에 넣는다
- `/me/*` 는 검색엔진 차단 (`noindex`) · 공개 페이지 어디에서도 링크하지 않는다
- **실계좌 API 응답은 쿠키 없으면 401.** 화면만 막고 API가 열려 있으면 안 된다

### 0-2. 헤더

로그인하면 탭 끝에 하나 추가.

```
Overview  전략  포지션  고래  연구  복기  |  나
```

## PART A — 화면 `/me/compare`

### A-1. 맨 위

```
광혁 vs 엔진                              [30일] [90일] [180일]

광혁이 이기고 있다                          ← display
같은 기간 순손익  광혁 +○○○ USDT · 엔진 최고 −41 USDT
```

**결론 문장을 맨 위에.** 엔진이 이기면 `크립토 엔진이 이기고 있다`.

### A-2. 비교표

```

                 실계좌    (페이퍼)   (페이퍼)  (페이퍼)
───────────────────────────────────────────────────────────────
순손익 (USDT)    ○         —         −41      −12        —
수익률 (시간가중) ○         —        −8.2%    −2.4%     +11.3%
PF               ○         —         0.66     0.65       —
승률             ○         —         53%      37%        —
평균 이익        ○         —         +3.1     +2.8       —
평균 손실        ○         —         −5.4     −4.1       —
이익/손실 비     ○         —         0.57     0.68       —
최대 일손실      ○         —        −31.2    −14.5       —

```

| 규칙 | 내용 |
|---|---|
| 첫 열 | **광혁 실계좌 고정** — 기준 |
| 각 칸 | 광혁보다 나쁘면 빨강 · 좋으면 초록 (BTC 열 제외) |
| 광혁복제 | TRADER-02 끝나기 전엔 `준비 중` |
| 열 추가 | 엔진 트랙이 늘면 자동으로 늘어난다 |
| 폰 | 첫 열 고정 · 가로 스크롤 |

**숫자는 예시다.** 실측으로 채운다.

### A-3. 핵심 한 줄 — 표 바로 아래

차이가 가장 큰 항목을 자동으로 골라 한 줄.

```
가장 큰 차이: 이익/손실 비 — 광혁 ○ · 크립토 엔진 0.57
광혁은 크게 벌고 작게 잃는다. 엔진은 반대다.
```

## PART B — 곡선

### B-1. 누적 손익 곡선

```
같은 기간 · 시작 1,000 기준으로 환산 · 입출금 제거
선: 광혁 (굵게) · 광혁복제 · 엔진 트랙들 · BTC 보유 (점선)
```

- 실계좌는 시간가중수익률로 환산
- 엔진은 각자 수익률로 환산
- **절대 금액이 아니라 같은 출발점에서 비교**

### B-2. 일별 손익 달력

광혁 거래소 앱과 같은 형태.

```
        광혁              크립토 엔진
 01   ○              01   −2.10
 02   ○              02   +0.40
 ...
```

**두 달력을 나란히.** 같은 날 광혁은 벌고 엔진은 잃은 날이 눈에 보인다.

## PART C — 손익 분포

**이 화면에서 가장 중요한 그림이다.**

```
거래별 손익률 분포 (증거금 대비)

광혁      ▁▂▅▇▃▁            ▁▂▃▂▁      ← 오른쪽 꼬리가 길다
크립토    ▁▃▇█▇▅▃▁                     ← 가운데 몰림 · 꼬리 없음
```

- 막대 둘을 겹치거나 위아래로
- **오른쪽 꼬리** (크게 번 거래) 가 있는지가 한눈에 보여야 한다
- 평균 이익 · 평균 손실에 세로선

## PART D — 같은 순간 비교

### D-1. 겹친 거래

```
광혁이 진입한 순간 — 엔진은 그때 뭐 했나

09-22 14:10  광혁 SOL 롱 진입 → +○ (보유 ○h)
             광혁복제  진입 ✅ → +121
             크립토    진입 ❌
             고래추종  숏 보유 중 → −3.2
```

- 광혁 거래를 시간순으로
- 각 엔진이 그 시각 무엇을 했는지
- **광혁복제가 따라갔는지** — TRADER-02 재현율을 실시간으로 본다

### D-2. 요약

```
광혁 진입 42건 중
  광혁복제 따라감   29건 (69%)
  크립토 겹침        6건
  고래추종 겹침      4건
```

- 불일치는 주황

## PART F — 데이터 흐름

```
FCE (실계좌 조회) · TRADER-01 수집
  → 랩 비공개 저장소
  → /api/me/* (쿠키 필수)
  → /me/compare · /me/rules
```

| 규칙 | 내용 |
|---|---|
| 갱신 | 실계좌 15분 · 엔진은 기존 주기 |
| 공개 API | `/api/lab/*` 에 실계좌 데이터가 섞이면 안 된다 — 테스트로 강제 |
| 로그 | 실계좌 손익·잔고를 서버 로그에 찍지 않는다 |

## 완료 확인

1. `/me/*` 가 로그인 없이는 안 열린다 · **API도 401**
2. 공개 `/api/lab/*` 응답에 실계좌 필드가 없다 (테스트)
3. 비교표 첫 열이 광혁 실계좌 · 열이 엔진 수만큼
4. **%가 시간가중수익률이다** (입출금 제거)
5. 광혁보다 나쁜 칸이 빨강
6. 가장 큰 차이 한 줄이 자동으로 나온다
7. 누적 곡선이 같은 출발점 기준이다
8. 일별 달력 두 개가 나란히
9. **손익 분포에서 오른쪽 꼬리 차이가 보인다**
10. 같은 순간 비교가 있고 광혁복제 따라간 비율이 나온다
11. 매매법 탭에 말한 것 vs 데이터가 있다
12. 폰에서 동작한다

## 하지 말 것

- 실계좌 데이터를 공개 경로에 올리지 말 것
- 화면만 잠그고 API를 열어두지 말 것
- 거래소 앱의 %를 그대로 쓰지 말 것
- 절대 금액으로 곡선을 겹치지 말 것 (자본이 다르다)
- 서버 로그에 실계좌 숫자를 찍지 말 것
