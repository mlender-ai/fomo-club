## 0. 이 화면이 답하는 질문

> **어느 전략이 돈을 넣어도 될 만한가.**

지금 답은 **"아직 없다"** 다. 화면이 그걸 정직하게 말해야 한다.

## PART A — 목록 `/strategies`

### A-1. 맨 위

```
전략

기준선을 넘은 전략 없음                     ← display 36/600
BTC 보유 0.70 · 운용중 2 · 정지 3
```

**가장 큰 글자가 결론이다.** 이긴 전략이 생기면:

```
고래 추종이 기준선을 넘었다
수익÷낙폭 1.24 · BTC 보유 0.70
```

### A-2. 비교 막대

SuperHi 비교표 느낌. 가로 막대로.

```
                      수익÷낙폭
BTC 보유  기준선     ████████████████  0.70
────────────────────────────────────────
고래 추종            ░░  −0.87       기준 미달
크립토               ░   −0.85       기준 미달
주식 US              —               정지
주식 KR              —               보류
폴리마켓             —               제외
```

| 규칙 | 내용 |
|---|---|
| 기준선 | **맨 위 · 회색** |
| 이긴 전략 | 파랑 · 순위 번호 |
| 진 전략 | 빨강 · `기준 미달` · **순위 없음** |
| 정지·보류·제외 | 막대 없음 · 사유 |

### A-3. 상세 표

막대 아래. 열이 많아도 된다 — 여기는 비교하는 곳이다.

| 열 |
|---|
| 전략 |
| 자산 (환산) |
| 수익률 |
| MDD |
| 수익÷낙폭 |
| 샤프 |
| 승률 |
| 손익비 (PF) |
| 거래 수 |
| 평균 보유 |
| 레버리지 |
| 상태 |

**레버리지 열을 반드시 넣는다.** 3배로 돌고 있다는 게 보여야 한다.

### A-4. 우연 확률

```
전략 N개를 함께 보고 있다.
여럿을 보면 그중 하나는 우연히 좋아 보인다.
1위가 우연일 확률 약 M%.
```

**50% 넘으면 순위를 비운다.** LAB-FIX2 규칙 유지.

### A-5. 보관함

표 아래 접힌 섹션.

```
▸ 폐기한 전략 3개
    추세 스윙 v1    C/M 0.30   폐기 09-22   진입 우위 없음
    평균회귀 v1     C/M 0.15   폐기 09-22   진입 우위 없음
    고래 추종 v1    —          폐기 09-19   과거 데이터 없음 (FCE 쪽으로 이관)
```

**지우지 않는다. 접어둔다.**

### B-2. 차트

Overview와 같은 영역 차트. **이 전략 + 벤치마크.**

### B-3. 통계 6칸

```
수익÷낙폭   승률     손익비    MDD      거래    평균보유
−0.87      32.4%    0.47     8.59%    74     1.8일
```

### B-4. 기준선 대비

```
BTC 보유와 비교

             이 전략     BTC 보유
수익률       −7.45%     +5.10%
MDD          8.59%     11.20%
수익÷낙폭    −0.87       0.70

MDD는 BTC보다 낮지만 수익이 음수라 기준 미달이다.
```

**한 줄 해석을 붙인다.** 숫자만 두지 않는다.

### B-5. 거래 분포

```
수익률 분포 (히스토그램)
중앙값 −1.2%   최대 손실 −8.0%   최대 수익 +14.2%
```

**승률 32%인데 손익비 0.47이면 이긴 거래도 작다는 뜻이다.** 분포가 그걸 보여준다.

### B-6. 연결된 연구

```
이 전략과 관련된 연구
01  고래는 65.8% 맞히는데 우리는 왜 32.4%인가   [진행중]
02  강제청산을 넣으면 성과가 얼마나 바뀌나       [실매매 차단]
```

### B-7. 최근 거래

복기 탭과 같은 행 형태. 최근 10개 + `전체 보기 →`

## 완료 확인

1. **맨 위 가장 큰 글자가 결론이다** (`기준선을 넘은 전략 없음`)
2. 기준선이 막대 맨 위 회색이다
3. 기준 미달 전략에 순위가 없다
4. 상세 표에 레버리지 열이 있다
5. 우연 확률이 표시되고 50% 넘으면 순위가 빈다
6. 폐기 전략이 접힌 보관함에 있다
7. 전략 상세에 Hero·차트·통계·기준선 비교·분포·연구·거래가 있다
8. 기준선 비교에 한 줄 해석이 있다
9. 실제 FCE 데이터다
10. 폰에서 표가 가로 스크롤된다

- 레버리지를 숨기지 말 것
- 폐기 전략을 지우지 말 것
- 숫자만 두고 해석을 빼지 말 것
