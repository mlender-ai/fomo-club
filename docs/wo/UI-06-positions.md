## 0. FCE에 이미 있는 것 — 전부 가져온다

FCE 로컬 UI (`127.0.0.1:8876`) 라이브 포지션 화면:

| 기능 | FCE |
|---|---|
| 포지션 카드 | 심볼 · 방향 · 레버리지 · PnL · 건강도 원 |
| 상태 배지 | `관찰 필요` 등 |
| 고래 추적군 | 추적군 롱/숏 금액 · 지갑 수 · 분포 · 내 포지션과 정렬 여부 |
| 가격 레일 | 무효화 ← 현재 → 익절1 |
| 지금 볼 것 | 한 줄 행동 지침 |
| 유효 시간 | `유효 29분 남음` |
| 패턴 시간봉 | 1D·12H·4H·1H·15M 판정 (레인지·UTAD 등) |
| 실시간 동기화 | Bitget Live |
| 미니멀/프로 토글 | |

**하나도 빠뜨리지 않는다.**

## PART A — 목록 `/positions`

### A-1. 맨 위

```
포지션

−$40.07                                      ← hero (미실현 합계)
미실현 손익 · 열린 포지션 1개

마지막 동기화 12:09:11 · Bitget Live
```

### A-2. 포지션 카드

FCE 카드를 Coinbase 톤으로.

```
┌─────────────────────────────────┐
│  PONSUSDT              ⭕ 64     │
│  롱 · 5배                        │
│                                 │
│  −40.07%                        │  ← display · 손익색
│  [관찰 필요]                     │
│                                 │
│  ●━━━━○━━━━━━━━━━━━━━━●          │  ← 가격 레일 (작게)
│  무효 0.5698  현재 0.6158  익절 0.7791 │
└─────────────────────────────────┘
```

| 요소 | 스펙 |
|---|---|
| 건강도 | 원형 게이지 · 70↑ 초록 · 40~70 주황 · 40↓ 빨강 |
| PnL | `display` 36 · 손익색 |
| 상태 | 알약 |
| 가격 레일 | 무효화(빨강) ~ 현재(점) ~ 익절(초록) |
| 클릭 | 포지션 상세 |

### A-3. 정렬

```
건강도 낮은 순 (위험한 것 먼저)
```

### A-4. 청산 위험 경고

```
레버리지 × 손실률이 증거금의 80%를 넘으면
카드 테두리 빨강 + "청산 위험" 알약
```

**FCE가 청산을 모델링 안 해도 화면은 경고한다.** 연구 02와 연결.

## PART B — 상세 `/positions/[id]`

### B-1. 구조

```
① Hero
② 가격 레일 + 지금 볼 것

⑤ 고래 추적군
⑥ 포지션 정보
⑦ 연결된 연구
```

### B-2. ① Hero

```
PONSUSDT · 롱 · 5배                          ⭕ 64  관찰 필요

−40.07%                                      ← hero
증거금 대비 · 수수료·펀딩 포함 · 거래소 미실현 기준

진입 0.6421 · 현재 0.6158 · 12:07 기준
```

### B-3. ② 가격 레일 + 지금 볼 것

```
●━━━━━━━━━━━━━○━━━━━━━━━━━━━━━━━━━━━━━━━●
무효화 0.5698      현재 0.6158              익절1 0.7791

→ 지금 볼 것
  0.5698 지지 유지 여부. 이탈 시 손절 검토.

  유효 29분 남음
```

| 요소 | 스펙 |
|---|---|
| 레일 | 폭 전체 · 높이 8 · 무효화 구간 빨강 · 익절 구간 초록 |
| 현재 점 | 흰 원 + 파랑 테두리 |
| 지금 볼 것 | **카드 안 강조.** 파랑 왼쪽 바 · `body-strong` |
| 유효 시간 | 카운트다운 |

**"지금 볼 것"이 이 화면의 핵심 행동이다.** 눈에 가장 먼저 들어와야 한다.

### B-4. ③ 차트

**캔들 차트.** Lightweight Charts.

| 요소 | 스펙 |
|---|---|
| 캔들 | 상승 초록 · 하락 빨강 |
| 수평선 | 진입가(파랑 점선) · 무효화(빨강) · 익절(초록) |
| 시간봉 | 15M · 1H · 4H · 1D 전환 |
| 높이 | 360 |

### B-5. ④ 패턴 시간봉

FCE 그대로.

```
패턴 시간봉 · 각 시간봉의 확정 캔들을 독립 검사

  1D         12H        4H          1H          15M
  데이터 없음  데이터 없음  레인지 확인   UTAD 91     UTAD 95
                        Crab 92     하모닉 0    하모닉 0
```

| 규칙 | 내용 |
|---|---|
| 판정 있음 | 카드 강조 |
| 데이터 없음 | 회색 |
| 클릭 | 차트 시간봉 전환 |

**UTAD·Crab 같은 용어에 호버 설명을 붙인다.** 한 줄.

## PART C — FCE보다 나은 점

**이게 없으면 FCE를 그대로 쓰는 게 낫다.**

| FCE | 여기 |
|---|---|
| 포지션 카드만 | **미실현 합계 hero** |
| 청산 경고 없음 | **청산 위험 경고** |
| 차트 없음 (시간봉 판정만) | **캔들 차트 + 진입·무효화·익절 선** |
| 포지션만 | **어느 전략의 포지션인지 · 연결된 연구** |
| 용어 그대로 | **용어 호버 설명** |
| 로컬 | **폰에서도** |

## 완료 확인

1. **FCE 포지션 기능 9개가 전부 있다** (PART 0 표)
2. 목록에 미실현 합계 hero가 있다
3. 포지션 카드에 건강도 게이지·가격 레일이 있다
4. 건강도 낮은 순 정렬
5. **청산 위험 경고가 동작한다**
6. 상세에 가격 레일·지금 볼 것·캔들 차트·패턴 시간봉·고래 추적군·정보가 있다
7. 지금 볼 것이 가장 먼저 눈에 들어온다
8. 캔들 차트에 진입·무효화·익절 선이 있다
9. 패턴 용어에 호버 설명이 있다
10. 30초마다 갱신된다
11. 미니멀/프로 토글이 동작한다
12. **FCE 로컬 UI와 나란히 놓고 비교한 스크린샷이 있다**
13. 폰에서 동작한다
