
### B-1. 사후 채점이 핵심

**청산 후 가격이 어떻게 됐나.** FCE에 사후 채점 27,624건이 있다.

```
손절 후 반등    → 손절이 너무 빡빡했나
익절 후 더 오름  → 익절이 너무 일렀나
손절 후 더 빠짐  → 손절이 맞았다
```

**이걸 모아보면 청산 규칙을 고칠 근거가 된다.**
