```
□  복기      누르면 간다
```

### C-2. 모든 링크

```
□  트랙 행 → 전략 상세
□  연구 항목 → 연구 상세
□  최근 활동 → 복기 상세
```

**누르면 아무것도 안 일어나는 게 하나라도 있으면 실패.**
