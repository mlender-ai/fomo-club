## 0. 원인

화면 대부분이 설명 문단이다.

**지시서가 "주석을 붙여라"를 반복했고, 그게 전부 본문 문단이 됐다.**
정직하게 보여주는 것과 문단으로 설명하는 것은 다르다. **설명은 접는다.**

---

## PART A — 원칙 (전 탭 공통)

### A-1. 한 화면의 구성

```
큰 숫자 1개
그림 1개
목록 1개
```

**이 셋 말고는 전부 접거나 지운다.**

### A-2. 텍스트 예산 — 테스트로 강제

| 항목 | 상한 |
|---|---|
| 설명 문단 (2줄 이상 산문) | **화면당 0개** |
| 큰 숫자 아래 보조 문구 | 1줄 · 12자 내외 |
| 목록 행 | 이름 1줄 + 부제 1줄 |
| 알약 안 글자 | 6자 |
| 헤더 아래 부제 | 1줄 |

**넘으면 빌드 실패.**

### A-3. 설명은 ⓘ 로 접는다

지금 문단으로 있는 설명 전부 → 제목 옆 `ⓘ` → 누르면 바텀시트.

```
전략  ⓘ
```

바텀시트 안에서는 문단 허용.

### A-4. 절대 화면에 안 나오는 것

```
에러 코드         fill_price_outside_observed_range
문서 번호         LAB-00 §7 · 연구 02 (링크 텍스트로만)
내부 용어         invariant · NAV · 커버리지 · 모집단
중복 문구         한 행에 같은 말 두 번
```

에러 코드는 사람 말로 바꾼다.

| 코드 | 화면 |
|---|---|
| `fill_price_outside_observed_range` | 체결 가격 이상 |
| 봉 불일치 정지 예방 · 대기 13,940건 | 데이터 불일치 |
| 451 지역 차단 · NAV 미산출 | 지역 차단 |

## PART B — 깨진 것 (먼저)

### B-1. 전략 탭 레이아웃 붕괴

```
주
식
US
N
3
```

**이름 열이 폭을 못 받아 한 글자씩 세로로 쪼개진다.** 오른쪽 숫자·알약은 화면 밖으로 잘린다.

- 이름 열 최소 폭 고정, 줄바꿈 금지 (`white-space: nowrap` + 말줄임)
- 오른쪽 열은 수익률 하나만. 나머지는 부제로 내린다
- 390px 폭에서 가로 스크롤 없이 한 행에 들어가야 한다

### B-2. 포지션 PnL이 전부 같다

```
XRPUSDT   −0.27%
MRVLUSDT  −0.27%
BABAUSDT  −0.27%
AMATUSDT  −0.27%
```

**버그다.** 원인을 찾는다.

```
1  FCE가 준 값이 이미 같은가
2  업로드 과정에서 한 값으로 덮이나
3  화면이 잘못된 필드를 읽나
```

### B-3. 건강도가 전부 `—`

FCE 로컬 UI에는 건강도가 나온다. **안 올라오는 것이다.** UI-02 업로드에 추가한다.

**값이 없으면 `건강도 —` 를 띄우지 말고 칸을 숨긴다.**

### B-4. 기준선 불일치

| 화면 | 표시 |
|---|---|
| Overview 전략 경쟁 | BTC 기준선 4.15 |
| 전략 탭 | 기준선 없음 — 비교 불가 |

**같은 앱에서 같은 질문에 다른 답이다.** 하나로 맞춘다.

- 크립토·고래 → BTC 보유 기준선. 기간은 트랙 시작일부터
- 기준선 계산을 한 곳에서 하고 두 화면이 같은 값을 읽는다

### B-5. 거래 수 불일치

```
Overview 누적 거래    246
복기                  248
```

**문단으로 해명하지 않는다. 숫자를 하나로 맞춘다.**

- 어느 쪽이 맞는지 정하고 둘 다 같은 소스를 읽게 한다
- 차이 2건의 정체를 보고한다

### B-6. 전략 탭 hero 줄바꿈

```
기준선 넘은 전략 없
음
```

한 글자가 다음 줄로 떨어진다. PART C-2로 해결.

## PART C — 탭별로 자른다

### C-1. Overview

**거의 맞다. 텍스트만 뺀다.**

| 요소 | 처리 |
|---|---|
| hero · 변동 · 메타 1줄 | 유지 |
| 차트 | 유지 |
| 차트 범례 4줄 | **1줄로.** `— 내 포트폴리오  --- BTC 보유` |
| `점선 = 시작 금액` | 삭제 (보면 안다) |
| `회색 = FCE 관측 부족일…` | 삭제 → 차트 제목 옆 `ⓘ` |
| 차트 회색 띠 | **훨씬 옅게.** 지금은 띠가 차트를 덮는다 |
| 통계 4칸 부제 2줄 | **1줄 또는 삭제** |
| 트랙 리스트 | 유지 |
| 하단 주석 3문단 | **1줄로.** `페이퍼 · 트랙당 $10,000 환산 · 강제청산 미반영  ⓘ` |
| 지금 연구 중 | 3개만. 부제 1줄 |
| 전략 경쟁 아래 설명 문단 | 삭제 |

### C-2. 전략

**hero를 문장이 아니라 숫자로.**

```
지금   기준선 넘은 전략 없음        ← 문장 · 두 줄로 깨짐

바꿈   기준선을 넘은 전략
       0 / 2                       ← hero 숫자
```

행:

```
크립토 · 3배                    −29.12%
N 156 · 승률 52.6%

고래 추종 · 3배                  −5.73%
N 87 · 승률 36.8%

주식 US                         정지
체결 가격 이상

주식 KR                         보류
데이터 불일치

폴리마켓                         제외
지역 차단
```

| 규칙 | 내용 |
|---|---|
| 오른쪽 | 수익률 **또는** 상태 하나 |
| 부제 | 1줄. N·승률만. PF·MDD는 상세로 |
| `기준선 없음` | 삭제 (행마다 반복됨) |
| `운용중` 알약 | 삭제 (정상이면 표시 안 함. 비정상만 표시) |
| 하단 설명 문단 | 삭제 → 제목 옆 `ⓘ` |

### C-3. 포지션

B-2·B-3 고친 뒤.

```
미실현 손익
+$0.52                          ← hero

XRPUSDT    롱 3배    −0.27%   ◔ 72
MRVLUSDT   롱 3배    +1.14%   ◕ 85
...
```

| 규칙 | 내용 |
|---|---|
| 행 | 심볼 · 방향·배수 · PnL · 건강도 게이지 |
| 진입 시각 | 행에서 삭제 → 상세 |
| 증거금 | 행에서 삭제 → 상세 |
| hero 아래 `증거금 × 손익률의 합` | 삭제 |

**UI-06의 가격 레일·지금 볼 것·패턴 시간봉은 아직 없다.** 이 WO 범위 밖이지만 **06이 끝나지 않았다는 사실을 보고에 적는다.**

### C-4. 복기

```
실현 손익
−$174.25                        ← hero
116승 · 130패

[청산 사유 막대]

최근 거래 목록
```

| 요소 | 처리 |
|---|---|
| `수수료·펀딩비가 총손익 규모의 85.1%다` | **유지하되 짧게.** `비용 85%` 알약 하나. 이건 중요한 발견이다 |
| 4칸 카드 | **2칸으로.** 비용 전 · 비용. (비용 후는 hero와 같다) |
| `전광판 156건 · 이 표 248건…` 문단 | 삭제. B-5에서 숫자를 맞춘다 |
| `최근 60건 · 나머지 188건은 위 합계에만` | 1줄. `최근 60건` |

### C-5. 연구

목록은 유지. **상세는 에디토리얼이라 문단이 허용되는 유일한 곳이다.** 단:

- 섹션 카드 4개 → 섹션 제목 + 본문. 카드 테두리 제거
- 인용 블록 안 볼드 남용 제거

### C-6. 고래

같은 원칙. hero = 갭 숫자. 모집단 경고는 **알약 하나** (`모집단 다름`) + `ⓘ`.

## PART D — 폰 기준으로 확인

**390px에서 확인한다.** 데스크톱에서 멀쩡해도 폰에서 깨지면 실패.

```
□  이름이 세로로 쪼개지지 않는다
□  오른쪽이 잘리지 않는다
□  한 행이 두 줄을 넘지 않는다
□  한 화면에 설명 문단이 없다
□  에러 코드·문서 번호가 없다
```

## 완료 확인

1. 텍스트 예산 테스트가 CI에 있고 통과한다
2. 설명 문단이 연구 상세 말고는 **0개**다
3. `ⓘ` 바텀시트가 동작한다
4. **전략 탭 세로 쪼개짐·잘림이 없다**
5. 에러 코드가 사람 말로 바뀌었다
6. **포지션 PnL이 각자 다른 실제 값이다** (원인 보고)
7. 건강도가 FCE에서 올라오거나, 없으면 칸이 숨겨진다
8. **기준선이 두 화면에서 같은 값이다**
9. **거래 수가 두 화면에서 같다** (차이 원인 보고)
10. 전략 hero가 숫자다 (`0 / 2`)
11. 행마다 반복되던 `기준선 없음`·`운용중`이 없다
12. 차트 회색 띠가 옅어졌다
13. **탭 6개를 폰(390px)에서 캡처해 첨부했다**
