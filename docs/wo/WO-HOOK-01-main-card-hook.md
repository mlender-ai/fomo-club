# WO-HOOK-01 — 메인 카드 후킹 재설계

| 항목 | 값 |
|---|---|
| 선행 | DS-00 (토큰) |
| 후행 | WO-HOOK-02 (상세) |
| 대체 | DS-01을 이 문서로 **대체**한다 |
| 완료 | 정규 도메인 배포 후 화면 확인 |

---

## 0. 문제

카드가 데이터 표다. 사람은 주식을 볼 때 표를 읽지 않는다. **호재·급등·장대양봉에 반응한다.**
우리가 파는 건 "아직 아무 일도 안 일어난 상태"라 그 자극이 원래 없다. **그러면 만들어야 한다.**

### 0-1. 이 제품의 유일한 후킹은 역행이다

```
주가는 안 움직이는데 안에서는 사고 있다
1년간 조용하던 사람들이 이번 주에만 샀다
하루 거래량의 절반을 몇 사람이 가져갔다
```

**"뭔가 알고 있나?"** — 이 서스펜스가 우리가 팔 수 있는 도파민이다.

현재 카드는 이 긴장을 `누가 / 언제 / 얼마나 드문가 / 거래량` 네 줄로 분해해서 없앤다. 분해하는 순간 긴장이 사라진다.

### 0-2. 후킹은 카피만으로 안 된다

`임원 4명이 여드레 새 함께 매수`를 아무리 다듬어도 **그림이 없으면 안 읽힌다.** SuperSignal이 68점 옆에 레이더를 두는 이유다. 숫자 하나 + 그림 하나.

---

## 1. 카드 3형 — 신호 유형이 결정한다

**사람이 고르는 게 아니라 신호가 결정한다.** 각 형이 요구하는 데이터가 다르다.

| 형 | 조건 | 데이터 요건 |
|---|---|---|
| **A 역행** | 임원 매수 + 주가 정체·하락 | 임원 매수 누적 시계열 |
| **B 비율** | 매수 규모 / 일 거래대금 ≥ 임계 | 거래량 비율 |
| **C 희소성** | 연속일수가 N거래일 내 최장 | 일별 매수 여부 |

### 1-1. 선택 규칙

```
if 임원매수누적 확보 and |주가변동| < θ_flat  →  A
elif 거래량비율 >= θ_ratio                    →  B
elif 연속일수 == 최근N일중최장                 →  C
else                                          →  C (기본)
```

- θ는 실측 분포로 정한다. 감으로 정하지 않는다
- 어느 형도 성립 안 하면 **그 종목은 픽에서 제외**한다. 후킹이 없는 카드를 만들지 않는다

## 2. 티커 마스킹

**앞면에서 종목명·티커·종목코드를 가린다.** 상세에서 공개한다.

### 2-1. 이유

우리 유니버스는 무명주다. 종목명이 보이면 사용자는 "모르는 회사네" 하고 넘긴다. **가리면 궁금해진다.** 정보를 줄여서 후킹을 만드는 장치다.

### 2-2. 가리는 것 / 남기는 것

| 가림 | 남김 |
|---|---|
| 종목명 | 국가 (`미국` / `한국`) |
| 티커 / 종목코드 | 섹터 (신뢰 가능할 때만) |
| 로고 | 시총 |
| — | 현재가 · 등락률 |

**섹터·시총을 남기는 이유**: 다 가리면 낚시가 되고 판단 재료가 0이 된다. "미국 자동차부품, 시총 $13B"만 있어도 규모감은 전달된다.

### 2-3. 해제 조건

| 상황 | 동작 |
|---|---|
| 상세 진입 | 즉시 공개, **이후 그 카드는 영구 해제** |
| 재방문 | 이미 연 카드는 종목명 표시 |
| 관심 등록 | **상세에서만 가능.** 앞면 ★ 제거 |
| 성적표 · 내 기록 | 마스킹 없음 (이미 본 것) |
| 지켜보는 중 | 마스킹 없음 (픽이 아님) |

해제 상태는 로컬 저장. 로그인 없이 동작해야 한다.

### 2-4. CTA 문구

```
자세히 보기  →  어떤 회사인지 보기
```

**가렸다는 사실을 CTA가 명시한다.** 안 그러면 낚시로 읽힌다.

## 3. 카드 구조 — 공통

```
┌───────────────────────────────┐
│ ① 정체 (마스킹)                 │
│ ② 가격                         │
│                               │  20
│ ③ 후킹 — 형별로 다름            │
│                               │  20
│ ④ 그림 — 형별로 다름            │
│                               │  18
│ ⑤ 보조 2줄                     │
│                               │  18
│ ⑥ CTA                          │
└───────────────────────────────┘
```

패딩 16px, radius 16px, `surface-1`. **고정 높이 금지.**

### ① 정체

```
미국 · 자동차부품 · 시총 $13B
```

`label` mono 12px, `text-2`. 한 줄. 섹터 신뢰 불가 시 생략.

### ② 가격

```
$48.92  +0.7%
```

`data` mono 15px. 상승 `text-1`, 하락 `down`. 화살표 없음.

### ⑤ 보조

```
8일간 4명 · $8.3M
1년 매수는 3건뿐이었어요
```

`caption` 12px, `text-2`. **최대 2줄.** 칩 사용 금지.

### ⑥ CTA

높이 48px, radius 999px, `surface-2`, 0.5px `border`, `body` 14/500 `text-1`.
**하나만.** 넘기기·더보기 폐지, 스와이프로 대체.

## 4. A형 — 역행

### 4-1. 후킹 문장

```
주가는 제자리인데
임원만 사고 있어요
```

`display` 19px/500/1.35/-0.02em, `text-1`, 최대 2줄.

**변형**

| 주가 | 문장 |
|---|---|
| 정체 (±2% 이내) | 주가는 제자리인데 임원만 사고 있어요 |
| 하락 | 주가는 빠지는데 임원은 사고 있어요 |
| 소폭 상승 | 주가는 조용한데 임원이 계속 사고 있어요 |

### 4-2. 그림 — 이 배치의 핵심 산출물

```
높이 76px
회색 선  (#4A4A48, 1.5px)  주가, 같은 기간
라임 선  (#D4FF3F, 2.5px)  임원 매수 누적 금액
끝점     라임 원 3.5px
범례  — 주가   — 임원 매수 누적   (10px)
```

**두 선의 갭이 이 제품 전체를 한 장으로 설명한다.** 말이 필요 없다.

**데이터 요건**: Form 4 / 내부자 공시의 날짜별 매수 금액을 누적한 시계열. 기간은 신호 구간 + 앞뒤 여유.

- 두 선을 각자 정규화한다 (같은 축에 두지 않는다). y축 라벨 없음
- 누적선이 실제로 우상향하지 않으면 A형을 쓰지 않는다

---

## 5. B형 — 비율

### 5-1. 큰 숫자

```
51%
```

| 항목 | 값 |
|---|---|
| 크기 | 52px, mono, weight 600 |
| 색 | `accent` |
| letter-spacing | -0.03em |

**이게 SuperSignal의 68점 자리다.** 점수를 못 주는 대신 비율을 쓴다.

### 5-2. 후킹 문장

```
임원들이 하루 거래량의
절반을 사갔어요
```

16px/500/1.4, `text-1`, 숫자 아래 10px.

**숫자를 문장으로 다시 읽어준다.** `51%`만으로는 무엇의 51%인지 모른다.

| 비율 | 표현 |
|---|---|
| ≥ 45% | 하루 거래량의 절반을 |
| 25–45% | 하루 거래량의 3분의 1을 |
| 10–25% | 하루 거래량의 상당 부분을 |
| < 10% | **B형 미사용** |

### 5-3. 그림

스파크라인 54px, 회색 1.5px, 매수 시작 지점 흰 원 4px. 범례 없음.

## 6. C형 — 희소성

### 6-1. 후킹 문장

```
40거래일 만에
가장 길게 사고 있어요
```

### 6-2. 그림

```
최근 40거래일 매수일 막대
높이 46px, 막대 간격 3px
미매수·과거 매수일   #252523
현재 연속 구간       accent
캡션                최근 40거래일 기관 매수일  (10px)
```

**희소성이 그림이 된다.** 회색 막대 사이에서 라임 4개가 붙어 있는 게 "이례적"의 시각화다.

- 막대 수가 40개면 화면폭에서 각 4~5px. 20개로 줄여도 됨(실측으로 결정)

## 7. accent 규칙

| 형 | accent 위치 |
|---|---|
| A | 매수 누적선 |
| B | 큰 숫자 |
| C | 연속 구간 막대 |

**형별로 한 곳.** CTA·가격·문장에 쓰지 않는다.

### 7-1. 우리 성적은 어디로?

DS-01에서 카드에 넣기로 했던 `8/17 이후 +13.1%`는 **이번 배치에서 카드에 넣지 않는다.**

- accent가 두 곳이 된다
- 마스킹된 카드에서 "짚은 뒤" 문구는 종목 정체를 암시한다
- **상세 마지막 섹션으로 이동** (WO-HOOK-02)

## 10. 완료 기준

1. 카드 3형이 신호 유형에 따라 자동 선택된다
2. 앞면에 종목명·티커·로고가 없다
3. 상세 진입 후 그 카드는 영구 해제된다 (로컬 저장)
4. CTA가 `어떤 회사인지 보기`다
5. accent가 형별 1곳에만 있다
6. 칩이 없다
7. A형 역행 차트가 두 선의 갭을 보여준다
8. B형 큰 숫자가 52px `accent`다
9. C형 막대에서 연속 구간만 `accent`다
10. 고유어 수 표현이 없다
11. 카드 높이가 내용에 따라 변한다
12. 세 형 모두 320px 폭에서 후킹 문장이 3줄이 되지 않는다

## 11. 실패 모드

| 실패 모드 | 방지 |
|---|---|
| 세 형을 하나로 합치려 함 | 요구 데이터가 다르다. 분리 유지 |
| A형 누적 데이터 없이 억지 구현 | 없으면 B/C로 폴백 |
| 마스킹을 다 가려서 낚시가 됨 | 섹터·시총·가격은 남긴다 |
| 재방문 시 다시 가려짐 | 로컬 해제 상태 저장 |
| accent가 2곳 이상 | 형별 1곳 |
| 후킹 문장이 사실 서술로 회귀 | 역행/희소성 프레임 유지 |

## 12. 에이전트에게

- **A형 역행 차트가 이 배치의 핵심 산출물이다.** 다른 걸 못 해도 이건 만든다
- 세 형 중 어느 것도 성립 안 하는 종목은 픽에서 뺀다. 후킹 없는 카드를 만들지 않는다
- θ 임계값은 실측 분포로 정하고 근거를 문서에 남긴다
- 완료는 정규 도메인 배포 후 화면 확인이다
