# WO-HOOK-02 — 상세 페이지 「왜 지금 사는가」

| 항목 | 값 |
|---|---|
| 선행 | WO-HOOK-01 |
| 대체 | DS-03을 이 문서로 **대체**한다 |
| 완료 | 정규 도메인 배포 후 화면 확인 |

---

## 0. 문제

현재 상세의 첫 섹션이 이렇다.

```
근거
누가          기관 · 1,243주
언제          4일째 이어짐
얼마나 드문가   40거래일 중 최장
거래량        평소의 33%
```

**앞면 훅이 "기관이 40거래일 중 가장 긴 4일 매수"인데, 이 네 줄은 그 문장을 쪼개서 다시 쓴 것이다.** 사용자는 "진짜야?"라고 물으며 들어왔는데 같은 말을 네 조각으로 다시 듣는다.

그리고 이 정보는 **HTS 필터로 다 나온다.** 여기서 끝나면 우리 앱을 쓸 이유가 없다.

### 0-1. 상세가 답해야 하는 질문

> **왜 조용히 사고 있는가.**

이 답이 없으면 상세는 기본 정보 나열이다.

---

## 1. 핵심 발견 — 재료는 이미 화면에 있다

지금 상세에 **답의 재료가 흩어져 있다.** 서로 무관한 정보처럼 나열돼 있어서 의미가 없을 뿐이다.

휴니드 실제 화면:

| 지금 있는 위치 | 내용 |
|---|---|
| `값` 섹션 | PBR 0.36배 — 5년 밴드 1% 구간 |
| `값` 섹션 | EPS -378원 (적자 구간) |
| `틀리는 경우` | 52주 저점 3,550원 |
| 별도 | 최근 30일 공시 없음 |

**이걸 `왜 지금 사는가` 아래 모으면 그게 근거다.**

```
왜 지금 사는가
값     PBR 0.36배 — 5년 중 가장 낮은 구간이에요
손익   적자 구간이라 이익으로는 값을 잴 수 없어요
가격   52주 저점에서 27% 위예요
재료   최근 30일 공시가 없어요
```

**새 데이터 수집이 필요 없다.** 배치·재편성만으로 된다.

---

## 2. 「왜 지금 사는가」 명세

### 2-1. 위치

**상세의 첫 섹션.** 헤더 → 후킹 문장 → 이 섹션.

### 2-2. 축 (현재 데이터로 가능한 것)

| 축 | 조건 | 표현 |
|---|---|---|
| `값` | PBR/PER 밴드 백분위 확보 | `PBR 0.36배 — 5년 중 가장 낮은 구간이에요` |
| `손익` | 영업이익 부호 | `적자 구간이라 이익으로는 값을 잴 수 없어요` / `흑자 전환 뒤 2분기째예요` |
| `가격` | 52주 고저 대비 위치 | `52주 저점에서 27% 위예요` / `고점 대비 41% 아래예요` |
| `재료` | 최근 90일 공시 유무 | `최근 30일 공시가 없어요` / `8월 4일 공시 뒤로 사고 있어요` |
| `이력` | 이 신호의 과거 성과 | `비슷한 신호 50번 중 26번 올랐어요 (52%)` |

**최소 2축이 채워져야 섹션을 표시한다.** 1축 이하면 섹션 전체 미표시.

### 2-3. 표현 규칙

| 금지 | 사유 |
|---|---|
| `~때문에` `~로 인해` `~해서 샀어요` | 인과 단정. 매수 주체의 의도를 알 수 없다 |
| `호재` `악재` `저평가` `기회` | 평가·투자의견 |
| `곧 오를` `상승 전망` | 예측 |

**꼬리표 필수** — 섹션 하단에 `caption` `text-3`:

```
이 시점에 함께 관측된 것들이에요. 왜 샀는지는 확인할 수 없어요.
```

### 2-4. 스타일

| 요소 | 스펙 |
|---|---|
| 라벨 | `label` mono 12, `text-2`, 고정폭 56px |
| 값 | `body` 14/1.6, `text-1` |
| 행 간격 | 12px |
| 박스 | 없음 |

### 2-5. 확장 (데이터 확보 후)

| 축 | 필요 | 표현 |
|---|---|---|
| `실적` | 실적 발표일·서프라이즈 | `2분기 적자 축소, 다음 발표는 11월이에요` |
| `공시` | 공시 제목 | `8월 4일 방산 수출 계약 공시가 있었어요` |
| `구조` | 가격·거래량 판정 | `넉 달째 좁은 범위에서 움직이고 있어요` |

**이 축들은 이번 배치 범위 밖이다.** 자리를 미리 만들지 않는다.

---

## 3. 「근거」 섹션 — 압축

기존 `누가/언제/얼마나 드문가/거래량/비중` 5줄을 **2줄로 줄인다.**

```
근거
매수     기관 1,243주 · 4일 연속
비교     최근 40거래일 중 가장 길어요
```

- 앞면 훅에 이미 나온 내용은 **여기서 반복하지 않는다**
- 앞면 훅이 `40거래일 중 최장`이면 `비교` 행을 삭제한다
- 스파크라인은 이 섹션 아래 (88px, 무효선 점선 포함)

---

## 4. 섹션 순서

| # | 섹션 | 비고 |
|---|---|---|
| 1 | 후킹 문장 | 카드와 동일. **화면에서 1회만** |
| 2 | **왜 지금 사는가** | 최소 2축 |
| 3 | 근거 | 2줄 + 스파크라인 |
| 4 | 무슨 회사 | 종목명 공개 지점 |
| 5 | 값 | 3개 이상일 때만 |
| 6 | 틀리는 경우 | 무효 조건 + 유형 리스크 최대 2개 |
| 7 | 우리 기록 | accent |

**7개. 늘리지 않는다.**

## 5. 종목 공개

앞면에서 마스킹했으므로 **상세 진입 순간이 공개 지점**이다.

### 5-1. 헤더

```
←   휴니드                          4,520원      ★
    005870 · 방산                    -0.9%
```

- 진입 즉시 표시 (로딩 없음)
- ★ 관심 등록은 **여기에만** 존재

### 5-2. 공개 연출

| 항목 | 스펙 |
|---|---|
| 방식 | 헤더 종목명 페이드 인 200ms |
| 과장된 연출 금지 | 카운트다운·플립·파티클 없음 |

**한 번 열면 그 카드는 영구 해제**되어 앞면에도 종목명이 표시된다.

## 6. 「무슨 회사」 수정

### 6-1. 현재 결함

| 종목 | 현재 문구 | 문제 |
|---|---|---|
| 한화투자증권 | `투자매매업, 투자중개업, 집합투자업` | 사업자등록증 업종명 |
| 빅텍 | `2024년 자회사 …를 설립하여` | 주력 사업 누락 |
| 휴니드 | `전술통신장비 및 시스템의 방산사업과 보잉, GA-ASI 등…` | 한 문장에 다 욱여넣음 |

### 6-2. 규칙

- **첫 문장은 무엇을 파는가.** 설립·상장·법인격 금지
- 최대 2문장
- 약어(`GA-ASI`, `PBL`, `MRO`, `TICN`)는 풀거나 제거
- 확보 실패 시 섹션 전체 미표시

```
휴니드
군용 전술통신장비를 만드는 방산 업체예요.
항공전자장비를 해외로 수출하기도 해요.
```

## 7. 「우리 기록」 — accent 유일

```
우리 기록
┌────────────────────────────┐
│ │ 8월 17일에 짚은 뒤          │
│ │ +13.1%                    │
│                            │
│ 8/17   $4.37               │
│ 8/19   $4.945              │
└────────────────────────────┘
```

### 7-1. 현재 결함 — 최우선 수정

```
지금   2026-08-17  당시 4.37   7일 아직  30일 아직  90일 아직
       2026-08-18  당시 4.37   7일 아직  30일 아직  90일 아직
       2026-08-19  당시 4.945  7일 아직  30일 아직  90일 아직
```

**8/17에 4.37, 지금 4.945. +13.1%.** 맞은 걸 눈앞에 두고 "아직"을 아홉 번 반복한다.

### 7-2. 수정

- `7일 아직 / 30일 아직 / 90일 아직` **전량 삭제**
- **가장 오래된 발행일 대비 현재 수익률**을 계산해 표시 (데이터는 DB에 있음)
- T+7/30/90 채점 결과는 **도래한 것만** 별도 행
- 발행 이력 최대 5건, 날짜+가격만
- 오늘 첫 발행이면 섹션 전체 미표시

### 7-3. 스타일

| 요소 | 스펙 |
|---|---|
| 박스 | `surface-2`, radius 10, 패딩 14 |
| 좌측 바 | 2px `accent` |
| 수익률 | mono 20/500, `accent` |
| 이력 | mono, 날짜 `text-3` / 가격 `text-1` |

**이 화면에서 박스는 여기 하나, accent도 여기 하나.**

## 8. 「틀리는 경우」 압축

```
틀리는 경우
가격     52주 저점 3,550원 아래로 마감하면
사업     분기 영업이익이 흑자로 안 바뀌면

이 유형에 흔한 것
· 적자 기간이 길어질 수 있어요
· 빚 만기가 몰리면 재조달 조건이 문제가 될 수 있어요
이 유형의 종목에 흔한 항목이에요
```

- 유형 리스크 **3개 → 2개**
- `확인 예정일을 아직 못 잡았어요` — 예정일 확보 시에만 표시
- 종목 고유 리스크 확보 시 유형 리스크 **위에** 배치

## 9. 완료 기준

1. **`왜 지금 사는가`가 첫 섹션**이고 최소 2축이 채워진다
2. 인과 단정 표현이 없고 꼬리표가 붙는다
3. `근거` 섹션이 2줄 이하이고 앞면 훅과 중복되지 않는다
4. 후킹 문장이 화면에서 1회만 나온다
5. 헤더에서 종목명이 즉시 공개되고, 해당 카드가 영구 해제된다
6. `무슨 회사` 첫 문장이 주력 사업이다
7. **`7일 아직 / 30일 아직 / 90일 아직`이 사라지고 실제 수익률로 대체됐다**
8. 박스와 accent가 `우리 기록` 하나뿐이다
9. 섹션이 7개 이하다
10. 확보 안 된 섹션은 빈 헤더 없이 사라진다
11. 밴드 없을 때 밴드 관련 문구가 없다

## 10. 실패 모드

| 실패 모드 | 방지 |
|---|---|
| `왜 지금 사는가`를 인과로 서술 | 꼬리표 + 금지어 테스트 |
| 재료가 없어서 섹션을 비움 | 2축 미만이면 섹션 자체 미표시 |
| `근거`가 다시 5줄로 늘어남 | 상한 2줄 |
| 우리 기록을 채점 상태로 되돌림 | 완료 기준 7 |
| 데이터 확보 전 축 자리를 미리 만듦 | 2-5 참조 |

## 11. 에이전트에게

- **이 WO의 핵심은 새 데이터가 아니라 재편성이다.** 화면에 흩어진 정보를 하나의 질문 아래 모은다
- `왜 지금 사는가`가 2축도 못 채우는 종목이 많으면 그 비율을 보고한다. 그게 다음 작업(CTX-03 재료 수집)의 근거다
- 완료는 정규 도메인 배포 후 화면 확인이다
