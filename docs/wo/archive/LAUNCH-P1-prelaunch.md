## PART A — 메타데이터

### A-1. 실제 프로덕션 head (2026-09-08 실측)

지시서가 적은 것과 **한 줄 다르다.**

```
<title>FOMO Club</title>                                   ← 이미 맞았다
description  종목을 스와이프하며 내 취향의 종목을 발견하고…    ← 피봇 이전
og:title     FOMO Club — 주식시장의 틴더                     ← 피봇 이전
og:image     (없음)                                          ← 링크 공유 시 그림이 안 뜬다
본문 h1      오늘의 조용한 돈                                 ← 피봇 이후
```

`틴더` 는 `<title>` 이 아니라 **og:title · twitter:title** 에 있었다.

### A-3. 고친 것

| 태그 | 값 |
|---|---|
| `title` | `FOMO Club`(그대로) |
| `og:title` · `twitter:title` | `FOMO Club — 오늘의 조용한 돈` |
| `description` · `manifest.description` | `뉴스가 나기 전에 돈이 먼저 들어간 종목을 찾아 보여드려요. 기관·외국인·임원이 조용히 사고 있는 곳, 그때 무슨 공시가 있었는지까지 함께 봅니다.` |
| `og:description` · `twitter:description` | `뉴스가 나기 전에 돈이 먼저 들어간 종목을 찾아 보여드려요.` |
| `manifest.name` | `FOMO Club — 오늘의 조용한 돈` (종전 `캐주얼 투자 발견`) |
| `twitter:card` | `summary` → `summary_large_image` |

**쓰인 말은 전부 이미 일어난 사실**이다(돈이 먼저 들어갔다 · 조용히 사고 있다).
`곧 오른다` 류 예측은 메타에도 쓰지 않는다(§5.1).

#### 법무 문서는 문구만 바꾸지 않았다

v1.2 의 수집 항목표에 `온보딩 취향 선택` · `스와이프(관심/비관심)` 가 있었다. 지금 살아 있는
화면에는 **온보딩 취향 선택 단계가 없고**(`HomeView` 는 `QuietPickDeck` 만 그린다),
스와이프는 탐색 동작이라 관심/비관심으로 저장되지 않는다. 실제로 서버로 가는 것은
`pickTelemetry` 의 열람·머문 시간·상세 열기·관심 담기다.

```
바꿈  관심 시장·테마 등 온보딩 취향 선택   → 관심 담기(★)한 종목·업종 목록
바꿈  열람·스와이프(관심/비관심)·검색 요청 → 카드 열람·머문 시간·상세 열기·관심 담기
```

**하지 않는 수집을 적어 두는 것도 거짓이다.** 항목을 줄이는 변경이라 시행일을 앞당겨 적었다.
⚠️ 이 두 줄은 **법무 확인이 필요하다** — 수집 항목 삭제는 문구 교체와 다른 성격이다.

## PART C — 사람 판단 3건

### C-1. `guard:discovery` override — **조항을 걷었다**

지시: *"게이트를 느슨하게 하지 않는다. 필요했던 사례를 목록으로 보고하고, 없으면 조항을 삭제한다."*

**단계 1 — 사례 실측(2026-09-08):**

| 확인 | 결과 |
|---|---|
| discovery 46장에서 진짜 조언 표현 | **0건.** 금칙어로 잡힌 36건은 전부 `순매수`(사실 용어)이고 게이트가 이미 중성화한다 |
| 과거 사례(`목표가 3만3000원 유지`) | **수집 기사 제목**이다. 우리가 쓴 문장이 아니다 |
| 그 문장이 사용자 화면에 나가나 | **아니다.** `HomeView` 는 `QuietPickDeck` 만 그린다 — 레거시 발견 피드는 props 로 받고 쓰지 않는다 |
| 서빙 페이로드의 `목표가` | 0건 |

**단계 3 — 정당한 사례가 없으므로 삭제했다:**

```
docs/CONSTRAINT_OVERRIDE_DEV.md   ACTIVE: true  → false
apps/web/lib/copy-guards.ts       DEV_CONSTRAINTS_LIFTED = true → false
```

그 문서가 처음부터 못을 박아 뒀다 — *"공개 출시 전 반드시 false 로 복원."* 출시 작업이
이 WO 이므로 지금이 그 시점이다. 이제 게이트 둘(`spec-analyze` · `discovery-regression-gate`)이
**같은 규칙으로 돈다** — 어긋남이 STATUS §31 의 버그였다.

복원 후 전체 게이트 재실행: **3,120 통과 · guard:discovery ✅ · spec:analyze ✅.**
투자조언 금칙어가 다시 켜졌는데 걸린 것이 없다 — 지금 화면 문장은 그 규칙 아래에서도 안전하다.

### C-2. 마이너스 수익률 — 사실만 쓴다

지시서가 준 모양 그대로 두 조각으로 쪼갰다.

```
종전   우리가 8월 26일에도 짚었고 그 뒤로 -4.2% 움직였어요   ← 문장에 숫자가 묻힌다
지금   8월 26일에 짚은 뒤
       -4.2%
```

문장으로 쓰면 숫자가 말 속에 묻히고, **묻힌 숫자 옆에는 완충어를 넣고 싶어진다.**
쪼개면 넣을 자리가 없다. 셋을 못 박았다:

- 위로 문구 없음 — 테스트가 `아쉽`·`하지만`·`괜찮`·`그래도`·`다만` 을 막는다
- **색을 바꾸지 않는다** — e2e 가 렌더된 색의 `r - max(g,b) < 40` 을 확인한다(빨간색 금지)
- 가격을 못 쟀으면 `0%` 로 채우지 않고 그 사실을 쓴다

### C-3. 13F 수집 위치 이전 — 인증 확인 후 진행

**단계 1·3 — 무인증 경로 감사:** 크론 19개 전부 `CRON_SECRET` 을 쓴다. 무인증 경로는 없다.
**다만 패턴이 위험했다:**

```ts
return !secret || header === `Bearer ${secret}`;   // 환경변수가 비면 전부 통과
```

읽기 크론에서는 넘어갔지만 **쓰기에서는 그게 공개 쓰기다.** 새 창구는 감사 라우트의 규칙
(`미설정 = 거부`)을 따르고 `timingSafeEqual` 로 비교한다.

**단계 2 — `CRON_SECRET` 을 쓴다.** 이 값은 **이미 GitHub Actions 에 있다**
(`investor-collect.yml` 이 크론 라우트를 부를 때 쓴다). 새 비밀값을 만들면 관리할 것이
하나 늘 뿐이고 노출면은 그대로다.

**만든 것:**

| 파일 | 역할 |
|---|---|
| `apps/web/lib/thirteenf-ingest.ts` | 검사·병합 **순수 함수** — 라우트 없이 테스트된다 |
| `app/api/fomo/cron/investors/thirteenf/route.ts` | POST 창구. 인증 필수 |
| `scripts/collect-thirteenf.ts` | Actions 에서 SEC 를 읽고 POST. `CRON_SECRET` 없으면 **POST 하지 않고 멈춘다** |
| `.github/workflows/investor-13f-collect.yml` | 08:00 KST(ARK 수집보다 먼저) |

**받는 쪽에서 막는 것 셋:** ① `source: "13f"` 인 id 만(ARK 칸을 밖에서 덮어쓸 수 없다)
② 티커·공시일 없는 보유는 버린다 ③ 한 인물 5,000종목 · 한 요청 20인물.
빈 payload 로는 아무것도 쓰지 않는다.

**로컬 dry-run 실측: 11인물 전부 수집 · 실패 0** (버핏 28종목 · 드러켄밀러 66종목 등,
전부 직전 분기 스냅샷까지). Actions 러너도 로컬과 같은 위치이므로 같은 결과가 나온다.

### 실측 중 찾은 출시 위험 — 「기타」 389종목

벤더 업종 79개 중 **가장 큰 것이 `기타`(389종목)** 였다. 우리 규칙은 「모르는 종목을 기타로
묶지 않는다」인데 **벤더가 이미 묶어서 보내고 있었다.** 얇은 업종 기준(5종목)을 가볍게
넘으므로 어느 날 카드가 「기타에서 돈이 빠지고」라고 말할 수 있었다 — 아무 뜻도 없는 카드다.

`isPlaceholderSector()` 로 `기타`·`기타업종`·`미분류`·`분류없음` 을 미분류로 세고 버린다
(집계·일별 원장 양쪽). `기타금융`·`기타제조` 는 실제 업종이라 살린다.
