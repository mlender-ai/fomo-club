## 0. 왜 먼저인가

이 배치는 **새 데이터를 카드에 붙이는 일**이다. 데이터가 안 나오면 전부 무너진다.

지난 배치에서 이 순서를 지켜서 얻은 것: KR 사업설명이 실제로는 있었다는 사실(파서 버그),
DART 가 Vercel 런타임에서는 열린다는 사실. **추측 파서로 0% 를 찍고 그걸 문서에 박제할 뻔한 것을
두 번 막았다.**

같은 규율을 적용한다. **응답 구조를 먼저 덤프하고, 그 근거로 파서를 쓴다.**

## PART A — 현재 카드 정보 감사

### A-1. 카드 페이로드 필드 인벤토리

발행 카드에서 **실제로 채워지는 필드**를 전수 집계한다.

| 축 | 확인 항목 |
|---|---|
| 수급 주체 | 개미·기관·외국인 중 몇 개가 동시에 채워지나 |
| 연속일수 | 주체별로 따로 있나, 하나만 있나 |
| 거래량 | 평소 대비 비율 외에 무엇이 있나 |
| 가격 구조 | 52주 저점 대비 위치 외에 무엇이 있나 |
| 캔들·OHLC | 일봉 시계열이 팩트시트/페이로드에 존재하나 |
| 배경 | 뉴스·공시·실적 관련 필드가 하나라도 있나 |

**표본 규약 (개정 R3)**
- 목표는 200장·유니버스 무작위 추출·시드 기록이다.
- **확보 불가 시 확보 가능한 전수를 쓰고, 표본 수·추출 방식·한계를 문서에 명시한다.**
- 발행 게이트를 통과한 카드만으로 확보율을 재지 않는다 — 게이트가 이미 거른 것을
  확보율로 읽으면 실패 모드 "표본이 좋아 보임" 에 해당한다.

산출: `docs/audit/CTX_card_field_inventory.md`

### A-2. 정보 밀도 대비 판단 기여도

카드 블록 각각에 대해 **"이 블록이 없으면 판단이 달라지는가"** 를 판정한다.
**사람이 판정하고** 근거를 한 줄씩 남긴다. 기여도 낮은 블록은 CTX-05 에서 제거 대상이 된다.

## PART C — 성능 예산

504 사고를 반복하지 않는다.

### C-1. 현재 조회 경로 예산

- 발견 덱 조회 1회의 현재 소요와 단계별 분해
- **남은 여유가 몇 초인가**

> ⚠️ **`stage-timer` 만으로 판정하지 않는다 (개정 R4).**
> 실측에서 서버 self-report 는 175ms 인데 클라이언트는 49.0초를 기다렸다(약 280배).
> `stage-timer` 는 콜드스타트를 보지 못한다. **웜업 없는 첫 호출을 직접 측정**한다.

### C-2. 신규 층의 예산 배정

```
조회 시점에 계산되는 것: 0
배치에서 미리 굽는 것:   수급 3분 · 구조 판정 · 재료 수집 · 배경 후보
```

**추가 조건 (개정 R4·WO-SYNC C-3) — 번들 격리**

```
신규 모듈은 조회 경로 번들에 포함되지 않아야 한다.

- 계산을 배치로 빼도 무거운 의존성이 조회 번들에 들어가면 콜드스타트가 나빠진다
- 현재 람다 단일 번들 10.15MB. 신규 모듈 추가 후 증가분이 임계 이내여야 한다
- 조회 경로 번들 크기를 CI 에서 측정하고 임계 초과 시 실패
- INV-C15 를 "조회 경로에서 신규 모듈 미호출" → "미호출 + 번들 미포함" 으로 확장
```

**조회 경로에 새 계산이 들어가면 이 배치는 실패다.**

## 완료 조건

1. 카드 필드 인벤토리가 실측값으로 채워져 있다
2. B-1·B-2·B-3 매트릭스의 **모든 셀이 실측값**이다 (미확인은 `미확인` 으로 명시)
3. **응답 구조 덤프가 파서 작성보다 먼저** 이루어졌다
4. 뉴스 방침이 문서에 반영돼 있다 (개정 R5 — 확인이 아니라 **확정 방침 적용**)
5. 신규 층 전부가 배치 사전계산으로 설계돼 있고, **번들 격리 조건**이 명시돼 있다
6. GO/NO-GO 판정과 조정된 범위가 기록돼 있다
7. `docs/STATUS.md` 가 갱신돼 있다

## 에이전트에게

- **프로덕션 쓰기·크론 호출을 하지 않는다.** 읽기 전용 감사 라우트 추가는 허용된다(R1)
- 감사 라우트는 **`AUDIT_TOKEN`** 을 쓴다. **`CRON_SECRET` 재사용 금지**(R2)
- 데이터가 안 나오면 안 나온다고 적는다. 우회하지 않는다
- 불확실하면 중단하고 질문한다
