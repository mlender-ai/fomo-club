# WO-DECK-01 — 덱 고착 해소

> 지시 원문(채팅) 을 그대로 옮긴 정본. 진행 상황은 `docs/audit/DECK_STAGNATION.md` 와 `docs/STATUS.md` 에 남긴다.

| 항목 | 값 |
|---|---|
| 성격 | 랭킹·덱 구성 로직 수정 |
| 마감 | 2일 |
| 완료 | **3일 연속 관측했을 때 1페이지 종목이 매일 바뀌는 것** |
| 우선순위 | **최상.** 재방문 이유가 없는 상태다 |

---

## 0. 문제

며칠째 덱 1/10이 같은 종목(빅텍)이다. 사용자가 매일 열어도 같은 카드를 본다.
**재방문 이유가 없다.** 일 노출 5.8·5일 중 2일 세션 0이라는 실측이 이것과 무관하지 않다.

---

## 1. 원인 가설 — 실측으로 확인할 것

### 1-1. 연속일수는 단조 증가한다

`기관 25일 → 26일 → 27일`. 랭킹 점수가 연속일수에 비례하면 **시간이 갈수록 그 종목이 더 강해진다.** 1등에서 내려올 구조적 경로가 없다.

### 1-2. 컨셉과 랭킹이 반대다

카드 캡션은 `◆ 사기 시작한 시점`이다. 제품이 잡으려는 건 **"돈이 들어오기 시작한 순간"**인데, 랭킹은 **"가장 오래 들어오고 있는 것"**을 1등으로 올린다.

> **신호의 가치는 발생 시점에 가장 높고 시간이 갈수록 낮아진다.**
> 26일째 매수는 이미 26일 늦은 정보다.

### 1-3. 재노출 페널티가 없다

어제 1페이지에 나온 종목이 오늘 또 1페이지에 오는 것을 막는 규칙이 없다.

### 1-4. 픽 통과 풀이 작다

유니버스 486인데 픽 10 + 워치 10 = 20. **나머지 466이 왜 안 나오는지** 확인이 필요하다. 회전할 종목 자체가 부족하면 위 셋을 고쳐도 한계가 있다.

---

## PHASE 1 — 진단 (선행)

**고치기 전에 실측한다.**

### 1-1. 고착 실측

```
최근 14일간 일별 덱 구성을 뽑는다:
  - 1위 종목이 며칠 연속 같았는가
  - 1페이지(1~3위) 종목의 일별 변경률
  - 10장 전체의 일별 신규 진입 수
  - 종목별 누적 노출 일수 상위 10
```

### 1-2. 랭킹 점수 분해

1위 종목의 점수를 **구성 요소별로 분해**한다.

| 확인 |
|---|
| 연속일수가 점수에 어떻게 들어가는가 (선형? 로그? 상한 있나) |
| 연속일수 항이 총점에서 차지하는 비중 |
| 시간 경과에 따라 감쇠하는 항이 하나라도 있는가 |

### 1-3. 풀 크기 진단

466종목이 왜 픽에 못 드는지 **사유별로 집계**한다.

| 사유 | 건수 |
|---|---|
| 신호 없음 | |
| 신호 있으나 임계 미달 | |
| 대형주 제외 필터 | |
| 유동성 필터 | |
| 이미 많이 오름 필터 | |
| 기타 | |

**"신호 있으나 임계 미달"이 많으면 임계값 문제**이고, **"신호 없음"이 많으면 신호 산출 문제**다. 대응이 달라진다.

### 1-4. 산출물

`docs/audit/DECK_STAGNATION.md`

---

## PHASE 2 — 신규성 축 도입

### 2-1. 원칙

> **연속일수 자체가 아니라 "지금 새로 생긴 것인가"를 랭킹의 1차 축으로 둔다.**

이건 임계값 조정이 아니라 **랭킹 철학의 수정**이다. 컨셉("사기 시작한 시점")에 맞춘다.

### 2-2. 신규성 점수

```
novelty = f(신호 발생 경과일)
- 신호가 처음 나타난 날 최대
- 경과일에 따라 감쇠
- 감쇠 곡선은 PHASE 1 실측 분포로 결정한다 (감으로 정하지 않는다)
```

**연속일수는 "신호 강도"가 아니라 "신호 나이"다.** 오래된 신호는 강한 게 아니라 늦은 것이다.

### 2-3. 연속일수의 새 역할

완전히 버리지 않는다. 다음 용도로만 쓴다.

| 용도 | 내용 |
|---|---|
| 이례성 판정 | "40거래일 중 최장" 같은 상대 비교 |
| 최소 조건 | N일 미만은 노이즈로 제외 |
| **랭킹 가점** | **금지.** 길수록 순위가 오르면 고착이 재발한다 |

### 2-4. 상한

연속일수가 일정 기간을 넘으면 **"신규 신호"가 아니므로 픽 후보에서 워치로 강등**한다. 임계는 실측으로 정한다.

---

## PHASE 3 — 재노출 쿨다운

### 3-1. 규칙

```
최근 N일 내 1페이지(1~3위)에 노출된 종목은 순위를 강등한다.
- 완전 제외가 아니라 강등 (강한 신호를 영구히 못 보게 하면 안 된다)
- N과 강등 폭은 실측으로 정한다
```

### 3-2. 쿨다운 예외 — 재등장 사유가 명확할 때

다음 중 하나면 쿨다운을 무시하고 재등장할 수 있다. **단 카드에 재등장 사유를 표시한다.**

| 예외 | 표시 |
|---|---|
| 무효선 이탈 | 되돌아보는 선을 넘었어요 |
| 새 재료 발생 | 공시가 나왔어요 |
| 다른 주체가 합류 | 외국인도 사기 시작했어요 |
| 구조 유형 전환 | 거래가 붙기 시작했어요 |

**"어제보다 1일 더 이어졌어요"는 재등장 사유가 아니다.** 그건 변화가 아니라 지속이다.

---

## PHASE 4 — 덱 구성 규칙

점수 상위 10개를 그대로 쓰지 않는다. **구성 비율을 고정한다.**

```
10장 구성:
  신규 신호 (경과 N일 이내)     최소 M장
  지속 신호                      최대 K장
  동일 주체 편중 방지            같은 주체 신호가 X장을 넘지 않음
```

- M·K·X는 PHASE 1 실측 후 결정
- **신규 신호가 M장에 못 미치면 그 자리를 비우거나 워치에서 승격한다.** 지속 신호로 채우지 않는다
- 구성 규칙을 문서에 고정하고 버전을 찍는다

---

## PHASE 5 — 계측

### 5-1. 회전율 지표

```
- 1위 종목 연속 유지일 (목표: 3일 이하)
- 1페이지 일별 변경률
- 덱 10장의 일별 신규 진입 수
- 종목별 30일 누적 노출 일수 분포
```

**대시보드에 노출하고, 1위가 3일 이상 고착되면 알림.**

### 5-2. 행동 지표 연결

`WO-SUB-00`의 행동 계측과 연결한다.

| 지표 | 확인 |
|---|---|
| 재방문율 | 회전율 개선 후 변화 |
| 1페이지 이탈률 | 같은 카드 반복 노출과의 관계 |
| 덱 완주율 | |

## 완료 조건

1. `DECK_STAGNATION.md`에 고착 실측과 원인이 기록돼 있다
2. 466종목의 픽 미달 사유가 사유별로 집계돼 있다
3. **연속일수가 랭킹 가점으로 쓰이지 않는다** (코드 검증)
4. 신규성 축이 랭킹 1차 축으로 동작한다
5. 감쇠 곡선·쿨다운 기간·구성 비율에 **실측 근거가 문서에 있다**
6. 재노출 쿨다운이 동작하고, 예외 시 카드에 재등장 사유가 표시된다
7. 덱 구성 비율이 고정되고 버전이 찍혀 있다
8. 회전율 지표가 대시보드에 노출된다
9. **3일 연속 관측 시 1페이지 종목이 매일 바뀐다** — 프로덕션 실측
10. 정규 도메인 배포 후 화면 확인

## 실패 모드

| 실패 모드 | 방지 |
|---|---|
| 임계값만 조정해 임시로 순서를 바꿈 | 연속일수의 랭킹 가점 자체를 제거 |
| 무작위 섞기로 회전을 만듦 | 근거 있는 신규성 축이어야 한다 |
| 쿨다운으로 강한 신호가 영원히 안 보임 | 강등이지 제외가 아님 + 예외 규칙 |
| 신규 신호가 부족해 지속 신호로 채움 | 자리를 비우거나 워치에서 승격 |
| 파라미터를 감으로 정함 | PHASE 1 실측 선행 |
| 배포 후 하루만 보고 완료 판정 | 3일 연속 관측 |

---

## 에이전트에게

- **PHASE 1을 끝내고 보고한 뒤 PHASE 2로 간다.** 원인 규명 없이 랭킹을 고치지 않는다
- **연속일수를 랭킹 가점에서 빼는 것이 이 WO의 핵심**이다. 다른 걸 다 해도 이게 남으면 고착이 재발한다
- 파라미터를 정할 수 없으면 분포와 선택지를 정리해 질문한다
- 완료 판정은 **3일 연속 프로덕션 관측**이다. 하루 보고 끝내지 않는다
