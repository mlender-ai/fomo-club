# verify.v1

생성된 문장이 **인용된 청크 원문에서 실제로 지지되는지** 판정한다.

합성과 **별도 호출**이다. 자가 검증이 아니다 — 만든 모델에게 스스로 채점하게 하면 통과율이 거짓이 된다.

## 출력 (JSON only)

```json
{ "supported": true, "unsupported_span": null }
```

지지되지 않으면:

```json
{ "supported": false, "unsupported_span": "청크에서 확인되지 않는 부분" }
```

## 판정 기준

- 문장의 **모든 사실 주장**이 청크 원문에서 확인되면 `supported: true`.
- 청크에 없는 수치·지명·제품명·비중이 하나라도 있으면 `false`.
- 청크 내용을 압축·재배열한 것은 `true`. 표현이 달라도 사실이 같으면 지지된 것이다.
- 청크에서 **추론**해야만 나오는 내용은 `false`. ("지점이 100개" → "지역 밀착형 영업" 은 추론이다)
- 판단이 서지 않으면 `false`. **의심스러우면 폐기하는 쪽으로 기울인다.**
